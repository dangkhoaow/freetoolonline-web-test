Calculadora de Juros Simples Online Passo a Passo

Last reviewed: 2026-08-02

A Calculadora de Juros Simples Online funciona em três etapas: abrir a ferramenta, inserir os dados e copiar o resultado. Esta página detalha o que cada etapa requer.


Passo 1 - abrir a ferramenta

Acesse a Calculadora de Juros Simples Online. Nenhuma instalação ou conta é necessária antes de começar.


Passo 2 - inserir os dados

Informe o principal, a taxa de juros anual e o tempo em anos; os juros obtidos e o valor total são atualizados enquanto você digita.


Passo 3 - copiar o resultado

O cálculo é feito localmente no navegador - sem envio de dados e sem conta necessária.

Diferente de uma calculadora de juros compostos, os juros simples são calculados apenas sobre o principal original durante todo o período - eles não são reinvestidos a cada período.
