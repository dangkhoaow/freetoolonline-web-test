Comprimir Arquivo Zip

Empacotar arquivos em um .zip no navegador pode ter dois significados: criar um arquivo .zip novo a partir de arquivos ou pastas, ou tentar reduzir o tamanho de um .zip já existente. Esta página indica a ferramenta certa para cada objetivo - o compactador ZIP para criar, o guia de compressão para reduzir.

Qual é a sua tarefa?

  1. Tem um arquivo ou pasta (fotos, documentos, código) que você quer empacotar em um único .zip antes de enviar? Use o compactador ZIP - upload, opção de senha, download em segundos.
  2. Já tem um .zip e quer reduzir o tamanho? Veja Comprimir Pasta Zipada - o algoritmo deflate já removeu a redundância, então re-comprimir raramente reduz mais de 1%.
  3. Quer comprimir uma pasta inteira pela primeira vez em português? Veja Compactar Pasta - passo a passo em português do mesmo fluxo no /zip-file.html.

Criar um arquivo zip novo a partir de um arquivo ou pasta

Esta é a tarefa mais comum quando alguém digita "comprimir arquivo zip" no buscador. O fluxo no compactador ZIP é: arraste o arquivo ou a pasta para a área de upload, abra "Settings" e defina o nome do .zip + senha opcional (Standard, AES-128 ou AES-256), clique em Zip e baixe o resultado. A hierarquia de subpastas é preservada dentro do arquivo gerado, e os arquivos enviados são removidos do serviço privado de build após uma janela curta de retenção. Não há conta, cadastro nem versão paga.

Por que re-comprimir um .zip existente raramente vale a pena

Se o arquivo que você tem em mãos já é um .zip e o objetivo é reduzir o tamanho, a expectativa precisa ser ajustada. O formato ZIP usa o algoritmo deflate (combinação de LZ77 + Huffman) que já remove redundância byte por byte na primeira compactação; re-comprimir um .zip processa bytes que são quase aleatórios para o algoritmo. Em testes práticos, re-comprimir um .zip uma segunda vez economiza menos de 1% na maioria dos casos. O guia detalhado em Comprimir Pasta Zipada compara três abordagens (re-zipar direto, descompactar e re-zipar com nível máximo, descompactar e comprimir as imagens individualmente antes de re-zipar) com números de tamanho e tempo.

Quando proteger o arquivo zip com senha

Tanto no fluxo de criação novo (item 1 acima) quanto numa eventual re-compactação, você pode marcar a opção de senha em Settings. Standard é a opção mais antiga e compatível - qualquer descompactador abre o ZIP desde que a senha esteja correta, mas a criptografia é considerada fraca para conteúdo confidencial. AES-128 é o padrão moderno recomendado para a maioria dos casos de uso (contratos, documentos internos, conjuntos de fotos pessoais); o 7-Zip, o WinRAR e o The Unarchiver no macOS leem o formato sem configuração extra. AES-256 oferece a proteção mais forte com a mesma compatibilidade do AES-128 e é a escolha indicada para dados realmente sensíveis. A senha aplicada não "quebra" senhas de ZIPs criados em outro lugar - se você precisa abrir um .zip protegido com uma senha conhecida e ter uma cópia sem senha, veja o removedor de senha ZIP.

Perguntas frequentes

Comprimir um arquivo qualquer em .zip realmente reduz o tamanho?

Depende do tipo de arquivo. Texto, código-fonte e planilhas costumam encolher entre 50% e 80% no ZIP. Imagens JPG / PNG / HEIC e vídeos MP4 / MOV já estão comprimidos pelo formato original, então o ZIP adiciona pouco ou nenhum ganho - o uso principal nesse caso é empacotar vários arquivos em um único anexo. PDFs ficam entre os dois extremos: páginas com texto puro encolhem; páginas escaneadas (que são imagens internamente) quase não mudam.

O processamento é feito no navegador ou no servidor?

O compactador ZIP faz upload dos arquivos via HTTPS para o serviço privado de build da FreetoolOnline, monta o .zip do lado do servidor e devolve o resultado como um único download. Os arquivos enviados são removidos do serviço após uma janela curta de retenção. Se a sua política exige que os arquivos não saiam do dispositivo em nenhum momento, use um compactador desktop (7-Zip, WinRAR, ou o utilitário nativo do macOS).
