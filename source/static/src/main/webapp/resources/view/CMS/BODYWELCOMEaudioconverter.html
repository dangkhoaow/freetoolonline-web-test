Audio Converter

Last reviewed: 2026-07-02
freetoolonline.com editorial team

Turn an audio file, or the soundtrack of a video, into an MP3 right in the browser. Choose an MP3 bitrate, drop or select your file, and save the result - conversion runs in the tab using FFmpeg.wasm and nothing reaches a server. The working copy is released when you navigate away.

You can start from MP3, WAV, AAC, OGG, FLAC, or M4A audio, or a video whose sound you want to keep; the output is always an MP3.


Key features

  • Encodes MP3 with libmp3lame and strips the video stream, so a video file's audio track comes out as a clean MP3.
  • Choose the MP3 bitrate from 128, 192, 256, or 320 kbps (192 is the default).
  • Runs entirely in your browser tab via FFmpeg.wasm - no bytes leave your device.
  • The FFmpeg.wasm engine (about 31 MB) loads only on your first conversion, so the page stays light until you actually use the tool.
  • The result is delivered as an in-tab download link, and the temporary input and output files are cleared from memory once the download is ready.

When to use it

  • Pull the soundtrack out of a video clip and keep it as an MP3.
  • Re-encode a large WAV or FLAC recording into a smaller, widely-playable MP3.
  • Set a lower bitrate when file size matters most, or 320 kbps when you want higher-fidelity audio.

Privacy and data handling

Your input file is processed locally in the page and discarded when you close it - nothing is stored or uploaded at any step. Because the conversion happens on your device rather than a server, private recordings never leave the browser.


How the conversion runs

While the tool works, a status line reports load and conversion progress so you can see what is happening. If FFmpeg cannot process the file, the tool shows the error message in a panel instead of failing silently, so you know to try a different file or setting.
