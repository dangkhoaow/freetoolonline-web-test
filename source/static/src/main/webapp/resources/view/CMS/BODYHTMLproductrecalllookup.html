Type a product, brand, or manufacturer keyword - the tool searches recall titles first and automatically retries by manufacturer name when the title search comes up empty, so "stroller" and "Peony Design" both find their reports. Matching recalls list newest first, with an optional hazard keyword filter (like "choking" or "fire"). Each recall card links to the official cpsc.gov notice and carries the remedy badge (refund, repair, or replace), the hazard, the affected models and unit counts, and where the product was sold; the remedy table below explains what each option means.
