Passport Photo Maker: Wann Verwenden, Schritte Und Alternativen

Last reviewed: 2026-08-10

Öffnen Sie Passport Photo Maker, wenn Sie schnell ein Pass- oder Visumfoto brauchen, ohne Installation und ohne Konto. Die Ausgabe wird auf einem einfarbig weißen Hintergrund in der exakten Pixelgröße des Presets zusammengesetzt, berechnet mit 300 DPI für den Druck.


Wann es passt

Es passt für einen schnellen Einmal-Einsatz: ein Porträt, eine Größe, ein Download. Presets deckt die Größen für USA, Indien, Schengen/EU, Großbritannien, Australien, Kanada und China-Visum ab, und "Custom size (mm)" nimmt jede Breite und Höhe in Millimetern, wenn Ihr Zielland nicht auf dieser Liste steht. Aktivieren Sie "Also generate a 4x6in print sheet", um zusätzlich einen Druckbogen mit so vielen Kopien herunterzuladen, wie auf eine Seite passen.


Die drei Schritte

  1. Öffnen Sie das Tool. Vor dem Start muss nichts installiert oder angemeldet werden.
  2. Wählen Sie ein Porträtfoto und die Preset-Größe, ziehen Sie dann das Foto, um das Gesicht im Rahmen zu positionieren, und füllen Sie den Rahmen mit dem Zoom-Regler.
  3. Klicken Sie auf Generate photo und speichern Sie das Ergebnis über die Download-Links. Alles läuft lokal über die Canvas API, das Foto wird also nie auf einen Server hochgeladen.

Vergleich mit einer Desktop-Anwendung oder einem Upload-Dienst

Dies ist eine von drei gängigen Möglichkeiten dafür: ein Browser-Tool wie dieses, eine Desktop-Anwendung oder ein Upload-basierter Online-Dienst. Jede Option unterscheidet sich darin, wohin Ihre Daten gehen und was installiert werden muss.

Was das Tool nicht tut

Dieses Tool schneidet zu und passt die Größe an, und kann den Hintergrund des Fotos optional durch einen weißen, hellblauen oder hellgrauen Hintergrund ersetzen - mit einem KI-Modell, das auf Ihrem Gerät läuft (einmaliger Download von ~26 MB). Es erkennt oder zentriert das Gesicht nicht automatisch und prüft nicht die Einhaltung der vollständigen Anforderungen einer bestimmten Passbehörde (Beleuchtung, Ausdruck, Kopfbedeckung); prüfen Sie die offiziellen Regeln Ihres Ziellandes vor dem Einreichen.
