Random Team Generator Step By Step

Last reviewed: 2026-07-24

Random Team Generator splits a pasted list of names into teams in four clicks. This page walks through what each step expects, from the first name you type to the team cards you read off.


Step 1 - open the tool and check the sample names

Go to Random Team Generator. Nothing needs to be installed or signed in - the page loads with 8 sample names already split into 2 teams so you can see the shape of the result before typing anything.


Step 2 - paste your own names

Clear the sample list and paste your names into the box, one name per line. Blank lines are ignored, so it is fine to paste a list with extra spacing.


Step 3 - set the number of teams

Type the number of teams you want into the Teams box (from 2 up to 20). If you ask for more teams than you have names, the tool shows a message telling you to add more names instead of generating a broken split.


Step 4 - generate and read the teams

Click "Generate teams." The names are shuffled fairly and divided evenly across the team cards below the button, each headed "Team 1," "Team 2," and so on. Click the button again any time to reshuffle the same list, or edit the names first for a different roster.

Everything happens in your browser - the names you paste are never sent to a server, and the list is not saved once you leave the page.
