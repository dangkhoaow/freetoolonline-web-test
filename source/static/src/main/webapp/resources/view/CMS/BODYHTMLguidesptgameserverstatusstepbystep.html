Como Verificar o Status de Servidores de Jogos - Passo a Passo

Last reviewed: 2026-08-18

O verificador de status de servidores de jogos responde a duas perguntas em uma página: a plataforma está fora do ar, e um servidor específico de Minecraft está online? Veja exatamente o que clicar e como ler cada resultado.


1. Leia os três cartões de plataforma

Os cartões de Fortnite / serviços Epic Games, Roblox e Discord preenchem-se sozinhos, sem cliques. Cada um lê a API pública de status da própria plataforma e mostra um indicador colorido com a descrição oficial palavra por palavra: verde significa operacional, amarelo um problema parcial, laranja uma falha grave, vermelho uma queda geral da plataforma. Cada cartão também traz o link da página oficial de status.


2. Verifique um servidor de Minecraft pelo endereço

Digite o endereço do servidor na caixa - um host simples como mc.hypixel.net, ou host:porta como play.example.org:19132. Escolha Java Edition ou Bedrock Edition e pressione Check server (Enter também funciona). Uma consulta de exemplo roda quando a página carrega, claramente identificada, para você ver o formato do resultado antes.


3. Leia o cartão de resultado

Um servidor online mostra os jogadores conectados sobre o máximo, a versão e a primeira linha da mensagem do dia. Um servidor offline ou inacessível recebe um cartão claro repetindo o endereço digitado - confira a grafia e a porta primeiro, pois um erro de digitação aparece como offline. A verificação é feita pelo serviço mcstatus.io, que guarda os resultados em cache por cerca de um minuto; um servidor recém-reiniciado pode aparecer offline por instantes.


4. Se um cartão disser que não alcançou a API

Algumas redes de escolas e escritórios bloqueiam domínios de jogos por categoria. Os cartões avisam isso claramente em vez de ficar em branco, e as páginas oficiais de status podem ainda abrir. Nada do que você digita vai para os servidores deste site, e a página não armazena nada.
