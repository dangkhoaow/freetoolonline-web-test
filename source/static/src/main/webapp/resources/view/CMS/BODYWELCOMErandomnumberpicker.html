Random Number Generator

Last reviewed: 2026-07-02
freetoolonline.com Editorial Team

This random number generator picks a whole number between a minimum and maximum you choose, right in your browser. There is nothing to download, install, or sign up for - set your range and click Generate.

Enter a Min and a Max in the two boxes, then click Generate and the result appears underneath. Click Generate again at any time for a fresh number in the same range.


Key features

  • Picks a whole number between the Min and Max you choose, with both ends of the range included.
  • Swaps the two values internally if you enter the larger number in the Min box, so the range still works.
  • Each number is chosen using your browser's crypto.getRandomValues, a fairness source built into every modern browser, so every whole number in your range has an equal chance on every click.
  • Runs entirely in your browser - no download, no install, and no account.

When to use it

Reach for it for raffles and giveaways, picking a random sample index, settling a quick decision, or any moment that needs a fair number from a range you choose rather than a fixed one-to-six or heads-or-tails result.


Privacy

Everything runs locally on your device, with no upload and no account. The result is not saved once you leave the page, so refreshing clears it back to a fresh generator.

How your Min and Max range shapes the result

Because the pick counts both the Min and the Max you type as possible results, a range of 1 to 100 gives exactly 100 equally likely results rather than 99, and setting the boxes to 0 and 9 returns all ten single digits. The Min and Max fields also accept negative values, so a range such as -50 to 50 covers 101 numbers in total. Every press of the green Generate button is independent of the last, which means the same value can repeat across clicks - this random number tool does not draw without replacement, so for a set of unique values or a reordered list a shuffler is the better fit. When the page first loads it has already produced one number from the default 1 to 100 range, so a result is on screen before you touch either box.
