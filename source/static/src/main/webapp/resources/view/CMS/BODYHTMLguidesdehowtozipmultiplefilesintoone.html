Wie man mehrere Dateien zu einer ZIP zusammenfuegt

Zuletzt geprueft: 2026-04-27. Oeffnen Sie das ZIP-Werkzeug, um Dateien in Ihrem Browser ohne Upload zu kombinieren.

30-Sekunden-Antwort. Mehrere Dateien zu einer ZIP zu buendeln erfordert vier Schritte in dem ZIP-Werkzeug: Dateien auswaehlen, Ausgabe benennen (etwas Beschreibendes, ohne Leerzeichen wenn E-Mail das Ziel ist), Default-Kompression fuer gemischten Inhalt oder Store fuer bereits komprimierte Medien einstellen und auf Download klicken.

Die vier Schritte im Detail

  1. Dateien auswaehlen. Drag-and-Drop ist der schnellste Weg auf dem Desktop; Multi-File-Picker funktioniert auf Telefonen. Das Werkzeug akzeptiert jeden Dateityp.
  2. Ausgabe benennen. Das Werkzeug nimmt standardmaessig archive.zip - funktioniert, aber sagt dem Empfaenger nichts. 2026-Q1-rechnungen.zip oder urlaubsfotos.zip lesen sich besser.
  3. Kompressionslevel einstellen. Default (Level 6) fuer einen Mix. Best (Level 9) wenn die Dateien hauptsaechlich Text sind. Store (Level 0) wenn alles darin bereits komprimiert ist.
  4. Herunterladen. Der Browser uebergibt Ihnen das fertige Archiv. Die Originaldateien bleiben unberuehrt.

Wie viel kleiner die ZIP wird

Die Komprimierungseffektivität hängt davon ab, was Sie hineinlegen, nicht davon, wie viele Dateien Sie auswählen.

DateitypTypische Größenreduzierung
Text, Quellcode, CSV, JSON60-80% kleiner
Office-Dokumente (Word, Excel, PowerPoint)10-25% kleiner
PDFs5-15% kleiner
Bereits komprimierte Fotos (JPG, PNG, HEIC)0-5% kleiner

Was das Werkzeug nicht tut

Was das Werkzeug nicht tut bei Mehrere Dateien zu einer ZIP zusammenfuegen ist standardmaessig verschluesseln, in die Cloud syncen oder jede Datei umbenennen - es packt nur was Sie ablegen.

  • Ein Passwort waehrend der Erstellung hinzufuegen. Fuer passwortgeschuetzte Archive siehe ZIP-Datei mit Passwort.
  • Ordnerstruktur ueber mehrere Drag-and-Drop-Auswahlen erhalten. Wenn Sie ein verschachteltes Layout in der ZIP benoetigen, ziehen Sie den uebergeordneten Ordner.
  • Eine Datei vor dem Zippen bearbeiten. Komprimieren Sie Bilder zuerst mit Bild komprimieren wenn die Groesse wichtig ist.

Fuer weitere ZIP-Workflows: Datei zu ZIP zeigt den schrittweisen Erstellungspfad; ZIP auf 2 MB komprimieren erklaert, wie ein Groessenlimit eingehalten werden kann. Fuer alles andere, der ZIP-Werkzeuge-Hub.

Häufig gestellte Fragen

Was bekomme ich zurück, wenn ich mehrere Dateien zippe?

Ein ZIP-Archiv, das jede ausgewählte Datei bündelt. Laden Sie es als eine einzige Datei herunter; der Empfänger entpackt es wieder in dasselbe Layout, das Sie gesendet haben, einschließlich jeder erhaltenen Ordnerstruktur.

Warum wird ein Ordner voller Fotos beim Zippen kaum kleiner?

JPG-, PNG- und HEIC-Dateien sind bereits durch ihr eigenes Format komprimiert. Mehrere davon in ein ZIP zu packen bündelt sie meist nur - die Größe sinkt nur um 0-5%. Wenn der Ordner hauptsächlich Fotos enthält und die Größe wichtig ist, komprimieren Sie die Bilder zuerst mit Bild komprimieren und zippen Sie dann das Ergebnis.

Wohin gehen meine Dateien, während die ZIP erstellt wird?

Nirgendwohin. Die ZIP wird vollständig auf Ihrem Gerät erstellt - die ausgewählten Dateien verlassen Ihren Browser nie, und es findet kein Upload statt. Sobald das Archiv fertig ist, erzeugt der Browser den Download-Link direkt aus der fertigen ZIP im Arbeitsspeicher.
