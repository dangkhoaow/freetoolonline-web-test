Bộ Tạo QR Code - Các Thực Hành Tốt Nhất

Lần rà soát cuối 2026-06-16. Mở bộ tạo QR code để tạo code trong trình duyệt bạn mà không gửi payload đi đâu.

Câu trả lời 30 giây. Một QR code luôn quét được phụ thuộc vào năm cài đặt. Sửa lỗi mức M hoặc cao hơn (cho code sống sót từ hư hại nhẹ). Tương phản cao (đen trên trắng, không gradient nhẹ). Kích thước vật lý tối thiểu 2 cm (nhỏ hơn thất bại trên camera điện thoại). Vùng yên tĩnh ít nhất bốn modules quanh cạnh. Và payload ngắn - URL dài tạo code dày, khó quét; dùng URL shortener trước.

Sửa lỗi - cài đặt bị bỏ qua nhiều nhất

QR code có bốn mức sửa lỗi. Chúng nói với bộ mã hóa bao nhiêu của code có thể bị hư hại hoặc che trước khi quét thất bại:

  • L (Low). Khôi phục đến ~7% hư hại. Code nhỏ nhất, ít khoan dung lỗi nhất. Dùng chỉ khi code ở trên màn hình và không bị xước.
  • M (Medium). Khôi phục ~15% hư hại. Mặc định trong hầu hết bộ tạo. Tốt cho hầu hết ngữ cảnh in.
  • Q (Quartile). Khôi phục ~25% hư hại. Dùng khi code có thể chồng logo hoặc bị che một phần.
  • H (High). Khôi phục ~30% hư hại. Lựa chọn đúng cho code in trên biển hiệu ngoài trời, trên bao bì, hoặc nơi mong đợi sự hao mòn.

Đánh đổi: sửa lỗi cao hơn làm code dày hơn (nhiều ô vuông đen-trắng hơn mỗi vùng) cho cùng một payload. Chọn mức thấp nhất mà môi trường của bạn khoan dung.

Tương phản và màu sắc

Tiêu chuẩn là tiền cảnh tối trên nền sáng. Đen trên trắng quét tốt nhất. Đảo ngược (sáng trên tối) thường thất bại vì scanner camera điện thoại giả sử tính phân cực tiêu chuẩn.

Màu tùy chỉnh hoạt động nếu tỷ lệ tương phản giữ trên 4:1 - một xanh đậm trên trắng là ổn, một xám trung bình trên trắng không ổn. Sáng-trên-tối không đáng tin cậy; không bao giờ dùng QR trắng-trên-đen cho vật liệu in. Nền gradient phá quét hoàn toàn; khu vực code phải là một màu rắn duy nhất.

Kích thước vật lý và vùng yên tĩnh

Kích thước tối thiểu quét được phụ thuộc khoảng cách. Quy tắc ngón: độ dài cạnh code phải ít nhất 1/10 khoảng cách quét. Một code quét từ 30 cm (một điện thoại trên tay) cần ít nhất 3 cm. Một code quét từ 3 m (một poster) cần ít nhất 30 cm.

Vùng yên tĩnh là khoảng trắng quanh code. Đặc tả QR yêu cầu ít nhất bốn modules (các ô vuông nhỏ) lề trên cả bốn cạnh. Đặt code sát văn bản, một viền, hoặc một đồ họa khác làm scanner thất bại dù chính code còn nguyên vẹn.

Độ dài payload quan trọng hơn bạn nghĩ

Độ dày của một QR code tăng với kích thước payload. Mã hóa URL 10 ký tự tạo code thưa mà quét từ khoảng cách một mét. Mã hóa URL 200 ký tự với tracking parameters tạo code dày cần lớn hơn vật lý và quét từ gần hơn.

Luôn rút ngắn URL trước. example.com/p tốt hơn example.com/products/winter-collection?utm_source=poster&utm_campaign=2026-q1. Redirect có thể mang tracking parameters phía server; QR mang chỉ link ngắn. Kết quả là một code nhỏ hơn, đáng tin cậy hơn.

Test trước khi in

In code ở kích thước bạn dự định dùng, quét từ khoảng cách và góc bạn mong, và thử ít nhất hai điện thoại - một mới, một vài năm tuổi. Một code quét được từ 5 cm nhưng thất bại từ 50 cm là kích thước sai. Bộ tạo QR code xem trước code ở nhiều kích thước trước khi tải. Thêm logo ở giữa

Bộ tạo QR code có thể đặt một logo ở giữa code. Chọn một ảnh từ thiết bị của bạn và nó nằm trên một nền trắng nhỏ ở giữa; ảnh được đọc trong trình duyệt của bạn và không bao giờ được tải lên. Khi bạn thêm logo, công cụ tự động nâng mức sửa lỗi lên High, để các ô mà logo che vẫn có thể được khôi phục.

Giữ logo nhỏ - công cụ chỉnh kích thước nó khoảng một phần năm chiều rộng của code, mức mà code với sửa lỗi High chịu được. Logo lớn hơn vẫn có thể làm hỏng việc quét, vì vậy hãy tạo code và quét ảnh cuối cùng từ khoảng cách bạn mong đợi trước khi in hoặc đăng. Bạn cũng có thể đặt màu nền trước và nền sau để hợp với thương hiệu, miễn là tương phản vẫn cao.
