When to use Iapetus Equatorial Ridge 3D Explorer

Use this explorer when you want to see Iapetus's equatorial ridge height and walnut outline, plus the two-tone albedo contrast.

  • Comparing a ~20 km ridge on a ~1,400 km moon
  • Introducing Cassini New Years Eve 2004 discovery imaging
  • Discussing ridge-origin debates without forcing one answer

This is an educational visualization, not a formation model.
