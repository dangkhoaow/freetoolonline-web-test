Googol Stopping Game

Googol Stopping Game is a free browser optimal-stopping puzzle you can play without an account or install. Reveal fifty numbered tiles that hide enormous values one at a time, keep your last pick, and press I'm done when you believe you hold the biggest number of the set.

Key features

  • Fifty hidden values on a secretary-problem style board teach when to stop picking.
  • Huge-number strings up toward a googol make each reveal feel dramatic.
  • The Computer button demonstrates the classic sample-then-threshold strategy: it samples about n/e tiles, then keeps picking until one beats the sample.
  • A tiny ~8 KB download after Play fits a one-minute decision break on desktop or phone.
  • No account and no save file - just reveal, decide, and reset.

When to use it

Reach for it as a quick one-minute decision break on desktop or phone whenever you want to feel the sample-then-threshold rule in action rather than read about it.

Privacy and data

The adapted build is session-only, so refreshing the page resets the board and nothing is stored. It runs entirely in your browser with no account and no save file.

About the game

Googol Stopping Game is adapted from Victor Ribeiro's MIT-licensed googol.
