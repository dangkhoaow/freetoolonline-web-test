Cat Typing Race

Last reviewed: 2026-07-29

Cat Typing Race is a free browser typing duel - no account, no install. Press Play to load the game, then race the AI cat by pressing the letter keys A-Z that match the on-screen letters before it does.


Key features

  • Press keyboard letter keys A-Z to match the highlighted letter before the AI cat.
  • Press J to continue tutorial and level-dialog overlays; press M inside the game to toggle background music on or off.
  • Letter perks appear during play: bomb (-1 point), rocket (opponent -1), and snowflake (+1 but a 2s freeze).
  • Ten levels, three rounds each; the letter count grows with the level, up to 10.
  • Finish a round fastest with at least half the letters correct to earn the round-winner bonus.
  • Loads in about 28 KB after Play; keyboard only - there is no touch or on-screen keyboard path.

Privacy

Nothing leaves this device except the initial page and the game files served from this site. There is no server backend or CDN at runtime.
