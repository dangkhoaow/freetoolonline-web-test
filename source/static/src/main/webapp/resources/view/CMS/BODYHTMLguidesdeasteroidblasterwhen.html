Wann Asteroid Blaster spielen

Asteroid Blaster passt, wenn du einen Tastatur-Canvas-Shooter willst: ~245 KB, Felsen-Split, Screen-Wrap und gelegentliches Alien - ohne Install und ohne Save.

Last reviewed: 2026-07-18

Wenn du eine Tastatur hast

Wenn du eine Tastatur hast, passt Asteroid Blaster: links/rechts drehen, hoch schubst, Space feuert. Pause mit P, Mute mit M. Touch-only Telefone sind nicht das Ziel.

Wenn du eine kurze Arcade-Runde willst

Wenn du eine kurze Arcade-Runde willst, liefert Asteroid Blaster: Wellen wachsen von 2 Felsen bis 12. Zwei Ersatzschiffe. Tab schliessen beendet den Score - kein localStorage-Save.

Wenn ein kleiner Download reicht

Wenn ein kleiner Download reicht, passt Asteroid Blaster: etwa 245 KB gesamt, nach dem ersten Load gecacht. Keine Netzwerkaufrufe nach dem Load, keine Accounts im Game-Frame.

Wann etwas anderes

Wann etwas anderes statt Asteroid Blaster: wollen Sie einen WebGL Underrun-Lauf bei ~120 KB? Probieren Sie Retro Arcade Shooter. Wollen Sie einen 3D-Marble-Tilt bei ~1.7 MB? Nutzen Sie Marble Maze.
