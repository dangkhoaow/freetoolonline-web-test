Cuándo usar el N-Body Sandbox 3D Explorer

Last reviewed: 2026-08-11
freetoolonline.com editorial team

Abre el N-Body Sandbox 3D Explorer cuando quieras colocar los cuerpos tú mismo y ver qué hace la gravedad con ellos - órbitas que se sostienen, casi-choques que lanzan un cuerpo lejos y capturas que no habías planeado. Elige otra página cuando necesites una figura fija y repetible o un diagrama estático de un solo pozo gravitatorio.


Buenas razones para abrir el N-Body Sandbox

El N-Body Sandbox 3D Explorer se justifica cuando la lección es el comportamiento y no una única respuesta ordenada.

  • Demostraciones de clase de órbitas emergentes, dispersiones y capturas
  • Mostrar que el caos crece a medida que se añaden cuerpos, lo que es una propiedad real de estos sistemas y no un defecto
  • Presentar la constante newtoniana G real junto a un sistema que el lector ha construido

Deja de lado el N-Body Sandbox cuando el objetivo sea una coreografía fija que señalar, o una imagen quieta de un solo pozo gravitatorio. Los dos exploradores hermanos de abajo hacen esas tareas directamente.


Montar un sistema en el N-Body Sandbox

El N-Body Sandbox 3D Explorer abre con un sistema inicial de cuatro cuerpos: una masa central pesada y tres más ligeras ya en movimiento. A partir de ahí la secuencia es corta.

  1. Abre el N-Body Sandbox 3D Explorer y deja que el sistema inicial de cuatro cuerpos tome su movimiento.
  2. Lee el panel de datos: el valor real de G, cuántos cuerpos hay en la escena de los 16 que permite el sandbox, cuántos están en órbitas ligadas y cuántos están escapando o dispersándose.
  3. Elige Light body o Heavy body para el siguiente cuerpo que vayas a añadir. El panel confirma la elección en la fila del próximo cuerpo.
  4. Haz clic en el suelo para insertar ese cuerpo. Cada cuerpo nuevo llega con una pequeña velocidad aleatoria, así que arranca en una trayectoria en vez de caer directo hacia el centro.
  5. Arrastra para orbitar la cámara y desplaza o pellizca para acercar mientras los rastros que se desvanecen muestran por dónde ha pasado cada cuerpo. Pause congela la escena para una captura; Reset devuelve los cuatro cuerpos originales.

Añadir un cuerpo pesado junto a una órbita existente es la forma más rápida de romper un patrón estable a propósito - el recuento de órbitas ligadas del panel baja en cuanto uno de los cuerpos más ligeros gana energía suficiente para marcharse.

Límites que conviene conocer antes de enseñar con él

El movimiento en pantalla del N-Body Sandbox 3D Explorer usa una constante gravitatoria escalada para que la dinámica siga siendo visible dentro de una pantalla; el valor real de CODATA de la tabla se muestra por alfabetización científica, no para mover las esferas. La fuerza a corta distancia está suavizada, práctica estándar en código de N cuerpos, lo que evita que la fuerza se desborde cuando dos cuerpos pasan muy cerca. El resultado es un sandbox educativo y no una efeméride de uso general, así que trata las posiciones como ilustrativas.

Abre el N-Body Sandbox 3D Explorer para construir un sistema, o pasa al Three-Body Problem 3D y al Gravity Well 3D para las vistas de figura fija y de pozo estático.
