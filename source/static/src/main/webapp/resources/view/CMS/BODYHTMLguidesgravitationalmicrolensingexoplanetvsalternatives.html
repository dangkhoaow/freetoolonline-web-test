Where Microlensing wins

Microlensing wins when the question is "how do we find planets we could never transit-detect" - the method works even for planets on wide orbits around stars that never happen to eclipse from Earth's viewpoint, and the event's brightening shape is unique to this technique.


Where Transit wins

Transit wins when the question is about the planet's own size - transit depth follows (Rplanet/Rstar) squared, so it directly compares planet radii, which the microlensing brightness curve does not show at all.


A reasonable rule

As a reasonable rule, use Transit first to build intuition for how a planet's size sets a simple dip depth, then use Microlensing to see a completely different detection signature - a brightening curve with an optional short planetary spike, not a dip.
