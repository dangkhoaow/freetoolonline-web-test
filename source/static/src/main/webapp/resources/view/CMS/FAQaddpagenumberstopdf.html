Frequently Asked Questions

What does Add Page Numbers to PDF do?

Add page numbers to every page of a PDF, right in the browser.

When should I reach for add page numbers to pdf?

Applies one fixed bottom-center style and numbering sequence - does not support custom position, custom text/format, skipping a numbered cover page, or restarting the count partway through the document.

What complementary tools work well alongside add page numbers to pdf?

To split, merge, rotate, delete pages from, or watermark the PDF instead, see the related-tools section.

What if I leave the starting number blank or type something invalid?

The starting number defaults to 1 and never crashes on bad input - if the box is left blank or you type a value below 1, add page numbers to PDF clamps it back to 1 before numbering the first page.

Can I number more than one PDF at once?

No - add page numbers to PDF takes one PDF at a time. Upload a single file, choose the starting number, and download the numbered copy before repeating the steps for another document.
