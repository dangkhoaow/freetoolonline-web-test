Level 13

Last reviewed: 2026-08-01
freetoolonline.com editorial team

Level 13 is a text-based survival incremental that runs entirely in the browser tab: explore a ruined underground City sector by sector, scavenge resources, build up a home camp, and slowly rebuild lost technology. Press Play to start.

How it plays: every action - move, scavenge, build, craft, fight - is a click or a tap. There is no keyboard shortcut scheme to learn, so the game plays the same on a phone touchscreen as on a desktop mouse.

A tech tree slowly unlocks new tools and buildings (workshops, greenhouses, hospitals) as you find blueprints and spend scavenged resources; progress compounds the longer a single run goes. Each new game generates a unique underground map from a random seed, and only that seed needs to be kept between sessions - not the whole map.

Progress autosaves in this browser roughly every 2 minutes, with a manual save option and multiple save slots so more than one run can be kept side by side. There is no account and no server, so clearing this browser's site data erases the save.

The game is about 8 MB - the engine, audio, and images - downloaded once from this site and then cached; no other network calls follow (the upstream game's visitor counter and error tracker were removed for this hosting).

Level 13 runs on the open-source Level 13 engine (Apache-2.0) by nroutasuo - the game's own in-app credits and changelog ship unchanged.
