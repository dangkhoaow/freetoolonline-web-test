The hidden text only survives inside a lossless PNG, because the message lives in the least-significant bit of each pixel; save the result as JPEG or any compressed format and those bits are gone. That is also why the hide and reveal math runs entirely on image-tools/steganography.html rather than on this page - the tool reads and writes the pixel data in your browser, so the cover image and the message never pass through a server, and the PNG it hands back is the only copy still carrying the note.
