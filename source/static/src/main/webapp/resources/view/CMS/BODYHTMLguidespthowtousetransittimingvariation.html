Como Usar o Explorador 3D de Variação do Tempo de Trânsito (TTV) - Passo a Passo

Última revisão: 2026-08-14

Abra o Explorador 3D de Variação do Tempo de Trânsito (TTV), escolha um dos três sistemas Kepler reais, percorra quarenta trânsitos com o controle deslizante ou com "Play transits", e pressione "Reveal hidden planet" para ver o segundo mundo que a oscilação de tempo indica.


Escolha um sistema real

Pressione "Kepler-19b + 19c", "Kepler-9b + 9c" ou "Kepler-36b + 36c" para carregar os períodos orbitais reais e os fatos publicados de TTV daquele sistema na cena e no painel de fatos.


Percorra ou reproduza os trânsitos

Arraste o controle deslizante "Scrub transits" para saltar direto para qualquer um dos quarenta trânsitos, ou pressione "Play transits" para percorrê-los automaticamente - observe o marcador brilhante no anel orbital interno subir (adiantado) ou descer (atrasado) em relação ao anel cinza "esperado", enquanto o gráfico em faixa abaixo traça o mesmo desvio.


Leia o gráfico em faixa

O gráfico em faixa marca o desvio de tempo de cada trânsito até o atual; o trânsito atual recebe um ponto maior, e o painel informa se esse trânsito ocorreu adiantado, atrasado ou no horário.


Revele o planeta oculto

Pressione "Reveal hidden planet" para mostrar o segundo planeta e seu anel orbital - o mundo para o qual a oscilação de tempo aponta, mas que o planeta em trânsito, por si só, nunca revela.


Arraste para orbitar e use a tela cheia

Arraste para orbitar a câmera, use a roda do mouse ou o gesto de pinça para dar zoom, e use o botão de Tela Cheia para expandir toda a moldura para uma visão mais clara.
