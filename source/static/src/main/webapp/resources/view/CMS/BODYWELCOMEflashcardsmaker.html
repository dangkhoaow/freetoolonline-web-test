Flashcards (Spaced Repetition)

Last reviewed: 2026-09-04

Study a stack of flashcards you build yourself, right in this browser - no sign-in, no app to install.


Key features

  • Build a deck by hand: adding a card needs both a question (front) and an answer (back). Leave either side blank and the tool shows an inline message next to the input instead of adding a half-empty card or throwing an error.
  • A card you just added lands at the very top of the management list, not the bottom, so it is always the first one you see.
  • Study one card at a time: mark it "I knew it" to set it aside for this pass, or "Still learning" to keep it in the queue.
  • Shuffle randomizes the study order but only reorders the cards you have not yet marked known; cards you already knew stay set aside.
  • Turn pasted notes into question-and-answer card drafts - the same box also works as a quiz-question generator for any text you paste.

How reviewing a card works

"Still learning" does not show the same card again right away - it moves to the end of the current queue, so a study pass spreads your weaker cards out instead of repeating one back-to-back.

The management list below the Study box is kept deliberately plain: each row shows only the card's front (question) text plus, once that card has been marked known during a study pass, a small green "Known" tag next to it. There is no back-of-card preview and no known/unknown toggle in that row - flipping a card or marking it known or still learning only happens from the Study box above. The one working control on a management row besides that read-only tag is Delete.


Turning pasted notes into card drafts

The "Turn notes into card drafts" box takes pasted study text and proposes question-and-answer cards. Nothing you paste is sent anywhere. Without an AI model, drafts come from plain in-page extraction: "Term: definition" lines become "What is Term?" cards, "X is Y" sentences become questions, and other informative sentences become fill-in-the-blank cards. If your browser ships built-in AI that is already installed on this device, the tool uses it automatically for better-worded questions - it never triggers a model download on its own. You can also load an optional on-device language model: the picker shows each model's one-time download size before anything starts, and the weights are cached by this browser and shared with the other AI tools on this site, so later loads cost nothing.

Drafts are suggestions, not finished cards. A small on-device model can word a question awkwardly, pick a minor fact, or get a detail wrong - review each draft before adding it. Every draft has its own Add to deck button; Add all skips any draft whose front text already matches a card in the deck, and both sides of a draft respect the same 500-character limit as hand-typed cards. Working from a long chapter or article? Condense it with the text summarizer first, then paste the summary here to draft cards from it.


Where your cards are stored

Cards are saved in this browser via local storage, so they survive a page reload; export a backup (JSON) before clearing browser data or switching devices, since neither is synced automatically.
