Sign PDF (Add Signature)

Last reviewed: 2026-08-31

Place a signature image onto a PDF page, right in the browser.

Places one signature image on one page at a fixed corner - does not draw freehand on the PDF, does not fill AcroForm signature fields, and does not cryptographically certify or lock the document.

The files are processed in this browser tab and are never uploaded to a server.

To draw a signature as a PNG first, use the signature pad tool; to stamp text on every page, use the watermark tool.

How the signature is sized and placed

Sign PDF (Add Signature) does not stamp your image at its original pixel size. The width is capped at whichever is smaller: 180 points (about 2.5in), or 35% of the target page's own width - and the height scales by that same ratio, so the shape is never stretched or squashed. On a standard US Letter page (8.5in / 612pt wide), the 35% rule alone would allow about 2.97in, but the smaller 180-point cap wins, so the signature tops out at 2.5in wide there. On a narrower page - a half-size document at 5.5in / 396pt wide, for example - 35% of the width works out to about 1.9in, which is smaller than the 180-point cap, so the narrower page's own width becomes the limit instead. A signature that is already smaller than whichever cap applies is placed at its own native size; the tool only ever shrinks an oversized image, it never enlarges a small one. Whichever corner you pick - bottom right (the default), bottom left, top right, or top left - the image sits a fixed 24-point margin in from that corner's edges, so it never touches the page boundary.

Sign PDF vs. Signature Maker vs. Add Watermark to PDF

These three tools sound similar but do different jobs, and picking the wrong one wastes a round trip:

ToolInputWhat it stamps, and where
Sign PDF (this tool)An existing PDF + a PNG/JPG signature image you already haveThat image on ONE page you choose, at one of four fixed corners
Signature MakerA freehand mouse/touch/pointer drawingNothing on a PDF - it downloads the drawing itself as a PNG (opaque white or transparent background)
Add Watermark to PDFTyped text, not an imageThe SAME text on EVERY page, diagonal, gray, semi-transparent

In short: use Signature Maker first if you need to create the signature image itself; use this tool once you already have a signature image and want it on one specific page; use Add Watermark to PDF instead when the goal is marking a whole document (for example "DRAFT") rather than adding a personal signature.
