Pulsar Timing Array 3D Explorer vs alternativas

O Pulsar Timing Array 3D Explorer calcula a correlação real de Hellings-Downs em tempo real para qualquer ângulo, direto no navegador - o próprio detector do LIGO vence para uma medição real de ondas gravitacionais em quilohertz; livros de astrofísica vencem pela derivação matemática completa.
