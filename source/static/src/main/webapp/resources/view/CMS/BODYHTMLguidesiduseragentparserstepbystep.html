User Agent Parser - Langkah demi Langkah

Last reviewed: 2026-07-24

User Agent Parser berjalan dalam tiga langkah: buka alat, masukkan input Anda, lalu salin hasilnya. Halaman ini menjelaskan apa yang diharapkan pada setiap langkah.


Langkah 1 - buka alat

Buka User Agent Parser. Tidak perlu memasang apa pun atau masuk akun sebelum mulai.


Langkah 2 - masukkan input Anda

Tempel string User-Agent apa pun ke kolom kiri, atau biarkan kosong agar alat ini otomatis membaca User-Agent browser Anda sendiri. Klik tombol untuk menguraikannya.


Langkah 3 - salin hasilnya

Kolom kanan akan terisi dengan nama dan versi browser, mesin render, sistem operasi, dan kelas perangkat, diikuti string mentah aslinya. Gunakan tombol Copy Output untuk menyalin ke clipboard. Semua ini terjadi secara lokal di browser Anda - tidak ada yang Anda tempel dikirim ke server.

Semuanya berjalan secara lokal di peramban - tanpa unggah dan tanpa akun.
