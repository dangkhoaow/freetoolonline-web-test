Quando Usar o Explorador 3D de Lente Gravitacional Forte - Melhores Sessões e Limites

Última revisão: 2026-07-25

Abra o Explorador 3D de Lente Gravitacional Forte quando quiser ver como o alinhamento entre uma fonte de fundo e uma lente em primeiro plano transforma um único objeto em várias imagens ou longos arcos - não para consultar o modelo de massa exato medido de um objeto específico.


Um padrão guiado pelo alinhamento, não uma única imagem fixa

Uma sessão começa escolhendo o caso da Cruz de Einstein para ver 4 imagens pontuais em torno de uma galáxia em primeiro plano no desvio para o vermelho 0,0394 lenteando um quasar no desvio para o vermelho 1,695, depois alternando para o caso Abell 2218 para ver dezenas de arcos de galáxias de fundo em desvios para o vermelho de até cerca de 2,5 - arrastar o controle deslizante de alinhamento em qualquer caso esmaece as imagens extras ou encurta os arcos.


Sessões que este explorador não atende

Sessões que esta página não atende são consultar um modelo de lente resolvido numericamente para a distribuição de massa exata de qualquer objeto, ou o caso simétrico especial em que o alinhamento é exato e as imagens se fundem em um único anel completo - esse caso está no Explorador 3D do Anel de Einstein. Percorra os controles no guia passo a passo.
