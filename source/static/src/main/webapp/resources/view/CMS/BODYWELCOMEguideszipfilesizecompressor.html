Loose files or a whole folder, and removing the password later

You do not have to collect everything into a folder first: the upload zone at /zip-file.html accepts individual files selected together from the same file picker just as readily as it accepts a whole folder, so a few documents scattered around your machine can go straight into one archive. That flexibility matters when the pieces you want to send never lived in the same place to begin with - selecting the files by hand saves you the busywork of making a throwaway folder just to feed the tool. If you add a password while bundling and later need to hand the archive to someone who should not have to type it, you can strip that password afterward at /remove-zip-password.html instead of rebuilding the .zip from scratch. As a rule of thumb, reach for a folder when the files already sit together and you want them archived as-is, and reach for the multi-file selection when they are spread out and you only need them gathered. Either route produces the same archive, so the choice comes down to what is already on hand rather than to any difference in the result.

What actually shrinks, and by how much, once the folder is inside the archive

Whatever you hand the tool at /zip-file.html - a few loose files or a full folder - the size you get back depends far more on the content than on any option you set. A folder of text-shaped payloads such as server logs, source code, CSV exports, or JSON dumps is where the archive earns its keep, because those files are dense with repeated tokens the DEFLATE algorithm inside ZIP can fold away, and a bundle like that routinely drops 60-90%. The same run over holiday photos or a downloaded video barely moves the needle: a JPEG, a PNG, and an H.264 MP4 are already compressed at the codec level, so DEFLATE finds almost no redundancy left to remove and trims only the small amount of directory overhead around each file. That contrast is the practical rule of thumb - if your total is dominated by already-compressed media, expect a few percent at most, and if it is dominated by text you can plan on the archive landing at a fraction of the original. When the input is mixed, the text portion carries the win while the media portion rides along near its original weight, so the final figure settles somewhere between those two extremes.
