Signature Maker - Schritt Für Schritt

Last reviewed: 2026-07-25

Signature Maker läuft in drei Schritten ab: Tool öffnen, Unterschrift zeichnen, dann Datei herunterladen. Diese Seite zeigt, was jeder Schritt bedeutet.


Schritt 1 - Tool öffnen

Gehe zu Signature Maker. Vor dem Start muss nichts installiert oder angemeldet werden.


Schritt 2 - Unterschrift zeichnen

Wähle eine Stiftfarbe und -breite, dann unterschreibe im Feld mit Maus, Finger oder Stift. Nutze Rückgängig, um den letzten Strich zu entfernen, oder Löschen, um neu zu beginnen, falls es nicht passt.


Schritt 3 - Ergebnis herunterladen

Klicke auf PNG herunterladen. Behalte den weißen Hintergrund für Dokumente, oder aktiviere zuerst die Option für transparenten Hintergrund, um die Unterschrift über anderen Inhalten einzufügen.

Alles läuft im Browser - kein Upload, kein Konto, und die Zeichnung wird nirgendwohin gesendet. Beim Neuladen oder Verlassen der Seite wird die Zeichenfläche gelöscht, also lade herunter, bevor du wegnavigierst.
