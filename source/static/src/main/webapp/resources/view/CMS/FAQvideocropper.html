Frequently Asked Questions

Is my video uploaded to a server?

No. The browser reads the file from your device, crops every frame inside the tab and keeps the result in the tab's memory until you download it. The only downloads are the tool's own code files from freetoolonline.com.

Does the crop apply to the whole video?

Yes - every frame, from start to end, is cut to the same rectangle. The box stays where you put it; it does not track a moving subject. To keep only part of the running time as well, cut the length first with the video trimmer, or use the video merger, which trims and crops each clip when you join two or more.

How do I crop a landscape video to 9:16 or to a square?

Pick "9:16" or "Square" under "Shape". The largest box of that shape appears in the middle of the picture; drag it sideways to frame the subject, then press "Crop video". A 1920 x 1080 video gives a 608 x 1080 file for 9:16 and a 1080 x 1080 file for Square.

Why is the saved size one pixel smaller than my crop?

Video encoders need an even width and height, so an odd number is rounded down by one pixel - a 405 x 720 crop is saved as 404 x 720. "Size" can also shrink the result on purpose; it never enlarges a small crop.

Which files can I open, and what do I get back?

MP4, MOV, WebM, MKV and most other videos your browser or the compatibility engine can read. You get MP4 (H.264) or WebM (VP9 or AV1, or VP8 on Auto) - the line above "Crop video" names the exact format, size and sound before you start. Compatibility mode always makes MP4 (H.264).

Does it keep the sound?

Yes, unless you choose "Remove the sound". The sound is copied unchanged when the new file type can carry it - AAC or MP3 into MP4, Opus or Vorbis into WebM - and is re-encoded to AAC or Opus otherwise.

Why does the preview show still frames instead of playing?

The browser cannot play that file type itself, so the preview shows single frames that follow the slider. The crop works the same, and the cropped file usually plays everywhere because it is saved as MP4 or WebM.

Is there a watermark or a length limit?

There is no watermark, account or sign-up. There is no fixed length limit either, but the new file is built in the tab's memory, so a very long or very large video can run out of memory on a phone; a smaller "Size" helps.
