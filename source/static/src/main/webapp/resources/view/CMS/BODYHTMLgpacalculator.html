Add a course, pick a letter grade, and enter the credit hours - the weighted GPA updates as you type.

The starting rows are just examples; edit or remove them and add your own courses with the "+ Add course" button.

Change any grade or credit-hour value at any time and the weighted GPA, total credit hours, and total quality points all recalculate immediately - there is no separate "calculate" button to press.

If every course is removed, the tool shows a prompt to add one instead of a wrong or empty result.

For a field-by-field walkthrough, see the GPA calculator step-by-step guide.
