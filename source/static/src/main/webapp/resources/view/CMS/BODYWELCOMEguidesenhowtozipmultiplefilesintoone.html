Do the actual zipping with the ZIP file tool: drop in all the files at once, or a whole folder, then click Zip to bundle them into one archive that keeps your original folder structure intact for whoever opens it.

Which compression level to pick

Match the compression level to what is inside the archive. The tool offers three levels; the table below shows what each one is best for.

Compression levelBest forResult
Store (0)Files already compressed (MP4, JPG, HEIC)Fastest; size drops only 0-5%
Default (6)A mix of documents and mediaBalanced speed and size
Best (9)Mostly text, code, or PDFsSmallest ZIP; slower on large input

Keep the ZIP under the email attachment limit

If you are emailing the bundle, size the ZIP to your recipient's mail service. The values below are the common per-message attachment ceilings - stay under them, or share a download link instead.
