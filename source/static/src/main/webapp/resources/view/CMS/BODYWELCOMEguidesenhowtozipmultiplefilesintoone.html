Do the actual zipping with the ZIP file tool: drop in all the files at once, or a whole folder, then click Zip to bundle them into one archive that keeps your original folder structure intact for whoever opens it.

Which compression level to pick

Match the compression level to what is inside the archive. The tool offers three levels; the table below shows what each one is best for.

Compression levelBest forResult
Store (0)Files already compressed (MP4, JPG, HEIC)Fastest; size drops only 0-5%
Default (6)A mix of documents and mediaBalanced speed and size
Best (9)Mostly text, code, or PDFsSmallest ZIP; slower on large input

How the archive is built on your own device

Because the bundling runs inside the page on your own machine, the files you add never travel to a server and nothing has to be installed before you begin, which keeps sensitive paperwork off anyone else's disk. Before you download, type a name for the finished archive in the output-name field instead of accepting the generic default, so a bundle saved as tax-2026.zip tells the recipient what it holds at a glance. There is no fixed limit on how many items you can add in a single pass - the practical ceiling is your device's available memory, so a hundred small receipts collapse into one archive in about a second while several gigabytes of raw video hold the tab busy noticeably longer. If dragging a batch onto the page is awkward, the same picker also lets you click to browse and add files one at a time. When the archive is ready, it saves straight to your usual downloads location, ready to attach or hand off.
