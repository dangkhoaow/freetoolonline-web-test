Subnetzrechner (IPv4 CIDR) - Wann Verwenden

Last reviewed: 2026-07-24

Der Subnetzrechner (IPv4 CIDR) lohnt sich immer dann, wenn Sie Netzwerkmathematik statt Alltagsmathematik brauchen. Diese Seite behandelt, wann das passt und wann nicht.


Wann es passt

Verwenden Sie ihn, wenn Sie IP-Adressbereiche planen, prüfen, ob zwei Adressen im selben Subnetz liegen, oder einen CIDR-Block überprüfen, bevor Sie einen Router, eine Firewall oder eine Cloud-VPC konfigurieren. Er behandelt auch die Sonderfälle /31 Punkt-zu-Punkt und /32 Einzelhost korrekt, funktioniert also auch dafür.


Wann es nicht passt

Wenn Sie alltägliche Prozentrechnung brauchen (ein Rabatt, ein Steueraufschlag, eine Note, eine prozentuale Änderung), greifen Sie stattdessen zum Schwesterwerkzeug, dem Prozentrechner - dieses Werkzeug versteht nur IPv4-Adressen und CIDR-Präfixe.


Was zu erwarten ist

Die Berechnung läuft lokal im Browser - kein Upload und kein Konto. Ändern Sie die Adresse oder das Präfix und jeder Wert wird live aktualisiert.
