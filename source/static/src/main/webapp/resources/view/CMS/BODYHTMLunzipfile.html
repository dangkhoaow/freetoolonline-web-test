How to extract a ZIP archive. Upload your ZIP file using the button above. The tool unpacks it and lists the contents - click any file to download it individually. Password-protected archives prompt for the password before extraction; the working copy is removed from the processing service after the response. For archives that will not open, the most common cause is an unusual compression method (LZMA or BZIP2 outside the standard DEFLATE spec) - re-create the archive with default settings on the sending end.
