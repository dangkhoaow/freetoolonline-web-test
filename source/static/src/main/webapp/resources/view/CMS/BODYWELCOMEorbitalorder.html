How the electron fill order works

The puzzle is built on the Aufbau principle: an electron settles into the lowest-energy orbital that still has room before any higher one begins to fill. That is why the inner 1s shell takes its two electrons first, then the 2s shell, and only then the roomier 2p shell. The blue s-electrons belong to those inner, earlier-filling shells, while the orange p-electrons belong to the outer shell that fills last - so seating them in that order is what keeps each atom building up cleanly as you climb toward oxygen.
