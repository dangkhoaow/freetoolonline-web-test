Wann sich ein Is-It-Down-Check lohnt - Echte Fälle

Zuletzt geprüft: 2026-08-21

Ein 10-Sekunden-Blick auf den Is-It-Down-Checker klärt die älteste Reflexfrage des Webs: Ist die Website down, oder liegt es nur an mir? Die Prüfung läuft vom eigenen Gerät - eine direkte Browser-Anfrage an die Website, ohne Drittanbieterdienst - und in diesen Momenten zahlt sie sich aus.


Eine Social-Plattform wirkt tot

Wenn Instagram, Facebook oder X nicht mehr laden, antworten die sieben Karten beliebter Websites oben auf einen Blick - jede Karte wird beim Laden zu Reachable mit Antwortzeit oder zu einem ehrlichen Nicht-erreichbar-Hinweis, ganz ohne Tippen. Ist die Karte der Plattform von Ihrem Gerät aus Reachable, ist die Ausfall-Schlagzeile womöglich nicht Ihr Problem - Ihre Sitzung oder App ist der nächste Verdächtige.


Nur eine Website scheitert, alles andere läuft

Adresse eingeben, Check drücken. Not reachable ist ehrlich mehrdeutig - die Website kann down sein, oder Ihr Netzwerk, DNS oder Werbeblocker blockiert sie, oder die Website verweigert seitenübergreifende Prüfungen - deshalb nennt die Karte alle drei Ursachen. Der entscheidende Zug ist ein zweites Netz: Lädt die Website über Mobilfunkdaten, aber nicht über WLAN, war die ganze Zeit Ihr Netzwerk der Blocker.


Die Website ist "oben", aber Ihre Seite wirft weiter Fehler

Ein Reachable-Ergebnis mit Antwortzeit beweist, dass der Server Ihrem Gerät auf Netzwerkebene geantwortet hat. Scheitert Kasse, Login oder eine bestimmte Seite weiterhin, liegt der Fehler hinter der Eingangstür - eine Funktion, eine Sitzung oder Ihr Konto. Hart neu laden, die Cookies der Website löschen oder ein privates Fenster probieren, bevor Sie den Router anfassen.


Wo dieser Check endet

Dies ist ein "Down für MICH"-Check: genau ein Beobachtungspunkt, Ihr Gerät. Er sieht keine HTTP-Statuscodes und keinen Seiteninhalt (die seitenübergreifende Browser-Prüfung ist opak), führt keine Ausfallhistorie und behauptet nie, eine Website sei für alle down. Für Bestätigung im großen Maßstab kombinieren Sie ihn mit einer Störungsmeldeseite - der Vergleichsguide zeigt, was jede Quelle sagen kann und was nicht.
