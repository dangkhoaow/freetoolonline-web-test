Reorder & Organize PDF Pages

Last reviewed: 2026-07-22

Put the pages of a PDF into a new order, right in the browser.


How reordering works

The output lists every original page in the sequence you type, so the reordering follows three simple rules:

  • Enter every original page number exactly once - the new order is the sequence you give.
  • Pages are reordered only; none are added, duplicated, or dropped.
  • To also remove pages, run the delete-pages tool first, then reorder what is left.

Private, in your browser

The reordered PDF is assembled entirely inside this browser tab - it is built from a local object URL on your own device and is never uploaded to a server.

The result is written as a downloadable blob in the browser with no server round-trip, so the file stays on your device from start to finish.
