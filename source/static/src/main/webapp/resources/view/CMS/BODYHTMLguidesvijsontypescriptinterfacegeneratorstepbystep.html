Json To Typescript Interface Generator Hướng Dẫn Từng Bước

Last reviewed: 2026-07-20

JSON to TypeScript Interface Generator gồm ba bước: mở trang, dán JSON, copy TypeScript đã tạo.


Bước 1 - mở công cụ

Vào JSON to TypeScript Interface Generator. Không cần cài đặt hay đăng nhập.


Bước 2 - dán JSON

Dán JSON hợp lệ vào ô bên trái. Gốc object hoặc array đều được. Ví dụ: {"id": 1, "name": "Ada", "tags": ["dev"]}.


Bước 3 - tạo và copy

Bấm JSON to TypeScript Interface Generator. Ô bên phải hiện export interface và alias export type. Dùng Copy Output để copy.

JSON không hợp lệ hiện lỗi parse thay vì interface.
