Cómo Usar el Explorador 3D de Variación del Tiempo de Tránsito (TTV) - Paso a Paso

Última revisión: 2026-08-14

Abre el Explorador 3D de Variación del Tiempo de Tránsito (TTV), elige uno de los tres sistemas Kepler reales, recorre cuarenta tránsitos con el control deslizante o con "Play transits", y pulsa "Reveal hidden planet" para ver el segundo mundo al que apunta la oscilación de tiempo.


Elige un sistema real

Pulsa "Kepler-19b + 19c", "Kepler-9b + 9c" o "Kepler-36b + 36c" para cargar en la escena y en el panel de datos los períodos orbitales reales y los datos de TTV publicados de ese sistema.


Recorre o reproduce los tránsitos

Arrastra el control deslizante "Scrub transits" para saltar directamente a cualquiera de los cuarenta tránsitos, o pulsa "Play transits" para recorrerlos automáticamente - observa cómo el marcador brillante del anillo orbital interno sube (adelantado) o baja (retrasado) respecto al anillo gris "esperado", mientras la gráfica de abajo traza el mismo desvío.


Lee la gráfica de franja

La gráfica de franja marca el desvío de tiempo de cada tránsito hasta el actual; el tránsito actual recibe un punto más grande, y el panel indica si ese tránsito llegó adelantado, retrasado o a tiempo.


Revela el planeta oculto

Pulsa "Reveal hidden planet" para mostrar el segundo planeta y su anillo orbital - el mundo al que apunta la oscilación de tiempo pero que el planeta en tránsito, por sí solo, nunca revela.


Arrastra para orbitar y usa la pantalla completa

Arrastra para orbitar la cámara, usa la rueda del ratón o el gesto de pinza para hacer zoom, y usa el botón de Pantalla Completa para expandir todo el marco y obtener una vista más clara.
