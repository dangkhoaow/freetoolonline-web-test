Quando Usar o Explorador 3D do Diapasão de Hubble

Última revisão: 2026-08-13

Abra o Explorador 3D do Diapasão de Hubble quando quiser uma resposta prática sobre como os astrônomos classificam formas de galáxias em elíptica, lenticular, espiral normal e espiral barrada - e como uma galáxia real e nomeada, como a Via Láctea, se encaixa nesse sistema.


Sessões para as quais este explorador é indicado

Estudantes e professores introduzindo tipos de galáxias por primeira vez, leitores que querem saber se a Via Láctea é uma espiral "normal" ou "barrada", qualquer pessoa curiosa sobre o que E0 até E7 realmente significam, e anfitriões de noites de quiz que querem uma atividade divertida e com fontes de "adivinhe a galáxia real" recebem uma resposta direta aqui.


Sessões para as quais este explorador não é indicado

Sessões para as quais esta página não é indicada são estudar a estrutura interna e a escala de uma galáxia espiral específica em profundidade, o que está no Simulador 3D de Galáxia - aquela página renderiza os braços espirais e a contagem de estrelas de uma galáxia, não o sistema de classificação que ordena todos os tipos de galáxias. Percorra os controles no guia passo a passo.
