Time Zone Converter is one of three common ways to do this: a browser-based tool like this one, a desktop calendar/clock application, or a search-engine "time in" answer box. Each trades off differently on precision and setup.

The main advantage of a browser-based converter over a desktop app is zero setup - it works the moment the page loads, on any device with a browser. The main advantage over a search-engine answer box is that it converts a specific date and time you choose, not only the current moment.
