Batas file 4 GiB FAT32 - kenapa video besar gagal di USB

FAT32 masih jadi format bawaan di banyak USB stick dan kartu SD, dan menolak setiap file lebih besar dari 4 GiB kurang 1 byte (4,294,967,295 byte), meski stick masih menunjukkan ruang kosong - video 4.7 GB tetap gagal disalin. Solusi andal adalah format ulang ke exFAT atau NTFS, atau pecah payload jadi bagian lebih kecil dengan alat ZIP file.

Apa yang terjadi

Tabel perbandingan sistem file Microsoft mencantumkan ukuran file maksimal FAT32 sebagai 4 GiB. Plafon itu datang dari field panjang file 32-bit di entri direktori FAT, jadi ukuran legal terbesar adalah 2^32 - 1 byte. Volume bisa jauh lebih besar; plafon per-file terpisah dari ruang kosong yang dilaporkan stick. exFAT dan NTFS keduanya mengiklankan ukuran file teoritis maksimal 2^64 - 1 byte di tabel yang sama, jadi format ulang stick yang sama biasanya membuat salinan berhasil.

Dicek terhadap Microsoft Learn (File System Functionality Comparison) dan dokumentasi keluarga FAT pada 18 July 2026:

Sistem fileUkuran 1 file maksimalPemakaian USB tipikal
FAT324 GiB - 1 byteDefault di banyak USB murah dan kartu kamera
exFAT2^64 - 1 byte (praktis tanpa batas untuk media)USB / SD file besar lintas platform
NTFS2^64 - 1 byteDrive eksternal Windows

Batas ini ada sejak desain FAT32 di pertengahan 1990-an. Masih menusuk di 2026 karena retailer tetap mengirim USB berformat FAT32 demi kompatibilitas maksimal, sementara file sehari-hari - video 4K, ISO Windows, installer game - rutin melebihi 4 GiB.


Kenapa ini penting untuk file sehari-hari

Pesan error sering bilang stick penuh padahal belum. OS menolak satu file terlalu besar, bukan total ruang kosong. Ketidakcocokan itu muncul saat memindah dump kamera, menyalin ISO game untuk teman, atau menyimpan rekaman layar panjang langsung ke USB. Perangkat yang hanya membaca FAT32 (beberapa TV, stereo mobil, kamera lama) tidak bisa membaca stick exFAT atau NTFS tanpa format ulang, jadi pilihan format adalah trade-off antara dukungan file besar dan kompatibilitas putar terluas.


Apa yang dilakukan dengan file Anda sekarang

Jika salinan gagal sekitar tanda 4 GiB pada stick yang masih punya ruang kosong, opsi berikut menutup kasus umum:

  • Pecah payload jadi bagian ZIP di bawah 4 GiB. Alat ZIP file bisa mengemas folder besar jadi archive yang bisa dicek ukurannya sebelum salin USB.
  • Ekstrak archive di drive penuh dulu. Alat unzip file dan panduan ekstrak ZIP RAR 7Z menjaga langkah expand jauh dari stick terbatas.
  • Format ulang stick ke exFAT bila setiap perangkat di jalur mendukungnya. Itu menghapus plafon 4 GiB sambil tetap dipakai di Windows, macOS terkini, dan banyak kamera.
  • Pakai NTFS bila stick hanya untuk workflow Windows. Headroom file besar yang sama; dukungan lebih lemah di TV terkunci dan beberapa konsol.

Kenapa Windows 11 tidak mau memformat drive besar ke FAT32

Klik kanan drive di File Explorer, pilih Format, dan Windows 11 hanya menampilkan FAT32 sebagai pilihan untuk volume hingga 32 GB - di atas ukuran itu dropdown cuma menawarkan NTFS dan exFAT. Plafon 32 GB itu datang dari dialog Format Windows sendiri dan alat baris perintah format, bukan dari sistem file FAT32 itu sendiri, yang bisa mengalamatkan volume hingga 2 TB. Formatter FAT32 pihak ketiga bisa melewati batasan GUI Windows dan membuat volume FAT32 lebih besar, tapi plafon per-file 4 GiB yang terpisah di atas tetap berlaku begitu drive sudah diformat - format ulang di atas 32 GB menyelesaikan soal ukuran volume, bukan soal file tunggal.

Frequently Asked Questions

Kenapa Windows 11 tidak menampilkan FAT32 sebagai pilihan saat memformat USB drive besar?

Dialog Format bawaan Windows 11 dan perintah format hanya menawarkan FAT32 untuk volume hingga 32 GB. Itu plafon buatan Windows, bukan batas sistem file FAT32 sendiri yang bisa mengalamatkan volume hingga 2 TB; di atas 32 GB, Windows hanya menampilkan NTFS dan exFAT.

Berapa ukuran file maksimal FAT32 dalam byte?

4,294,967,295 byte, yaitu 4 GiB dikurangi 1 byte. Entri direktori FAT menyimpan panjang setiap file di field 32-bit, jadi 2^32 - 1 byte adalah nilai terbesar yang bisa ditampung field itu.

Apakah format ulang USB stick ke exFAT akan menghapus file saya?

Ya. Memformat drive ke exFAT, NTFS, atau sistem file lain menghapus struktur direktori yang ada, jadi backup semua file penting sebelum format ulang.

Kenapa kamera dan dash cam masih pakai FAT32 kalau batas ukuran filenya kecil?

Banyak perangkat rekam memakai FAT32 secara default karena itu sistem file yang paling luas didukung di TV lama, stereo mobil, dan konsol game. Produsen menukar plafon 4 GiB per file dengan kompatibilitas itu, yang juga sebabnya sebagian kamera memecah rekaman panjang jadi beberapa file video terpisah.

Apakah macOS atau Linux punya batas 4 GiB FAT32 yang sama seperti Windows?

Ya. Plafon 4 GiB per file adalah bagian dari spesifikasi sistem file FAT32 itu sendiri, bukan batasan khusus Windows, jadi menyalin file lebih besar dari 4 GiB ke drive berformat FAT32 gagal dengan cara yang sama di macOS dan Linux.
