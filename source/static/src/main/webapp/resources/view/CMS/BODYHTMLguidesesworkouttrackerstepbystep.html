Rastreador de Entrenamiento Online - Paso a Paso

Last reviewed: 2026-07-27

Rastreador de Entrenamiento Online funciona en tres pasos: abrir la herramienta, añadir tus elementos y dejar la lista guardada. Esta página detalla qué espera cada paso.


Paso 1 - abrir la herramienta

Ve a Rastreador de Entrenamiento Online. No necesitas instalar nada ni iniciar sesión antes de empezar.


Paso 2 - añade tus elementos

Escribe cada ejercicio y añádelo a la lista; úsalo para una lista rápida cuando no quieras instalar una aplicación ni iniciar sesión.


Paso 3 - la lista queda guardada

Cada elemento recibe una casilla para marcarlo como hecho y un botón para eliminarlo; todo se guarda en este navegador mediante almacenamiento local.
