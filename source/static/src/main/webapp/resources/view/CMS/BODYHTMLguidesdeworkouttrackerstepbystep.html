Online-Trainingstracker - Schritt für Schritt

Last reviewed: 2026-07-27

Online-Trainingstracker funktioniert in drei Schritten: Tool öffnen, deine Einträge hinzufügen, Liste bleibt gespeichert. Diese Seite zeigt, was jeder Schritt erwartet.


Schritt 1 - Tool öffnen

Rufe Online-Trainingstracker auf. Vor dem Start muss nichts installiert oder ein Login erstellt werden.


Schritt 2 - deine Einträge hinzufügen

Gib jede Übung ein und füge sie der Liste hinzu; nutze es, wenn du keine App installieren oder dich anmelden möchtest.


Schritt 3 - die Liste bleibt gespeichert

Jeder Eintrag erhält ein Kästchen zum Abhaken und eine Schaltfläche zum Entfernen; alles wird in diesem Browser über den lokalen Speicher gesichert.
