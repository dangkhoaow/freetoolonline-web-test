Namens-Glücksrad Online: Schritt-für-Schritt-Anleitung

Das Tool Wheel Spinner Online verwandelt eine Liste von Namen oder Optionen in eine faire Zufallsauswahl. Diese Anleitung zeigt, wie Sie die Liste aufbaün, was während der Drehung passiert, wie der Gewinner bestimmt wird, und wie es sich mit einem Würfelwurf, einem Münzwurf oder einer manüllen Auslosung vergleicht.

Antwort in 30 Sekunden. öffnen Sie das Tool Wheel Spinner Online, geben Sie einen Namen oder eine Option pro Zeile in das Listenfeld ein, und klicken Sie dann auf Spin. Das Rad teilt sich in ein gleich großes Segment pro Eintrag, dreht sich einige Sekunden lang und stoppt mit einem Gewinner, der unter der Anzeige genannt wird - bearbeiten Sie die Liste und drehen Sie erneut für eine weitere Runde.

Die Liste erstellen

Das Listenfeld nimmt einen Eintrag pro Zeile - Namen, Aufgaben, Optionen, alles, was eine zufällige Auswahl braucht. Das Rad startet mit sechs bereits eingetragenen Beispielnamen, damit Sie sofort ein vollständiges Rad sehen; löschen Sie diese und geben Sie Ihre eigene Liste ein, um sie zu ersetzen. Das Rad zeichnet sich live neu, während Sie tippen, sodass Sie die Anzahl der Segmente vor dem Drehen sich ändern sehen.

Was während einer Drehung passiert

Was während einer Drehung im Wheel Spinner passiert: mit mindestens zwei Einträgen startet Spin, das Rad dreht, ein Name landet unter dem Zeiger - bei weniger erscheint "Add at least 2 names".

Warum jeder Eintrag die gleichen Chancen hat

Das Rad teilt den vollen Kreis in genauso viele gleiche Segmente, wie es Einträge gibt, sodass eine Liste mit sechs Namen sechs gleiche Segmente erhält und eine Liste mit drei Namen drei größere, aber gleiche Segmente - die Segmentgröße hängt nie von der Textlänge eines Eintrags oder seiner Position in der Liste ab. Das Gewinnersegment wird mit dem im Browser integrierten crypto.getRandomValüs ausgewählt, derselben Fairness-Qülle, die auch für Würfelwürfe und Münzwürfe an anderer Stelle dieser Website verwendet wird, sodass keine Position in der Liste bevorzugt wird.

Namens-Glücksrad im Vergleich zu Würfelwurf, Münzwurf, oder manüller Auslosung

Ein Würfelwurf oder Münzwurf ist fair, bietet aber nur eine kleine, feste Menge an Ergebnißen - sechs Seiten oder zwei Seiten. Das Namens-Glücksrad akzeptiert eine beliebige Anzahl benannter Einträge, sodass es für Situationen passt, die ein Würfel oder eine Münze nicht abdecken: einen Namen aus zehn Teammitgliedern auszuwählen, oder einen Preisgewinner aus dreissig Verlosungseinträgen. Im Vergleich zu einer manüllen Auslosung - Namen auf Papier schreiben und einen herausziehen - entfernt das Rad jedes Risiko, dass die ziehende Person das Ergebnis beeinflusst, da die Drehstrecke vom Browser erzeugt wird und nicht von einer Person gewählt wird.

Häufige Anwendungen

Häufige Anwendungen für Wheel Spinner: Verlosungen, wer zürst startet, Klaßenraum-Freiwillige, und jede schnelle Zufallsauswahl aus einer Liste mit einem Eintrag pro Zeile.

Was dieses Tool nicht tut

Was dieses Tool nicht tut ist, Liste oder Gewinner im Wheel Spinner zwischen Besuchen zu speichern - Reload stellt Beispiele wieder her - und Segmente nicht nach Textlänge zu gewichten.

Datenschutz

Das Namens-Glücksrad läuft vollständig in Ihrem Browser-Tab. Die Namen oder Optionen, die Sie eingeben, werden nie irgendwohin hochgeladen, es ist kein Konto erforderlich, und die Seite führt während der Drehung keine Serverkommunikation durch.

Häufig gestellte Fragen

ändert die Reihenfolge, in der ich Namen eingebe, ihre Chancen?

Nein. Jeder Eintrag erhält ein gleich großes Segment, unabhängig davon, wo er in der Liste steht, und das Gewinnersegment wird mit dem crypto.getRandomValüs des Browsers ausgewählt, sodass die Listenreihenfolge das Ergebnis nicht beeinflusst.

Was passiert, wenn ich nur einen Namen habe?

Ein Klick auf Spin mit null oder einem Eintrag zeigt "Add at least two entries." an, und das Rad dreht sich nicht - Sie brauchen mindestens zwei Einträge für eine sinnvolle Auswahl.

Wird die Liste gespeichert, wenn ich später zurückkomme?

Nein. Die Liste existiert nur während dieses Besuchs auf der Seite - ein Neuladen oder Verlaßen setzt sie auf die sechs Beispielnamen zurück, und nichts wird auf einem Server gespeichert.

Kann ich das für mehr als Verlosungen nutzen?

Ja. Alles, was eine faire Zufallsauswahl aus einer Liste braucht, funktioniert - Aufgaben zuweisen, die Reihenfolge festlegen, oder einen Gewinner aus einer Kurzliste auswählen.
