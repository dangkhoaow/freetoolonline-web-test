Cara menggunakan Penjelajah 3D Lintas Dekat Pluto oleh New Horizons

  1. Buka Penjelajah 3D Lintas Dekat Pluto oleh New Horizons dan tunggu hingga adegan tampil.
  2. Seret untuk memutar tampilan dan gulir untuk memperbesar lintasan dari peluncuran ke Pluto.
  3. Pilih Lintas dekat Pluto untuk lintasan misi utama atau Plus Arrokoth untuk lintasan perpanjangan.
  4. Geser penggeser fase dari 0 ke 99 untuk memindahkan wahana ke titik mana pun pada lintasan.
  5. Tekan Putar untuk menganimasikan seluruh lintasan secara terus-menerus, atau Jeda untuk mempertahankan satu posisi.
