Time Zone Converter - Passo a Passo

Last reviewed: 2026-07-24

Time Zone Converter funciona em três passos: escolher a data, hora e fuso de origem, escolher o fuso de destino, depois ler o resultado convertido. Esta página detalha o que cada passo espera.


Passo 1 - defina a data, hora e fuso de origem

Acesse Time Zone Converter. Os campos de data e hora começam no momento atual, e o menu De-fuso já vem com o fuso que seu navegador reporta. Altere qualquer campo para o momento que você quer converter.


Passo 2 - escolha o fuso de destino

Escolha um fuso no menu Para-fuso. O resultado abaixo atualiza imediatamente - não há um botão separado de "converter" para clicar. Use Swap para inverter os dois fusos no lugar, ou Now para voltar os dois campos ao momento atual.


Passo 3 - leia o resultado

O painel de resultado mostra a leitura do relógio em ambos os fusos lado a lado, além de quantas horas eles diferem naquela data específica (isso pode mudar numa transição de horário de verão). Uma linha de relógio mundial mais abaixo lista a hora atual em várias cidades importantes para uma olhada rápida.
