Cómo Explorar el Explorador 3D de Heliosismología y Oscilación Solar

Última revisión: 2026-07-25

Revisado por Equipo editorial de FreetoolOnline

Abre el Explorador 3D de Heliosismología y Oscilación Solar, observa la superficie ondulante y luego activa el corte interior para ver el límite real medido que este patrón de ondulación ayuda a encontrar a los astrónomos.

  1. Abre /space-3d/helioseismology-sun-oscillation.html y espera a que aparezcan la esfera ondulante y el panel de datos.
  2. Arrastra el control de amplitud de onda para hacer el patrón más fácil o más difícil de ver.
  3. Haz clic en "Next wave pattern" para alternar entre tres patrones de oscilación simplificados.
  4. Haz clic en "Show interior cutaway" para ver un corte transversal con el límite medido de 0,713 radios solares y la tachocline.
  5. Arrastra para orbitar y desliza o pinza para acercar y ver más de cerca.
  6. Lee el panel de datos para conocer el período de oscilación, el número de modos y los límites medidos.
