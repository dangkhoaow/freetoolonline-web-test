Cómo usar el Explorador 3D del Año Galáctico: Órbita del Sol

  1. Abre el Explorador 3D del Año Galáctico: Órbita del Sol y espera a que la escena cargue.
  2. Arrastra para girar la vista y desplázate para acercar el disco espiral y el anillo de órbita.
  3. Elige la vista Desde arriba para ver la órbita como un círculo, o la vista De perfil para ver al Sol subir y bajar por el plano del disco.
  4. Desplaza el control de tiempo transcurrido de 0 a 4.600 millones de años para mover al Sol a cualquier punto desde que se formó.
  5. Pulsa Reproducir para animar el tiempo continuamente, o Pausar para mantener una posición y leer el panel de datos.
