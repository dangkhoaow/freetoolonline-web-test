Como usar o Explorador 3D do Sobrevoo de Plutão pela New Horizons

  1. Abra o Explorador 3D do Sobrevoo de Plutão pela New Horizons e espere a cena carregar.
  2. Arraste para girar a visão e role para dar zoom no trajeto do lançamento a Plutão.
  3. Escolha Sobrevoo de Plutão para o trajeto da missão principal ou Mais Arrokoth para o trajeto estendido.
  4. Arraste o controle de fase de 0 a 99 para mover a sonda para qualquer ponto do trajeto.
  5. Pressione Reproduzir para animar o trajeto completo continuamente, ou Pausar para manter uma posição.
