Was Ein LCD-Test Macht (und Wann Einen Ausführen)

Ein LCD-Test nutzt LCD Test, um den Bildschirm mit Solid-Farben zu füllen und tote Pixel, feststeckende Pixel, Hintergrundbeleuchtungs-Bleeding und Banding-Artefakte aufzudecken. Führe ihn aus, bevor das Rückgabefenster für den neuen Monitor schließt.

30-Sekunden-Antwort. Ein LCD-Test füllt Ihren Bildschirm mit Volltonfarben (Rot, Grün, Blau, Weiß, Schwarz, manchmal Grauschritte), damit Defekte des Panels gegen einen einheitlichen Hintergrund sichtbar werden. Die vier Dinge, die er zuverlässig erkennt: tote Pixel (immer schwarze Punkte), festgesetzte Pixel (immer eine Farbe, unabhängig vom Input), Lichthof (ungleichmäßige Helligkeit nahe der Ränder bei schwarzem Bildschirm) und Banding / Dithering-Artefakte (sichtbare Stufen in einem Verlauf). Führen Sie ihn aus, bevor das Rückgabefenster eines neuen Monitors schließt, bevor Sie einen generalüberholten Bildschirm akzeptieren, oder wann immer Sie einen "komischen Fleck" auf Ihrem Display vermuten. Öffnen Sie das LCD-Test-Werkzeug und gehen Sie die Farben durch.

Was "LCD-Test" wirklich bedeutet

Der Begriff "LCD-Test" ist ein Sammelname für eine kleine Familie von Tests, die unterschiedliche Defektklassen prüfen. Die browserbasierte Version - die diese Anleitung behandelt - ist die häufigste, weil sie nichts kostet, überall läuft und die Defekte erkennt, die einem Käufer am wichtigsten sind. Sie ist nicht die einzige Option (Hersteller fahren in der Fabrik aufwendigere Kalibrierungs-Suites), aber sie ist das, was 99% der Menschen, die "lcd-test" bei Google eingeben, tatsächlich wollen.

Der Mechanismus ist einfach: das Werkzeug füllt den gesamten Bildschirm mit einer Volltonfarbe. Ein perfektes Panel ist ein perfekt einheitliches Feld. Defekte zeigen sich als Abweichungen - ein winziger Punkt anderer Farbe, ein hellerer oder dunklerer Fleck nahe der Ecke, ein Band, das nicht sanft ins nächste übergeht. Das bloße Auge erkennt Abweichungen von der Gleichmäßigkeit gut, also braucht der Test keine Spezial-Hardware, um nützlich zu sein.

Die vier Defekte, die ein LCD-Test erfasst

  • Tote Pixel. Ein Subpixel, das dauerhaft aus ist. In einem roten Feld sieht ein totes Pixel schwarz aus. In einem grünen Feld ebenfalls schwarz. In einem schwarzen Feld ist es unsichtbar. Der Tot-Pixel-Test geht durch Rot, Grün, Blau und Weiß, sodass jedes ausgefallene Subpixel auf mindestens einem Hintergrund auftaucht. Leitfaden zum Tot-Pixel-Test behandelt die Diagnosemuster im Detail.
  • Festgesetzte Pixel. Ein Subpixel, das dauerhaft mit voller Intensität an ist. Ein festgesetztes rotes Subpixel erscheint als heller roter Punkt auf schwarzem Feld, auf blauem Feld und auf weißem Feld. Tot von festgesetzt zu unterscheiden ist wichtig: festgesetzte Pixel lassen sich manchmal durch ein "Pixel-Exerciser"-Video wiederbeleben, das 10-30 Minuten lang schnell die Farben wechselt; tote Pixel sind verloren.
  • Lichthof. Licht, das an den Rändern eines LCD-Panels austritt, wo das Backlight nicht perfekt eingeschlossen ist. Am sichtbarsten auf schwarzem Feld in dunklem Raum - Sie sehen ungleichmäßiges Leuchten nahe der Ecken oder entlang einer Kante. Eine kleine Menge ist auf jedem IPS-Panel normal; viel ist ein Defekt. Die meisten Garantien decken "übermäßig" ab, vom Hersteller mehrdeutig definiert.
  • Banding und Dithering-Artefakte. Ein hochwertiges Panel kann sanfte Verläufe ohne sichtbare "Stufen" rendern. Ein Panel mit begrenzter Farbtiefe (6-Bit statt 8-Bit oder 8-Bit statt 10-Bit) produziert sichtbare Bänder, wenn der Verlauf einen weiten Wertebereich abdeckt. Das Graustufen-Schrittmuster im LCD-Test deckt das auf.

Wann das Ausführen eines LCD-Tests die richtige Entscheidung ist

Fünf Situationen, in denen der Test die zwei Minuten wert ist:

  • Bevor das Rückgabefenster eines neuen Monitors oder Laptops schließt. Die meisten Monitore haben eine 14-30-Tage-Rückgaberichtlinie plus Herstellergarantie. Die Rückgaberichtlinie erlaubt das Umtauschen einer defekten Einheit ohne Nachfragen; die Garantie erfordert oft, dass Sie den Defekt in einem Videoanruf mit dem Support nachweisen. Führen Sie den Test in der ersten Woche aus, solange Sie es noch einfach zurückgeben können.
  • Bevor Sie einen generalüberholten oder B-Ware-Bildschirm akzeptieren. Refurbished-Preise sind attraktiv, aber die Einheit kann ererbte Defekte haben, deretwegen der Vorbesitzer sie zurückgab. Führen Sie den Test am Tag 1 aus.
  • Bevor Sie einen Telefon- oder Tablet-Trade-in behalten. Carrier und Wiederverkäufer versenden gelegentlich Trade-in-Geräte mit verstecktem Bildschirmschaden. Der Pixel-Test bringt es innerhalb des Rückgabefensters des Carriers zum Vorschein.
  • Wenn Sie einen "komischen Fleck" auf einem bereits vorhandenen Display vermuten. Ein Staubkorn auf dem Bildschirm sieht aus einer Armlänge identisch zu einem toten Pixel aus. Der LCD-Test bestätigt, ob es auf der Oberfläche liegt (mit Mikrofasertuch abwischen) oder im Panel (Garantiefall).
  • Bevor Sie mit einem Streaming-, Gaming- oder Design-Rig öffentlich auftreten. Ein Defekt, der auf Ihrem normalen Desktop unsichtbar ist, kann gegen einen Green-Screen-Hintergrund oder eine einheitliche Farbe in einem Videoanruf grell auffallen. Testen Sie das Rig mit den Farben, die Sie tatsächlich übertragen.

Und für die tägliche Nutzung? Wahrscheinlich auslassen - der Test ist für "ist das Panel akzeptabel?", nicht für "ist das Panel perfekt für Color-Grading kalibriert?". Farbkalibrierung ist ein separater Workflow mit separater Hardware (einem Kolorimeter).

So lesen Sie die Testergebnisse

Gehen Sie jede Farbe vollbild 5-10 Sekunden durch, Augen etwa 30-50 cm vom Panel entfernt. Worauf Sie achten:

  • Pixel-Gleichmäßigkeit. Jeder Punkt, der vom Feld abweicht, ist ein Defektkandidat. Notieren Sie seine Position (z.B. "oben links, etwa 3 cm nach innen"). Wiederholen Sie es über alle Farben - ein totes Pixel zeigt sich auf einer Farbe, ein festgesetztes auf drei oder vier.
  • Rand-Gleichmäßigkeit. Auf dem schwarzen Bildschirm im dunklen Raum die vier Ränder absuchen. Gleichmäßiges Glow = OK. Helle Ecken oder Streifen = Lichthof.
  • Sanfte Verläufe. Gehen Sie die Graurampe langsam durch. Sie sollten einen kontinuierlichen Verlauf von Schwarz zu Weiß sehen, keine sichtbaren Stufen.
  • Farbton-Shift beim Blickwinkel. Neigen Sie den Kopf zur Seite. Ein gutes IPS-Panel hält Farben bis ~80 Grad außer-Achse stabil. Ein billiges TN-Panel verschiebt sich schon bei 30 Grad wahrnehmbar. Nützlich vor dem Kauf zu wissen.

Ein oder zwei Pixeldefekte auf einem 4K-Panel (8,3 Millionen Pixel) sind statistisch üblich, und die meisten Garantien decken sie nicht ab. Der Schwellenwert für "defekt" variiert: ISO 9241-307 Klasse II erlaubt bis zu 2 tote und 2 festgesetzte Pixel auf einem 4K-Panel. Darüber zurückgeben.

Warum ein browserbasierter Test genügt

Sie brauchen keine installierte App, um das zu tun. Der Browser kann bereits Vollbild-Volltonfarben rendern, und das ist der einzige Mechanismus, den der Test braucht. Browserbasierte Tests haben drei weitere Vorteile gegenüber installierten Alternativen:

  • Plattformübergreifend. Derselbe Test auf Windows, macOS, Linux, ChromeOS, iPadOS, Android, Smart-TV-Browsern. Keine Treiberkompatibilität, keine Installationsberechtigung, kein Admin-Passwort.
  • Kein Versions-Drift. Die Seite wird zentral aktualisiert; Sie fahren immer die aktuelle Version. Installierte Werkzeuge altern - letzte Aktualisierung vor drei Jahren ist die Norm.
  • Datenschutz. Keine Datei-Uploads, keine Telemetrie über Standard-Webserver-Zugriffslogs hinaus. Der Test ist rein eine Render-Anweisung an Ihren Bildschirm.

Wo browserbasierte Tests zu kurz greifen: Response-Time-, Refresh-Rate- und HDR-Konformitätstests sind im Browser ohne Spezial-Hardware schwerer. Für kompetitives Gaming oder farbkritische Arbeit deckt ein dediziertes Werkzeug (TestUFO, DisplayCAL, Kalibrator-Hardware) diese Lücken ab.

Was der LCD-Test nicht erkennen kann

Nützliche Abgrenzungs-Liste:

  • Farbgenauigkeit / Gamut-Abdeckung. Dafür brauchen Sie ein Kolorimeter.
  • Response-Time / Motion Blur. Dafür brauchen Sie TestUFO oder eine Hochgeschwindigkeitskamera.
  • Refresh-Rate-Stabilität. Dafür brauchen Sie einen Frame-Time-Logger.
  • Genauigkeit der Touch-Eingabe. Dafür brauchen Sie ein separates Touch-Test-Werkzeug.
  • Helligkeits-Gleichmäßigkeit in absolutem cd/m^2. Dafür brauchen Sie ein Luminanz-Messgerät.

Der LCD-Test erfasst die kategorischen Defekte, die ein Panel disqualifizieren; er misst keine Performance-Qualitäten. Für ein komplettes Pre-Call-Kit siehe Geräte-Test-Checkliste für Remote-Arbeit, die Kamera-, Mikrofon- und Tastatur-Tests hinzufügt.

Den Test ausführen

Öffnen Sie freetoolonline.com/lcd-test.html. Der erste Bildschirm erklärt die Steuerung (Leertaste zum Weiterschalten, Esc zum Verlassen des Vollbilds). Gehen Sie durch Rot, Grün, Blau, Weiß, Schwarz und die Graurampe. Notieren Sie jeden Defekt, den Sie entdecken. Ist Ihr Panel sauber, sind Sie in unter zwei Minuten fertig. Finden Sie etwas, entscheiden Sie, ob es für Rückgabe qualifiziert - und beginnen Sie das Gespräch, solange das Fenster offen ist.
