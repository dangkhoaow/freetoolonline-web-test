Wann Sie den Bennu + OSIRIS-REx TAG Sample Return 3D Explorer Nutzen Sollten - Beste Sitzungen Und Grenzen

Zuletzt überprüft: 2026-08-09

Öffnen Sie den Bennu + OSIRIS-REx TAG Sample Return 3D Explorer, wenn Sie ein klares Bild der realen Touch-and-Go-Probenentnahme der NASA von 2020 am Asteroiden Bennu und des überraschenden Oberflächenbefunds "wie ein Bällebad" benötigen, den sie enthüllte - kein Live-Tracker und keine Simulation der Kontaktdynamik.


Eine Lektion zur Probenrückführung

Eine Lektion beginnt mit einem Klick auf "Simulate TAG" und der Beobachtung, wie der Arm der Sonde in die Oberfläche von Bennu einsinkt, gefolgt vom Ablesen der realen Probenmasse, des Rückkehrdatums und der Einschlagsrisiko-Zahlen im Datenfeld.


Sitzungen, für die dieser Explorer nicht geeignet ist

Sitzungen, für die diese Seite nicht geeignet ist, sind eine numerisch integrierte Simulation von Abstieg und Kontakt - die unregelmäßige Form von Bennu ist eine prozedurale Lehrform, und die TAG-Sequenz ist eine geskriptete Zustandsmaschine, die für Klarheit zeitlich abgestimmt ist, kein physikalischer Löser - oder eine Live-Verfolgung von Bennu oder der heute in OSIRIS-APEx umbenannten Sonde. Für die Touch-and-Go-Probenrückführungsmission einer anderen Weltraumbehörde mit ihrem eigenen künstlichen Einschlagskrater nutzen Sie den Hayabusa2-Ryugu Sample Return 3D Explorer; für eine Sonde, die absichtlich in einen Asteroiden einschlug, um die Planetenverteidigung zu testen, nutzen Sie den DART Asteroid Deflection 3D Explorer. Üben Sie die Steuerung in der Schritt-für-Schritt-Anleitung.
