When to use Brown Dwarf 3D Explorer

Use this explorer when you want to see exactly where the real planet/brown-dwarf/star mass lines sit, and why size alone cannot tell them apart.

  • Showing the real 13-Jupiter-mass deuterium-fusion and 80-Jupiter-mass hydrogen-fusion lines
  • Explaining why a heavier brown dwarf is not much bigger (electron-degeneracy pressure)
  • Introducing Teide 1, the first confirmed brown dwarf (1995)

This is an educational visualization with a brightened default glow and a simplified color story - toggle Realistic dim for the fainter, real appearance.
