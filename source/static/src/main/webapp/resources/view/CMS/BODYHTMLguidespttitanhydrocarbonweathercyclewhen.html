Quando Usar o Explorador 3D do Ciclo do Tempo de Metano de Titã

Last reviewed: 2026-08-09

Abra o Explorador 3D do Ciclo do Tempo de Metano de Titã quando quiser ver como o metano se move entre evaporação, nuvens, chuva e acúmulo ao longo de uma estação de Titã, não apenas onde os mares estão.


Sessões para as quais este explorador é adequado

Estudantes que perguntam como o ciclo de chuva de metano de Titã realmente funciona ao longo do tempo, professores explicando a mudança sazonal de nuvens observada pela Cassini e a tempestade equatorial de 2010, e leitores curiosos que querem observar um ano comprimido de clima em vez de apenas ler sobre ele encontram uma resposta direta aqui.


Sessões para as quais este explorador não é adequado

Sessões para as quais esta página não é adequada são querer ver ONDE os mares e o oceano subterrâneo de Titã realmente estão, o que está no Explorador 3D dos Lagos de Metano de Titã; ou precisar de uma simulação atmosférica precisa, já que o movimento das nuvens e o momento das tempestades aqui são uma aproximação didática esquemática, não um modelo de circulação geral. Percorra os controles no guia passo a passo.
