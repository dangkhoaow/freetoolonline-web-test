What to do when a video is too large for the browser

The browser version of FFmpeg reads your whole file into the tab's memory, and a tab tops out near 4 GB with only about 1.5 to 2 GB left once the code has loaded - so a short phone clip converts fine, but long 4K footage or several stitched files run out of room. Local FFmpeg streams the file straight from disk instead of loading all of it into RAM, so it is limited only by your free disk space; when a clip refuses to open in the tab, that is the point to install the native binary and let it work off the drive.
