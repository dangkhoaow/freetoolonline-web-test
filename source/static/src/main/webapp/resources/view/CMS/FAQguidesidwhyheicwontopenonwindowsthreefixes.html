Pertanyaan yang sering diajukan

Mengapa Windows menampilkan foto HEIC saya sebagai gambar mini kosong?

Windows tidak menyertakan codec HEIF secara bawaan, sehingga File Explorer dan aplikasi Photos tidak dapat mendekode berkas .heic dan menampilkan gambar mini kosong atau pesan "tidak dapat dibuka". Ini masalah codec, bukan berkas yang rusak. Setelah Anda menambahkan HEIF Image Extensions (Perbaikan 1) atau mengonversi foto ke JPG (Perbaikan 3), setiap aplikasi Windows yang memakai tumpukan gambar sistem akan menampilkannya secara normal.

Apakah perbaikan ini memerlukan hak administrator di PC saya?

Tergantung perbaikannya. Memasang HEIF Image Extensions dari Microsoft Store (Perbaikan 1) dan CopyTrans HEIC sama-sama memerlukan hak administrator dan akses Store. IrfanView dalam mode portabel (Perbaikan 2) berjalan dari sebuah folder tanpa menulis ke folder sistem atau registry, sehingga bekerja tanpa hak administrator. Mengonversi secara daring dengan HEIC ke JPG (Perbaikan 3) tidak memerlukan pemasangan apa pun - cukup peramban web.

Apakah mengonversi HEIC ke JPG mempertahankan tanggal dan lokasi GPS foto?

Ya. Konversi dengan HEIC ke JPG mempertahankan metadata EXIF - tanggal pengambilan, model kamera, dan koordinat GPS jika ada - pada JPG keluaran secara bawaan. Jika Anda ingin menghapus metadata itu sebelum berbagi, hilangkan centang opsi EXIF di panel Pengaturan pada halaman alat sebelum mengonversi.

Microsoft Store diblokir di PC kerja saya - apa yang bisa saya lakukan?

Ketika group policy menonaktifkan Microsoft Store, Perbaikan 1 tidak tersedia. Gunakan IrfanView portabel (Perbaikan 2), yang berjalan dari flashdisk atau folder pengguna tanpa memasang apa pun di seluruh sistem, atau konversikan foto ke JPG secara daring (Perbaikan 3) hanya dengan peramban. Kedua cara ini sepenuhnya menghindari Store.

Bisakah saya membuka HEIC di Windows 8 atau versi lebih lama?

Tidak dengan jalur resmi Microsoft - HEIF Image Extensions memerlukan Windows 10 atau 11. Di Windows 8, 8.1, atau lebih lama, gunakan penampil pihak ketiga seperti IrfanView dengan plugin HEIF (Perbaikan 2) atau konversikan berkas ke JPG secara daring (Perbaikan 3), karena Windows sudah menangani JPG di setiap versi.
