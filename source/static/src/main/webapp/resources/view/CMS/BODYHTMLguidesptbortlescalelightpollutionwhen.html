Quando Usar o Explorador 3D da Escala Bortle de Poluição Luminosa

Última revisão: 2026-07-25

Revisado por Equipe editorial FreetoolOnline

Abra o Explorador 3D da Escala Bortle de Poluição Luminosa quando precisar ver o que uma classe de poluição luminosa realmente esconde, ou decidir se um local de observação planejado é escuro o suficiente para o que você quer observar.


Uma lição sobre poluição luminosa

Uma lição começa quando você arrasta o controle de classe de 1 a 9 e observa a contagem de estrelas e a visibilidade da Via Láctea mudarem, depois alterna entre os ajustes de local escuro excelente e céu de cidade para ver os dois extremos lado a lado.


Sessões para as quais este explorador não é adequado

Este explorador não é adequado para aprender o próprio SISTEMA NUMÉRICO de magnitudes - use o Explorador de Magnitude Estelar para isso - nem para obter uma leitura real e repetível de brilho no seu próprio quintal - use um medidor de qualidade do céu real ou um mapa de poluição luminosa em tempo real para isso. Percorra os controles no guia passo a passo.
