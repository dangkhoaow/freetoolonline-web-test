Como Usar o JSON Diff Checker Online - Passo a Passo

Last reviewed: 2026-07-30

O JSON Diff Checker Online compara dois textos JSON e destaca adições, remoções e valores alterados - tudo no navegador, sem necessidade de instalação.

Passo 1 - Abra a ferramenta

Acesse o JSON Diff Checker Online. A ferramenta carrega instantaneamente no navegador - nenhum programa precisa ser instalado nem exige login.

Passo 2 - Cole os dois JSONs

Cole o JSON original no painel esquerdo (Original JSON) e o JSON modificado no painel direito (Modified JSON). Objetos aninhados e arrays são comparados recursivamente, então mudanças em níveis profundos aparecem com o caminho completo.

Passo 3 - Clique em Comparar e revise

Clique no botão Compare. Cada linha de resultado mostra o caminho completo da chave (por exemplo, user.address.city), o valor antigo e o novo valor lado a lado. Chaves adicionadas aparecem em verde, removidas em vermelho e alteradas em âmbar.

Passo 4 - Copie o resultado

Clique em Copy Diff para copiar o resumo do diff para a área de transferência e colá-lo em um relatório de bug ou revisão de código. Nenhum dado sai do seu navegador em nenhum momento.
