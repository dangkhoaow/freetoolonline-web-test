Subnetzrechner (IPv4 CIDR) - Schritt für Schritt

Last reviewed: 2026-07-24

Der Subnetzrechner (IPv4 CIDR) arbeitet in zwei Schritten: Werkzeug öffnen, dann Adresse und Präfix eingeben. Diese Seite erklärt, was jeder Schritt erwartet.


Schritt 1 - das Werkzeug öffnen

Rufen Sie den Subnetzrechner (IPv4 CIDR) auf. Vor dem Start muss nichts installiert werden und keine Anmeldung ist nötig.


Schritt 2 - Adresse und Präfix eingeben

Geben Sie eine IPv4-Adresse in das erste Feld ein (zum Beispiel 192.168.1.0) und eine CIDR-Präfixlänge von 0 bis 32 in das zweite (zum Beispiel 24). Beide Felder sind mit einem Standardwert vorbelegt, sodass die Seite ein echtes Ergebnis anzeigt, bevor Sie überhaupt etwas eingeben.


Schritt 3 - das Ergebnis lesen

Netzwerkadresse, Broadcast-Adresse, Subnetzmaske, Wildcard-Maske, nutzbarer Hostbereich sowie die Gesamt-/Nutzbar-Hostzahlen erscheinen unter den beiden Feldern und werden bei jedem Tastendruck aktualisiert - es gibt keine separate Schaltfläche "Berechnen" und nichts zum Kopieren oder Herunterladen.

Die Berechnung läuft lokal im Browser - kein Upload und kein Konto.
