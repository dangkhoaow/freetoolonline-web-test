Neon Crime City

Last reviewed: 2026-07-07

Neon Crime City is a browser-based open-world crime city sandbox: drive the streets, hop out to explore on foot, and reset anytime. The game runs inside a dedicated frame so the rest of the page stays fast until you press Play.

Start the session with the Play button above; the game takes keyboard focus while it is running. Use the in-game settings menu to review or change key bindings, and the Fullscreen button for the largest view.

No installs, no accounts, and nothing is uploaded. This is a community-built browser port and is not affiliated with any commercial franchise.

For the smoothest experience, close extra tabs and keep the game in focus. The first load may take a moment while assets are prepared by the game host.
