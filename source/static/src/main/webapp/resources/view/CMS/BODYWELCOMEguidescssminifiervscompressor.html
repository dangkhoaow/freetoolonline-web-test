How to shrink a CSS file to its smallest size

Getting a stylesheet as small as it will go takes two passes, not one. First, minification at build time strips the whitespace, comments, and redundant characters the browser never needed, which trims a typical 100 KB source down to roughly 55 KB. Transport compression then re-encodes the repeated byte patterns that remain: gzip brings that same file to about 15 KB, and Brotli reaches around 11 KB. Lean on gzip alone and skip the minify pass, and you only get to about 22 KB, so the smallest result comes from running both stages in that order.
