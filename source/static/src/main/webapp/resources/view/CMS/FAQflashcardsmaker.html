Frequently Asked Questions

What does Flashcards (Spaced Repetition) do?

Study a stack of flashcards you build yourself, right in this browser - no sign-in, no app to install.

When should I reach for flashcards (spaced repetition)?

Mark a card "I knew it" to set it aside for this pass, or "Still learning" to keep it in the queue; Shuffle randomizes the study order.

What complementary tools work well alongside flashcards (spaced repetition)?

This is a simple study aid, not a spaced-repetition scheduler - there is no algorithm timing when a card comes back; "Study all again" just clears every card's known flag so the full deck re-enters the queue.

Is there a character limit on a card's question or answer?

Yes. Both the front (question) and back (answer) fields accept up to 500 characters each, the same limit used for a single item on this site's other localStorage-backed list tools. That is enough room for a full sentence or a short paragraph on either side of a card.

Can I edit a card after adding it?

Not in place. Flashcards Maker has no edit button for an existing card - to fix a typo or change the wording, delete the card and add a new one with the corrected front and back text.

What exactly happens when I export or import a backup?

Export downloads your whole deck as a JSON file named flashcards-maker-backup.json. Import reads a JSON file back in and merges it with whatever is already in this browser by matching each card's id - a card from the imported file replaces the matching card already on the page, while any card that exists only in the browser (not in the file) is kept. Importing an older backup will not silently wipe cards you added afterward.

Does the text I paste into "Turn notes into card drafts" leave my browser?

No. All three ways the tool can draft cards run on this device: plain in-page extraction (term-definition and fill-in-the-blank), the browser's built-in AI when it is already installed on the device, or an optional on-device model you choose to load. Your notes are never uploaded to a server.

How big is the optional AI model download?

Each model in the picker shows its one-time download size before anything starts - the smallest option is under 1 GB. The weights are cached by this browser and shared with the other AI tools on this site, so a model already loaded on another page is reused without a second download. Running a model needs WebGPU; if this browser cannot provide it, the tool says so and the basic no-model drafts keep working.

Are the generated card drafts ready to study as-is?

Treat them as drafts. A small on-device model can word a question awkwardly, pick a minor fact, or get a detail wrong - review each draft before adding it to the deck. Add all skips any draft whose front text already matches an existing card, and both sides of a draft are trimmed to the same 500-character limit as hand-typed cards.
