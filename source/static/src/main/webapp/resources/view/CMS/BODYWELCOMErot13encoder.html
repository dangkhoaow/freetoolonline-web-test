ROT13 Encoder

Last reviewed: 2026-07-26

Paste text and apply ROT13 in your browser - A-Z and a-z shift by 13; digits and punctuation stay as-is.


Key features

  • Output updates as you type; Copy puts the current result on the clipboard.
  • ROT13 is its own inverse - run it again on the result to restore the original Latin letters.
  • Does not apply Caesar shifts other than 13, and does not transliterate non-Latin scripts.

When to use it

Prefer this for puzzle spoilers, Usenet-style obfuscation demos, or quick letter-shift checks without installing an editor.


How ROT13 works

ROT13 shifts each Latin letter by 13 places, so the same action encodes and decodes - running it a second time on the result restores the original letters, while digits and punctuation stay as-is.


Privacy

Not encryption for secrecy - anyone who knows ROT13 can reverse it instantly. Nothing you paste is saved between visits.
