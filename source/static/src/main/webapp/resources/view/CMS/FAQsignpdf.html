Frequently Asked Questions

What does Sign PDF (Add Signature) do?

Place a signature image onto a PDF page, right in the browser.

When should I reach for sign pdf (add signature)?

Places one signature image on one page at a fixed corner - does not draw freehand on the PDF, does not fill AcroForm signature fields, and does not cryptographically certify or lock the document.

What complementary tools work well alongside sign pdf (add signature)?

To draw a signature as a PNG first, use the signature pad tool; to stamp text on every page, use the watermark tool.

What happens if I choose a page number that doesn't exist in my PDF?

After you choose the PDF, the tool reads its real page count and limits the page-number field to that many pages. If you still enter a page beyond that count, clicking Sign PDF stops and shows the PDF's actual page count instead of guessing or placing the signature on the wrong page.

Does my signature image's file extension have to match its real format?

Not exactly. The tool first guesses PNG or JPG from the file's name and browser-reported type, but if that guess turns out wrong - for example a JPEG photo saved with a .png extension - it automatically retries the other image format before giving up, so a mislabeled signature file usually signs correctly anyway.

Can I move or resize the signature after it's been placed?

No - the position (one of the four corners) and the size cap are both fixed at the moment you click Sign PDF. To change either, sign the original PDF again with a different corner choice, or resize/crop the signature image itself before you upload it.

Can I put my signature on more than one page in the same PDF?

Each run of the tool signs exactly one chosen page - there is no setting that repeats the same signature across several pages in a single pass. To sign a second page too, download the first result, then run it back through Sign PDF a second time with the new page number.
