Telling the two faults apart takes two different chord sizes

Ghosting and a rollover ceiling show up at different numbers of held keys, so no single chord tests both. Ghosting appears with as few as three keys: hold three corners of a rectangle on the layout, such as E, R and D, and watch whether F lights up on its own. The rollover ceiling stays hidden until you exceed the count, so a five-key chord like WASD plus Q proves nothing about rollover and tests only ghosting. To measure the ceiling instead, hold seven or more letter keys at once and count the highlighted boxes; if the display stops at six no matter how many more you add, that board is 6KRO, while a full-NKRO board keeps lighting every key you hold. Modifier keys such as Shift and Ctrl usually sit on their own lines and register on top of that six, so count only letter and number keys, or a genuine six-key cap can look like seven. In the keyboard test, read a missing key as a rollover limit and a self-lit key as a ghost - they point at two different hardware causes, not one.

Where you run the test changes the number you get

The USB HID boot protocol - the mode a keyboard uses before any driver loads - reports at most six regular keys plus eight modifiers (the left and right Shift, Ctrl, Alt and Windows keys) in a single packet, so a board wired for full NKRO still shows only 6KRO until the operating system switches it into a richer report mode. That is why a keyboard advertised as NKRO can cap at six keys inside the BIOS setup screen or the Windows login field, then register every key once the desktop loads and the full descriptor takes over. Count highlighted keys from inside the browser on a fully booted desktop, because running the same chord in a boot menu measures the USB fallback rather than the keyboard's real ceiling. A PS/2 connector sidesteps the limit entirely because it sends each key as its own interrupt, which is why a few enthusiast boards still ship with a PS/2 plug for guaranteed NKRO.

A spec sheet is not proof about your own unit

Full NKRO and genuine anti-ghosting almost always come from the same tiny component: a diode behind every switch, a one-way gate that blocks the stray current backflow which would otherwise light a fourth, never-pressed key. Membrane boards skip those diodes to shave cost, which is why a cheap office keyboard types fine yet ghosts the instant you cross three keys, while a mechanical board with per-key diodes clears both tests at once. So a listing that reads "26-key rollover" or "anti-ghosting on 19 gaming keys" is describing a partial matrix, not full NKRO - budget diode coverage often stops at the gaming keys, roughly the WASD block and the arrows, leaving the rest of the matrix at 2KRO, so a chord across the number row can still fail even when the gaming keys look perfect. Press the chords you actually use, over the number row and with your right hand, where an unprotected key is most likely to drop or double. Underneath both features sits one grid of wires that the controller scans row by row, energizing a single row at a time and reading back which columns answer, so every key is just a row-and-column junction. Rollover is how many of those junctions the controller reports in a single pass, one fixed number for the whole board, which is why a spec sheet can quote it as a single figure; which keys collide is set by how your particular board maps its layout onto those rows and columns, so you cannot borrow someone else's ghosting chord as proof about your own keyboard.

Which limit matters depends on how many keys you hold

Someone typing prose or code rarely exceeds two or three keys together, so a modest 6-key rollover is plenty; what matters for them is clean handling of the modifier chords a shortcut relies on, such as Ctrl plus Shift plus an arrow or Ctrl plus Alt plus a letter, where one dropped or invented key fires the wrong command. A gamer blows past six in a single motion - holding W, A and Shift to strafe-sprint while tapping Space to jump and a number key to swap weapons is already five or six live keys - so a higher rollover count is the feature that keeps the sixth input from vanishing mid-fight. Reproduce your busiest real chord in the on-screen test and hold it for a second while you watch whether every key lights up and nothing else on the layout moves. The two limits are fixed by different things when you shop: a low rollover count is a number you can buy past with a higher-rated board, while a matrix that garbles one particular region of keys is set by the wiring under those switches and reads the same on every reboot.
