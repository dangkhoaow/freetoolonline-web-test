Depth: NKRO = every simultaneous key registers

N-key rollover and anti-ghosting sound like the same feature, but a keyboard can pass one test and fail the other. Rollover is a count: 6-key rollover registers six held keys plus modifiers and silently drops the seventh, while true NKRO registers every key no matter how many you hold at once. Anti-ghosting is a wiring fix that stops phantom keys appearing when three keys share one matrix line - the classic WASD-plus-Q chord is where a cheap 2KRO board either loses the Q or invents a fourth keypress. To separate the two in the on-screen keyboard test, hold WASD and count the highlighted keys first (that measures rollover), then add Q and watch for any key that lights up on its own (that exposes ghosting). Budget boards often advertise anti-ghosting on a fixed set of gaming keys - roughly the WASD cluster and the arrows - while leaving the rest of the matrix at 2KRO, so a chord across the number row can still fail even when the gaming keys look perfect.
