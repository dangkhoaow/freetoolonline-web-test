Game-Server-Status prüfen - Schritt für Schritt

Last reviewed: 2026-08-18

Der Game-Server-Status-Checker beantwortet zwei Fragen auf einer Seite: Ist die Plattform selbst down, und ist ein bestimmter Minecraft-Server online? Hier steht genau, was zu klicken ist und wie jedes Ergebnis zu lesen ist.


1. Die drei Plattformkarten lesen

Die Karten für Fortnite / Epic-Games-Dienste, Roblox und Discord füllen sich von selbst, ohne Klick. Jede liest die öffentliche Status-API der jeweiligen Plattform und zeigt einen farbigen Indikator mit der offiziellen Beschreibung Wort für Wort: Grün heißt betriebsbereit, Gelb eine Teilstörung, Orange ein größerer Ausfall, Rot ein plattformweiter Ausfall. Jede Karte verlinkt zusätzlich die offizielle Statusseite.


2. Einen Minecraft-Server per Adresse prüfen

Die Serveradresse ins Feld tippen - ein einfacher Host wie mc.hypixel.net oder host:port wie play.example.org:19132. Java Edition oder Bedrock Edition wählen und Check server drücken (Enter geht auch). Beim Laden der Seite läuft eine klar gekennzeichnete Beispielabfrage, damit man die Ergebnisform vorab sieht.


3. Die Ergebniskarte lesen

Ein Online-Server zeigt die Spieler online vom Maximum, die laufende Version und die erste Zeile der Tagesnachricht. Ein offline oder nicht erreichbarer Server bekommt eine klare Karte, die die eingegebene Adresse wiederholt - zuerst Schreibweise und Port prüfen, denn ein Tippfehler erscheint als offline. Die Prüfung übernimmt der Dienst mcstatus.io, der Ergebnisse rund eine Minute zwischenspeichert; ein frisch neu gestarteter Server kann kurz noch offline erscheinen.


4. Wenn eine Karte die API nicht erreicht

Manche Schul- und Büronetzwerke blockieren Gaming-Domains als Kategorie. Die Karten sagen das klar, statt leer zu bleiben, und die verlinkten offiziellen Statusseiten lassen sich oft trotzdem öffnen. Nichts von dem, was man tippt, geht an die Server dieser Website, und die Seite speichert nichts.

Unsicher, ob jetzt der richtige Moment ist? Siehe wann sich ein Status-Check lohnt oder den Vergleich mit den Alternativen.
