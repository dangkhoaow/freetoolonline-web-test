User Agent Parser - Cuándo Usar

Last reviewed: 2026-07-24

Vale la pena abrir User Agent Parser cuando necesitas una verificación rápida y puntual sin instalar nada. Esta página explica cuándo aplica y cuándo no.


Cuándo encaja

Úsalo cuando un ticket de soporte, un registro de acceso del servidor, o una exportación de analítica trae una cadena de User-Agent en bruto y necesitas saber el navegador, el sistema o el dispositivo detrás de ella sin buscar en una tabla de referencia a mano. También sirve para verificar si el User-Agent de un bot o rastreador se identifica como afirma su documentación.


Qué esperar

Pega la cadena (o deja el campo vacío para leer la de tu propio navegador) y la herramienta devuelve el nombre y versión del navegador, el motor de renderizado, el sistema operativo y la clase de dispositivo - todo decodificado localmente en tu navegador, sin enviar nada a un servidor. Reconoce los principales navegadores y sistemas de escritorio y móvil actuales; una cadena no reconocida aún devuelve el texto en bruto más los campos que pueda detectar con confianza.
