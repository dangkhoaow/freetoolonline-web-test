Crystal Cave Flyer

Crystal Cave Flyer is a one-button 3D flight game. Hold Space, the mouse button, or a touch to climb; release to sink, threading the single circular gap in each rock wall. Press Play to start - a run lasts until you clip a wall.


Key features

  • Height is the whole game - there is no left-right steering, only climb and sink.
  • Each rock wall carries one circular gap, and the gap shrinks slightly as your distance grows.
  • Forward speed ramps up with distance, toward about double the starting pace.
  • Crystals float in roughly six of every ten gaps and add 25 points each on top of the meters flown.
  • One wall clip or touching the cave edge ends the run; press R or tap to start the next one.

When to use it

Because a run needs only one finger, Crystal Cave Flyer plays as well on a phone held in one hand as on a desktop. Early runs teach the climb-and-sink rhythm; later runs test it as the gaps tighten and the pace builds.


Privacy and storage

About 610 KB downloads once, mostly the shared 3D engine, then it is cached for repeat visits. Your best distance-plus-crystal total stays on this device under ftol:crystalcaveflyer:best. Nothing is uploaded and no account is needed.
