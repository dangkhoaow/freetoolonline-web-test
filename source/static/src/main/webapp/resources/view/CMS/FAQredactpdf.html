Frequently Asked Questions

Is the text really removed, or just hidden under a black box?

Really removed. The download is a rebuilt PDF: each page is re-created as an image with the black boxes baked in, and the original text, fonts, and document properties are not copied into the new file. A copy-paste, Ctrl+F, or a PDF text extractor finds nothing under a box - which is the difference between redaction and a rectangle drawn on top of live text.

How do I mark what gets removed?

Drag on any page to draw a box over the text, exactly like drawing a selection rectangle. Click a box to delete it. Nothing changes until you press the red button, so you can adjust the boxes as long as you like.

Can the tool find sensitive text for me?

Two helpers draw draft boxes for you to review. The instant pattern pass finds emails, phone numbers, card numbers, and IBANs with no download. The optional AI pass finds likely names, organizations, and places on this device - it downloads about 105 MB once, on your click, with the size stated first. Both only suggest: check every page yourself, because no detector provably finds everything, and scanned pages have no embedded text for the helpers to read.

Why can I no longer select or search text in the result?

Because every page becomes an image - that is the mechanism that guarantees the removed content is gone. If you need the remaining text searchable again, run the redacted file through the OCR PDF tool on this site, which writes a fresh text layer over the pages.

Does my PDF get uploaded anywhere?

No. The file is opened, rendered, and rebuilt entirely in your browser with page-rendering and PDF libraries served from this site. The only thing that ever downloads is the optional AI suggestion model - and that travels TO your device, not from it.

What about password-protected or very long PDFs?

Password-protected files must be unlocked first - this site has a PDF password remover for that. Files over 50 pages are refused so that no page can be silently missed; split them first with the PDF splitter, then redact each part.
