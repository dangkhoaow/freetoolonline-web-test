Choose a PDF, drag boxes over anything to remove (or use the suggestion buttons), then press the red button: the tool rebuilds the file on this device so whatever a box covers no longer exists anywhere in it.

The file opens on this device only - it is never uploaded. Password-protected PDFs must be unlocked first.
Suggestions only DRAW boxes for you to review - nothing is removed until you press the red button. Drag on any page to add a box by hand; click a box to delete it. Scanned pages have no embedded text, so suggestions cannot see them - use hand-drawn boxes there.
The output is a rebuilt PDF where every page is an image: whatever a box covers is gone from the file - not hidden under a rectangle - and no text on any page can be selected or searched afterwards. The original file on your disk is not touched.
