Live AQI Checker By City When To Use

Last reviewed: 2026-08-04

Live AQI Checker by City is worth opening when you need a quick, one-off run without installing anything. This page covers when that fits and when it does not.


When it fits

A 3-day peak-AQI forecast table below the result answers "will it improve tomorrow" for wildfire-smoke or pollution spikes.


What to expect

Data comes live from Open-Meteo's free air-quality API - nothing is uploaded and no account is required; the city search uses Open-Meteo's geocoding API.

Reports outdoor ambient air quality only - not an indoor air-quality sensor reading and not a substitute for local health advisories during a smoke event.
