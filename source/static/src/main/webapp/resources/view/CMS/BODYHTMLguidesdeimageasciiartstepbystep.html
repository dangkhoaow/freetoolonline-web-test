Bild zu ASCII-Art, Schritt für Schritt

Zuletzt geprüft: 2026-09-19

Der Bild-zu-ASCII-Art-Konverter braucht zwei Aktionen - Foto wählen, Ergebnis speichern. Alles läuft im Browser; das Bild wird nie hochgeladen. Hier jeder Schritt mit der Einstellung, die an dieser Stelle zählt.


Schritt 1 - das Werkzeug öffnen

Öffnen Sie Image to ASCII Art Online. Eine Demo-Kugel ist beim Laden bereits konvertiert, Sie können also jede Einstellung ausprobieren, bevor Sie eine Datei wählen. Nichts wird installiert, kein Konto verlangt.


Schritt 2 - Ihr Bild wählen

Nutzen Sie die Dateiauswahl oben. PNG-, JPEG-, WebP-, GIF- und BMP-Dateien öffnen direkt im Tab; von einem animierten GIF wird nur das erste Einzelbild gelesen - ein bestimmtes Bild holen Sie vorher mit dem GIF-Frame-Extraktor. Die Konvertierung läuft neu, sobald die Datei geladen ist.


Schritt 3 - Breite, Palette und Richtung einstellen

Die Breite bietet 40, 80, 120 oder 240 Spalten - 40 passt in Chatfenster, 80 für READMEs und Terminals, 120 und 240 für Drucke mit feinem Detail; die Zeilenzahl folgt automatisch der Bildform. Die Palettenauswahl tauscht den Zeichensatz: dicht (@%#*+=-:. ), leicht, Ziffern oder Unicode-Blöcke. Haken Sie Umkehren an, wenn die Kunst auf dunklem Grund liegen wird, etwa im Terminal.


Schritt 4 - Ausgabemodus wählen

Klartext ist der kopierbare Standard. Beim Wechsel auf farbiges HTML werden dieselben Zeichen mit näherungsweiser Pixelfarbe neu gezeichnet - nützlich für Webseiten; die Klartextform bleibt einfarbig.


Schritt 5 - kopieren oder herunterladen

Drei Schaltflächen unter der Ausgabe: Text kopieren legt die Zeichen in die Zwischenablage, .txt laden speichert den rohen Text, PNG laden rendert die Kunst auf ein transparentes Bild in Rastergröße. Das PNG folgt dem aktuellen Modus, eine farbige Konvertierung exportiert also in Farbe.


Wenn etwas falsch aussieht

Ausgabe wirkt gestaucht: Die Proportionskorrektur setzt normale Monospace-Schriften voraus - fügen Sie die .txt-Ausgabe in einen Editor mit echter Monospace-Schrift ein. Detail matschig: Spaltenzahl erhöhen oder dichte Palette wählen. Kunst auf Ihrem Hintergrund unsichtbar: Umkehren umschalten. Für welche Aufgaben der Konverter taugt, steht in wann er hilft; der Vergleich mit anderen Wegen im Vergleich.
