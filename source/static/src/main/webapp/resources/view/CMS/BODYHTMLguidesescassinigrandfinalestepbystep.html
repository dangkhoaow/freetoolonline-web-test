Cómo usar el Explorador 3D del Grand Finale de Cassini

  1. Abre el Explorador 3D del Grand Finale de Cassini y espera a que se pinte el lienzo.
  2. Arrastra para orbitar la vista y desplázate o pellizca para acercar Saturno, los anillos y Titán.
  3. Desliza el control de fase de 0 a 99 para mover la nave a cualquier punto de la línea de tiempo de 2016-2017.
  4. Pulsa Reproducir para animar la línea de tiempo completa de la misión de forma continua, o Pausar para detenerte y examinar una fase.
  5. Haz clic en Saturno, los anillos o Titán para actualizar el panel de datos con la fase actual de la misión.

El panel de datos lista las fechas y cifras reales publicadas por la NASA/JPL para cada fase - consulta la tabla de cifras del explorador para la referencia completa.
