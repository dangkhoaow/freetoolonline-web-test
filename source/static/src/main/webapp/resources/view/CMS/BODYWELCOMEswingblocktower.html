Welcome to Swing Block Tower - a free browser stacking game with no account or install. Tap or click to drop swinging blocks and chase a higher score. About ~2.0 MB loads after you press Play. Nothing is uploaded; play stays on-device. For more free browser games, open the games hub. Related picks: Mono Stack Blocks and One Tap Platformer.

Each block hangs from a crane and swings across the top of the tower. The whole game is timing: release a block as its edge lines up with the block below, and matched edges keep the tower wide enough to keep stacking.

How to play

  • Watch the crane swing the next block, then tap, click, or touch to release it over the tower.
  • Line up the block edges - clean overlaps score and keep the tower wide, while sloppy drops shave it narrower.
  • Three missed drops end the run, so wait for each swing to line up before you release.

Good to know

  • Background music and drop sounds play as you stack, and a Fullscreen button expands the stage once the game has loaded.
  • The same controls work on phone and desktop - tap on a touchscreen, click with a mouse.
  • This build keeps no save data, so scores last for the current session only.
