Como Usar o Explorador 3D do Diapasão de Hubble - Passo a Passo

Última revisão: 2026-08-13

Abra o Explorador 3D do Diapasão de Hubble, pressione um botão E0-E7 ou um botão a/b/c para transformar a amostra, alterne entre Normal e Barrada, e experimente o desafio de galáxia real para testar o que aprendeu.


Pressione os botões E0-E7

Pressione E0 até E7 para ver a amostra achatar de uma nuvem de pontos quase redonda até a forma mais achatada que os astrônomos realmente observam - o painel de informações mostra a fórmula exata de elipticidade atrás de cada nível.


Pressione S0, depois a, b ou c

Pressione S0 para ver a classe de transição lenticular - um bojo e um disco sem braços espirais - depois pressione a, b ou c para fazer crescer os braços espirais, observando o bojo central encolher e os braços afrouxarem de bem enrolados para soltos.


Alterne entre espiral Normal e Barrada

Pressione "Barred spiral (SB)" para adicionar a barra central e ver os braços espirais surgirem das pontas da barra em vez do bojo; pressione "Normal spiral (S)" para removê-la. O alternador só muda algo quando você está em S0 ou a/b/c.


Pressione "Walk the fork"

Pressione "Walk the fork" para percorrer automaticamente os doze níveis de vai-e-vem sem intervenção, ou pressione de novo para pausar e assumir o controle com os botões.


Mostre as irregulares, além do diapasão

Pressione "Show irregulars (beyond the fork)" para revelar uma forma irregular ao lado - a classe que Hubble deliberadamente deixou fora do seu diagrama.


Experimente o desafio de galáxia real

Pressione "Real-galaxy challenge" para receber uma pista sobre uma galáxia real e nomeada. Faça seu próprio palpite com os botões E0-E7/S0/a-b-c e o alternador Normal/Barrada, depois pressione "Reveal" para ver sua classificação real e o fato com fonte por trás dela.


Arraste para orbitar e use a tela cheia

Arraste para orbitar a câmera, use a roda do mouse ou o gesto de pinça para dar zoom, e use o botão de Tela Cheia para expandir toda a moldura para uma visão mais clara.
