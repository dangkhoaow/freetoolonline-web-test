Live AQI Checker by City - Cuándo Usar

Last reviewed: 2026-08-04

Live AQI Checker by City vale la pena abrirlo cuando necesitas una consulta rápida y puntual sin instalar nada. Esta página explica cuándo aplica y cuándo no.


Cuándo aplica

Una tabla de pronóstico del AQI máximo a 3 días debajo del resultado responde si la calidad del aire mejorará mañana, útil durante episodios de humo de incendios forestales o picos de contaminación.


Qué esperar

Los datos llegan en vivo desde la API gratuita de calidad del aire de Open-Meteo - no se sube nada y no se requiere cuenta; la búsqueda de ciudad usa la API de geocodificación de Open-Meteo.

Muestra solo la calidad del aire ambiental exterior - no es una lectura de un sensor de aire interior ni sustituye los avisos de salud locales durante un episodio de humo.
