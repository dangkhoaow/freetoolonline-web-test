Hilbert Curve Generator

Last reviewed: 2026-08-21

Draw a space-filling Hilbert curve at an order you choose, from 1 up to 7, entirely in your browser.

Key features

  • Pick a curve order from 1 up to 7 and redraw the whole path on the canvas.
  • Set the line width and color, then export the result as a PNG.
  • Load a photo to color each segment of the curve from that picture's pixels.
  • Everything runs in your browser - the image you load never leaves your device.

When to use it

Reach for it when you want a clean Hilbert curve image for a print, a teaching diagram, or a generative-art background.
