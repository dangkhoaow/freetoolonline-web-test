Cómo Explorar el Pulsar Timing Array 3D Explorer

Última revisión: 2026-08-04

Revisado por Equipo editorial de FreetoolOnline

Abre el Pulsar Timing Array 3D Explorer, mueve el control de separación y observa cómo la correlación de Hellings-Downs entre el púlsar de referencia dorado y el púlsar de prueba magenta sube, cae a negativo y vuelve a subir, calculada en vivo.

  1. Abre /space-3d/pulsar-timing-array.html y espera a que se renderice la Tierra, el conjunto de púlsares y el par resaltado.
  2. Arrastra el control de separación de 0 a 180 grados y observa cómo el púlsar de prueba magenta se mueve por el arco punteado alejándose del púlsar de referencia dorado.
  3. Presiona "Play sweep" para ejecutar automáticamente el ciclo completo de 0 a 180 grados.
  4. Marca "Show correlation-curve chart" para revelar el gráfico integrado con la correlación en cada ángulo, con un marcador en tu posición actual.
  5. Lee el panel de datos para ver el número de correlación de Hellings-Downs en vivo y si el par está correlacionado positivamente, anticorrelacionado o cerca de cero.
  6. Arrastra para orbitar la escena y usa el scroll o pellizca para ampliar y ver mejor el conjunto.
