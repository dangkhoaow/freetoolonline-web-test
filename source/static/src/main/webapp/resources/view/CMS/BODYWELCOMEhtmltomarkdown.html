HTML to Markdown Converter

Last reviewed: 2026-07-20

Paste HTML and get Markdown you can copy - entirely in the browser, no upload and no account.

Typical use: when a README, wiki, or CMS field accepts Markdown but your source is HTML from email, a docs export, or a rich-text editor.


Key features

  • Left textarea for pasting the HTML you want to convert.
  • Live conversion on input, plus a Convert to Markdown button that runs Turndown on the page.
  • Right textarea shows the Markdown result.
  • Clear resets both boxes; Copy Output puts the Markdown on your clipboard.
  • Turndown is served from this origin under /vendor/markdown/, so there is no third-party call once the script has loaded.

Privacy and processing

Turndown runs on this page after the vendor script loads from this origin. Conversion stays in your tab, and closing the tab discards the text - nothing is stored on a server.


Reverse direction

Need Markdown turned back into HTML? Use the related Markdown to HTML previewer linked from the related-tools section.
