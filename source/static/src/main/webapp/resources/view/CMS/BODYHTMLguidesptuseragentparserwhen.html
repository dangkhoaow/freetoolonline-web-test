User Agent Parser - Quando Usar

Last reviewed: 2026-07-24

Vale abrir o User Agent Parser quando você precisa de uma verificação rápida, pontual, sem instalar nada. Esta página explica quando isso se aplica e quando não.


Quando faz sentido

Use quando um chamado de suporte, um log de acesso do servidor, ou uma exportação de analytics traz uma string de User-Agent bruta e você precisa saber o navegador, o sistema ou o dispositivo por trás dela sem consultar uma tabela de referência manualmente. Também serve para verificar se o User-Agent de um bot ou crawler se identifica como a documentação dele afirma.


O que esperar

Cole a string (ou deixe o campo vazio para ler a do seu próprio navegador) e a ferramenta devolve o nome e a versão do navegador, o motor de renderização, o sistema operacional e a classe de dispositivo - tudo decodificado localmente no seu navegador, sem enviar nada a um servidor. Ela reconhece os principais navegadores e sistemas desktop e mobile atuais; uma string não reconhecida ainda retorna o texto bruto mais os campos que conseguir detectar com confiança.
