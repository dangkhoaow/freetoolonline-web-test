User Agent Parser - Quando Usar

Last reviewed: 2026-07-24

Vale abrir o User Agent Parser quando voce precisa de uma verificacao rapida, pontual, sem instalar nada. Esta pagina explica quando isso se aplica e quando nao.


Quando faz sentido

Use quando um chamado de suporte, um log de acesso do servidor, ou uma exportacao de analytics traz uma string de User-Agent bruta e voce precisa saber o navegador, o sistema ou o dispositivo por tras dela sem consultar uma tabela de referencia manualmente. Tambem serve para verificar se o User-Agent de um bot ou crawler se identifica como a documentacao dele afirma.


O que esperar

Cole a string (ou deixe o campo vazio para ler a do seu proprio navegador) e a ferramenta devolve o nome e a versao do navegador, o motor de renderizacao, o sistema operacional e a classe de dispositivo - tudo decodificado localmente no seu navegador, sem enviar nada a um servidor. Ela reconhece os principais navegadores e sistemas desktop e mobile atuais; uma string nao reconhecida ainda retorna o texto bruto mais os campos que conseguir detectar com confianca.
