More depth: the five real jobs behind "MD5 decode"

The word decode implies a reversible step, yet MD5 produces a 32-character hexadecimal fingerprint that no tool can turn back into the original text, so that wording almost always stands in for one of five concrete jobs. To build a fingerprint from text, open the MD5 converter and press the To MD5 button; to chase the text behind a hash you already hold, press the To Text button on the same page, which first checks the pairings your browser saved in localStorage and only then queries the server dictionary, so a value that was never hashed before comes back empty. Verifying a download is a different job entirely - there you compare two 32-hex strings for an exact match, and read and compare MD5 hashes correctly walks through the traps that make identical files look different, such as uppercase-versus-lowercase hex or a stray leading space.
