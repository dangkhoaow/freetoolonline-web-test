Cara membuka file ZIP, langkah demi langkah

  1. Buka /unzip-file.html di tab baru.
  2. Unggah arsip .zip yang ingin dibuka.
  3. Jika arsip terkunci dengan password, masukkan password tersebut di kolom yang tersedia sebelum memproses. Tanpa password yang benar, arsip tidak dapat dibuka - alat ini membuka password yang sudah Anda ketahui, bukan memecahkan password yang tidak diketahui.
  4. Setelah proses selesai, daftar isi arsip muncul. Unduh berkas yang dibutuhkan satu per satu.

Perlu diketahui sebelum mengunggah

Proses ekstraksi pada halaman ini berjalan lewat unggahan ke server - bukan proses di browser tanpa unggah. Ini berarti arsip ZIP Anda dikirim untuk diproses, kemudian isinya tersedia untuk diunduh; ini bukan alat yang membaca isi ZIP secara lokal tanpa transfer data. Untuk arsip yang berisi data sensitif, pertimbangkan hal ini sebelum mengunggah. Jika tujuan Anda justru membuat arsip ZIP baru (bukan membukanya), gunakan /zip-tools/zip-file.html, yang punya jalur di browser tanpa unggah untuk membangun arsip.

Ketika password ZIP tidak diketahui

Alat pembuka di halaman ini hanya menghapus password yang Anda sudah tahu dari arsip - bukan memecahkan password yang tidak diketahui atau lupa. Untuk penjelasan lebih lengkap soal kapan alat online dapat membantu dan kapan tidak untuk kasus password ZIP, lihat /guides/id/zip-password-unlocker.html.
