Wurmloch (Einstein-Rosen-Bruecke) 3D-Explorer im Vergleich

Diese Seite ist ein kostenloses, reines Browser-Einbettungsdiagramm (Katenoid) mit belegten Daten und einer Formel. Sie ist kein Loeser fuer Gleichungen der allgemeinen Relativitaetstheorie und kein Lehrbuch-PDF.

  • Dieser Explorer - Live-Regler fuer den Rachenradius (0,6 bis 2,5 Einheiten), Zeitleiste 1916-1988, keine Installation.
  • Physik-Lehrbuchdiagramme - statische Bilder, meist mit einem festen Rachenradius, keine interaktive Neuskalierung.
  • Desktop-Software zur Relativitaets-Visualisierung - kann echte Metriken loesen, braucht aber eine Installation und eine viel laengere Lernkurve.
