Expense Tracker

Last reviewed: 2026-07-11

Log each expense with a short description and an amount, and the total updates automatically as you add entries.

Use it to track daily spending, split a trip's costs, or keep a running tally of a project's expenses without installing an app or creating an account.

Each entry gets a checkbox to mark it reviewed and a button to remove it; the running total only counts entries currently in the list.

Your expense entries and the running total behind them are stored in this browser's local storage, so a reload or a closed tab will not reset the tally, and only clearing this site's browser data starts you from zero. Because that data belongs to this one browser and never reaches a server or an account, the Export backup (JSON) button is what you use before switching devices or wiping browser data - save the file, then Import backup on the other browser to pick the tally back up.
