GPU Test - WebGL Benchmark & Info is worth opening when you need a quick, one-off run without installing anything. This page covers when that fits and when it does not.


When it fits

M3: The score reflects sustained geometry throughput - tiers advance while the median holds 55 FPS, and frame rates above 60 count as 60 so high-refresh screens stay roughly comparable.


What to expect

M4: It is honest about limits - an indicative browser benchmark, not a lab-grade suite; device heat, battery mode, and other tabs shift the numbers, so compare scores only between runs on the same device and browser.

M5: Your recent runs (up to 20) are kept in this browser's local storage so you can watch a trend over time - nothing is uploaded anywhere.
