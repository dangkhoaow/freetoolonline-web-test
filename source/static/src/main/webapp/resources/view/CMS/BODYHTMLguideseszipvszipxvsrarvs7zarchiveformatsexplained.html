Respuesta de 30 segundos. Cuatro formatos, cuatro eras de compresion. Zip (1989, Deflate) abre en todas partes sin instalacion. Zipx (2008, contenedor de WinZip para algoritmos mas nuevos) abre solo con WinZip o herramientas compatibles. Rar (1993, propietario) se recibe mas, rara vez se crea. 7z (1999, LZMA2) comprime mas pequeno pero necesita descarga. Para enviar: usa zip a menos que ambos lados tengan algo mejor instalado.

Cuanto ahorra realmente la eleccion de formato

Los ahorros de compresion varian mucho segun el tipo de contenido. Los archivos de texto, codigo, JSON y CSV se reducen un 60-80 % en los cuatro formatos. Los documentos de Office comprimen un 10-25 %. Los PDF y archivos ya optimizados solo un 5-15 %. Las fotos en JPG, PNG o HEIC casi no comprimen (0-5 %) porque ya estan comprimidas. Para archivos de fotos, la diferencia de tamano entre Zip y 7z es casi nula; para repositorios de codigo fuente o registros de log, 7z con LZMA2 puede superar a Zip Deflate en un 20-40 %.

Para que sirve cada uno

Para que sirve cada uno en Zip vs Zipx vs Rar vs 7z, explicado: Zip para intercambio universal, Zipx para extras de WinZip, Rar para archivos solidos con recuperacion, 7z para maximo encogimiento open-source.

7z. Open-source, moderno, el mas pequeno. La eleccion correcta para almacenamiento de archivado de largo plazo y para cualquier transferencia grande donde ambos lados tienen 7-Zip o The Unarchiver instalados.
