Comprimir Pasta Zipada

Comprimir uma pasta que já está zipada raramente reduz o tamanho - o algoritmo deflate do ZIP já removeu a redundância da primeira vez. Use o compactador ZIP com nível máximo para tentar um pouco mais, ou descompacte primeiro e re-zipe arquivos individuais.

Como tentar comprimir uma pasta zipada

  1. Abra o compactador ZIP no navegador.
  2. Arraste a pasta zipada (.zip) que você quer comprimir mais.
  3. Selecione "Máxima compressão" nas Configurações.
  4. Compare o tamanho do novo arquivo com o original - se a redução for menor que 1%, a pasta já está no mínimo prático.

Por que ZIP duplo raramente funciona

O formato ZIP usa o algoritmo deflate (combinação de LZ77 + Huffman) que já remove redundância byte por byte na primeira compactação. Re-zipar um arquivo .zip processa bytes que são quase aleatórios para o algoritmo, então não há padrões restantes para comprimir. Em testes práticos, comprimir um .zip uma segunda vez economiza menos de 1% na maioria dos casos.

Comparação de tamanho: 3 abordagens

Abordagem Tamanho típico vs original Tempo
Re-zipar o .zip existente 99-100% 5-15s
Descompactar e re-zipar com nível máximo 95-99% 20-60s
Descompactar, comprimir imagens individuais (JPG/PNG/HEIC), re-zipar 40-70% (se a pasta tem fotos) 1-3 min

Quando vale a pena descompactar primeiro

Se a pasta zipada contém fotos (.jpg, .png, .heic) ou vídeos (.mp4, .mov), descompactar e comprimir cada arquivo de imagem individualmente com o compressor de imagens antes de re-zipar pode reduzir o tamanho final em 30-60%. Para PDFs grandes dentro da pasta, o hub PDF tem o compressor que reduz PDFs especificamente.

Se a pasta contém apenas texto, código, ou ficheiros já comprimidos (.zip, .gz, .mp3), descompactar e re-zipar não vai mudar quase nada - o tamanho mínimo já foi alcançado.

Perguntas frequentes

Posso comprimir um .zip protegido por senha?

Sim. Use o compactador ZIP e marque a opção de senha; o novo ficheiro vai preservar a proteção mas vai re-criptografar o conteúdo. Para remover a senha primeiro (se você souber a senha), use o removedor de senha ZIP antes de re-comprimir.

O processamento é feito no navegador ou no servidor?

O compactador ZIP processa arquivos pequenos no navegador; para pastas grandes (acima do limite anunciado na página) o upload vai para o serviço de processamento, e o arquivo é removido pouco tempo depois. Cada página de ferramenta documenta o seu próprio fluxo de dados.

É mais rápido descompactar e zipar de novo, ou usar uma ferramenta diferente?

Para redução real (acima de 5%), descompactar, comprimir as imagens/PDFs individualmente, e re-zipar produz o melhor resultado. Re-zipar diretamente o .zip já existente raramente vale o tempo.
