Paste names below, set the team count, then click Generate teams; each team renders as its own card.

How it works:

  1. Type each person's name into the list box above, one name per line.
  2. Set how many teams you need (2 to 20) in the number box next to the button.
  3. Click Generate teams; the list is shuffled fairly and split evenly across that many team cards.
  4. Edit the names or the team count and click Generate teams again for a fresh split.
