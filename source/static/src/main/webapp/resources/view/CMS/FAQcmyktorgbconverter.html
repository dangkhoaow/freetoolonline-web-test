Frequently Asked Questions

Can I type in numeric CMYK (C/M/Y/K) percentages?

No - there is no C/M/Y/K entry field. This is a colour picker: you choose a colour and it shows the matching RGB, HEX, and HSL. Use it to read the on-screen RGB of a colour you have in mind, not to convert exact print CMYK percentages.

Which colour formats can I copy?

Each value has its own Copy button - HEX, RGB, and HSL are copied separately - so you can paste just the format your editor or code expects instead of retyping the digits.
