User Agent Parser - Passo a Passo

Last reviewed: 2026-07-24

O User Agent Parser funciona em três passos: abra a ferramenta, informe sua entrada, depois copie o resultado. Esta página detalha o que cada passo espera.


Passo 1 - abra a ferramenta

Acesse o User Agent Parser. Nada precisa ser instalado ou logado antes de começar.


Passo 2 - informe sua entrada

Cole qualquer string de User-Agent na caixa da esquerda, ou deixe vazio para a ferramenta ler o User-Agent do seu próprio navegador automaticamente. Clique no botão para decodificar.


Passo 3 - copie o resultado

A caixa da direita se preenche com o nome e a versão do navegador, o motor de renderização, o sistema operacional e a classe de dispositivo, seguidos da string bruta original. Use o botão Copy Output para copiar para a área de transferência. Tudo isso acontece localmente no seu navegador - nada do que você cola é enviado a um servidor.

Tudo roda localmente no navegador - sem upload e sem conta.
