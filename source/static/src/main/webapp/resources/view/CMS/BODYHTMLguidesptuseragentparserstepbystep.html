User Agent Parser - Passo a Passo

Last reviewed: 2026-07-24

O User Agent Parser funciona em tres passos: abra a ferramenta, informe sua entrada, depois copie o resultado. Esta pagina detalha o que cada passo espera.


Passo 1 - abra a ferramenta

Acesse o User Agent Parser. Nada precisa ser instalado ou logado antes de comecar.


Passo 2 - informe sua entrada

Cole qualquer string de User-Agent na caixa da esquerda, ou deixe vazio para a ferramenta ler o User-Agent do seu proprio navegador automaticamente. Clique no botao para decodificar.


Passo 3 - copie o resultado

A caixa da direita se preenche com o nome e a versao do navegador, o motor de renderizacao, o sistema operacional e a classe de dispositivo, seguidos da string bruta original. Use o botao Copy Output para copiar para a area de transferencia. Tudo isso acontece localmente no seu navegador - nada do que voce cola e enviado a um servidor.

Tudo roda localmente no navegador - sem upload e sem conta.
