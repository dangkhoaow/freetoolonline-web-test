Cómo Usar el Explorador 3D del Efecto YORP - Paso a Paso

Last reviewed: 2026-08-13

Abre el Explorador 3D del Efecto YORP, elige aceleración o desaceleración, luego desliza o reproduce el control de años transcurridos y lee el panel de datos para ver la tasa real de aceleración medida, el cambio de período derivado, y el tamaño real y la fecha de descubrimiento del asteroide.


Elige aceleración o desaceleración

Usa #t3dYorpDirection para elegir Aceleración (54509 YORP, medida) o Desaceleración (espejo didáctico). Las flechas de par de torsión del asteroide cambian de color y dirección según tu elección.


Desliza o reproduce los años transcurridos

Arrastra #t3dYorpYears (0-100 años) para observar el cambio en la velocidad de giro que se muestra en pantalla, o presiona #t3dYorpPlayBtn para recorrer automáticamente todo el rango sin interacción manual.


Lee el panel de datos

El panel de la derecha se actualiza en vivo con la tasa medida, el período de rotación actual de 12,174 minutos, el cambio de período para tu elección y los años transcurridos, y la proyección dinámica a largo plazo.


Reinicia y compara

Presiona #t3dYorpResetBtn para volver al año 0, luego cambia el selector para comparar la aceleración con el espejo didáctico de desaceleración en el mismo tiempo transcurrido.


Arrastra para orbitar y usa pantalla completa

Arrastra para orbitar la cámara, usa la rueda del mouse o el gesto de pinza para el zoom, y usa el botón de Pantalla Completa para expandir todo el área y ver mejor el asteroide y sus flechas de par de torsión.
