Cómo Explorar el Explorador 3D del Cometa Interestelar 2I/Borisov

Última revisión: 2026-07-25

Revisado por Equipo editorial de FreetoolOnline

Abre el Explorador 3D del Cometa Interestelar 2I/Borisov y alterna entre 2I/Borisov y el Cometa Halley para comparar la excentricidad orbital real y la composición de la coma de cada objeto lado a lado.

  1. Abre /space-3d/borisov-interstellar-comet.html y espera a que se rendericen ambos modelos de cometa y el Sol.
  2. Arrastra el interruptor (0-1) para alternar el cometa destacado entre 2I/Borisov (coma azulada, camino abierto) y el Cometa Halley (coma anaranjada, bucle cerrado).
  3. Lee el panel de datos para la excentricidad orbital real, distancia del perihelio, velocidad y razón CO/H2O del cometa activo.
  4. Consulta la tabla de comparación debajo del panel de datos - la fila resaltada es el cometa activo.
  5. Observa las dos curvas de trayectoria: la hipérbola abierta de Borisov nunca se cierra, mientras que la elipse de Halley regresa alrededor del Sol.
  6. Arrastra para orbitar y desplaza o pellizca para ampliar y ver de cerca la densidad de la coma de cada cometa.
