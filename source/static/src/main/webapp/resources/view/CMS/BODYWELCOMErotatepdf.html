Rotate PDF

Last reviewed: 2026-09-02

Rotate every page of a PDF by 90, 180, or 270 degrees, right in the browser.

The angle applies uniformly to the whole document; it does not support rotating individual pages to different angles.

The file is processed in this browser tab and is never uploaded to a server.

No account or signup is needed, and nothing about the file is sent to any analytics or tracking service; once you close the tab, the file and its rotated copy are gone.

Why a page that was already rotated can look over-rotated afterward

Rotate PDF does not reset every page to a fixed orientation. It reads each page's existing rotation value and adds the angle you picked on top of it, then wraps the total at 360 degrees. For a page that starts at 0 degrees, picking 90 degrees clockwise lands exactly where you expect: 90 degrees. But a page that already carries a baked-in rotation - common in PDFs assembled from a scanner or a phone camera app, where some pages are stored sideways in the file even though they display upright in a viewer - ends up further rotated than the number you chose. A page already at 90 degrees, rotated another 90 degrees clockwise through this tool, lands at 180 degrees, not 90. The same input rotated 180 degrees instead lands back at 270 degrees. Because the tool applies one angle uniformly to every page in the file, a document where only some pages already carry a baked-in rotation and others do not will come out with pages at different final angles relative to each other, even though every page received the identical instruction. Checking a few pages of the result before relying on it is the reliable way to confirm the file rotated the way you expected, especially on scanned documents.

What the three angle choices mean, and what happens with a file that will not open

The angle picker offers exactly three choices: 90 degrees clockwise, 180 degrees, and 270 degrees clockwise. There is no separate counter-clockwise option, because 270 degrees clockwise produces the identical visual result as 90 degrees counter-clockwise - turning a page three-quarters of the way clockwise ends it in the same place as turning it one-quarter of the way the other way. Pick 270 degrees clockwise whenever you want to rotate a page counter-clockwise by 90 degrees. Rotate PDF also processes one file per run - the file picker here does not accept multiple PDFs at once, unlike the separate Merge PDFs tool, which does. Rotating several files means running the tool again for each one. If the file you choose cannot be read as a PDF at all - a renamed file of a different type, or a PDF that is damaged - the tool shows an inline message naming the problem and re-enables the rotate button immediately, so picking a different file and trying again does not require reloading the page.
