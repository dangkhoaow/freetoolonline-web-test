Cómo Comprobar el Estado de Servidores de Juegos - Paso a Paso

Last reviewed: 2026-08-18

El comprobador de estado de servidores de juegos responde dos preguntas en una sola página: ¿está caída la plataforma? y ¿está en línea un servidor concreto de Minecraft? Aquí tienes qué pulsar y cómo leer cada resultado.


1. Lee las tres tarjetas de plataforma

Las tarjetas de Fortnite / servicios de Epic Games, Roblox y Discord se rellenan solas, sin clics. Cada una lee la API pública de estado de la propia plataforma y muestra un indicador de color con la descripción oficial palabra por palabra: verde es operativo, amarillo un problema parcial, naranja una avería importante, rojo una caída total de la plataforma. Cada tarjeta enlaza además con la página oficial de estado.


2. Comprueba un servidor de Minecraft por dirección

Escribe la dirección del servidor en la caja - un host simple como mc.hypixel.net, o host:puerto como play.example.org:19132. Elige Java Edition o Bedrock Edition y pulsa Check server (Enter también sirve). Al cargar la página se ejecuta una consulta de ejemplo, claramente etiquetada, para que veas la forma del resultado antes de escribir nada.


3. Lee la tarjeta de resultado

Un servidor en línea muestra los jugadores conectados sobre el máximo, la versión y la primera línea de su mensaje del día. Un servidor apagado o inaccesible recibe una tarjeta clara que repite la dirección escrita - revisa primero la ortografía y el puerto, porque una errata aparece como desconectado. La comprobación la realiza el servicio mcstatus.io, que guarda los resultados en caché alrededor de un minuto; un servidor recién reiniciado puede aparecer desconectado un momento.


4. Si una tarjeta dice que no alcanzó la API

Algunas redes de colegios y oficinas bloquean los dominios de juegos por categoría. Las tarjetas lo dicen claramente en lugar de quedarse en blanco, y las páginas oficiales de estado enlazadas pueden abrirse igualmente. Nada de lo que escribes va a los servidores de este sitio, y la página no almacena nada.
