When the destination needs an exact pixel rectangle rather than a rough drag, the X, Y, width, and height inputs on crop-image.html accept those numbers directly - useful for a banner slot that demands precisely 1200 by 630, or a thumbnail grid where every tile has to match. The crop box jumps to the typed values immediately, so the live preview pane shows the exact result before the download click, not after. Because none of this leaves the browser tab, the same workflow works for a screenshot that still shows a name, an address, or another detail that should not pass through a remote server first.
