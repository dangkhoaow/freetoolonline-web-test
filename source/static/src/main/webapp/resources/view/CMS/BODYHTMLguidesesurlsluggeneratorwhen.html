URL Slug Generator - Cuando Usar

Last reviewed: 2026-07-26

URL Slug Generator vale la pena abrirlo cuando necesitas un permalink limpio a partir de un titulo humano sin instalar nada. Esta pagina cubre cuando encaja y cuando no.


Cuando encaja

Usalo para preparar permalinks de blog, rutas de CMS o nombres de archivo de sitio estatico a partir de un titulo. Pega una frase por linea para lote, elige "-" o "_" como separador y, si quieres, limita la longitud.


Que esperar

Slugify quita acentos latinos y vietnamitas con Unicode normalize (NFD) y corre localmente - sin subir nada y sin cuenta. Copiar pone el slug actual en el portapapeles; nada se guarda entre visitas.

No translitera scripts chinos, arabes o cirilicos. Si necesitas esos scripts en la ruta, usa primero un paso dedicado de transliteracion.
