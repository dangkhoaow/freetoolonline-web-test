Enter the air temperature and the relative humidity below; the heat index (how hot it actually feels) and its NWS risk category update as you type - nothing is uploaded and no calculation waits on a server round-trip.

Use the Fahrenheit / Celsius dropdown to switch units at any time; the temperature label and the result both switch with it. Humidity is entered as a plain percentage from 0 to 100.

The reference table below the result lists the four official NWS heat-index categories (Caution, Extreme Caution, Danger, Extreme Danger) and the typical effect of each, so you can see where today's reading falls.
