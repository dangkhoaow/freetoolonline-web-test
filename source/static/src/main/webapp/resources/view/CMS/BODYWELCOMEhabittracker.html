Habit Tracker

Last reviewed: 2026-07-03

Track the daily habits and recurring routines you are trying to build - add each one, check it off when you finish it for the day, and delete a habit you have dropped.

It works as a lightweight daily streak checklist for routines like drinking water, stretching, or reading, without installing an app or signing in.

Every habit carries its own checkbox to mark today done, plus a button to remove it. Your habit list and today's check marks are recorded in this browser's local storage, so closing the tab or reloading the page leaves the streak intact; the record only disappears if you clear this site's saved browser data.

Local storage stays put on the one browser that wrote it, so the Export backup (JSON) button saves your habits to a file you keep, and Import backup reads that file back in. That saved file is what carries the streak to a second browser, a new phone, or a reinstalled machine.

The habits never leave your device - there is no account to create and no background sync, so each browser holds an independent copy. A habit ticked off here stays here until you hand-carry the backup file across yourself.
