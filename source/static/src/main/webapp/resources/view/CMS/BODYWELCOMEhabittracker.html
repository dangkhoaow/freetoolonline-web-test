Habit Tracker

Last reviewed: 2026-07-03

Keep a habit list in the browser - add, check off, and delete items.

Use it for a quick checklist when you do not want to install an app or sign in.

Each item gets a checkbox to mark it done and a button to remove it. The list is saved in this browser via local storage, so it survives a page reload; clearing this site's browser data removes it.

Use the Export backup (JSON) button to download the current list as a file, and Import backup to load a saved file back in - local storage is a cache the browser can clear on its own, so keeping an exported copy is the only way to carry the list to a new browser or device.

This tool does not sync across devices or browsers on its own and does not use an account - each browser keeps its own separate copy, so a change made here will not show up on another device unless you export and import the backup file yourself.

To see how this browser tool compares to a desktop app or an upload-based service, see Habit Tracker vs desktop apps and online services.
