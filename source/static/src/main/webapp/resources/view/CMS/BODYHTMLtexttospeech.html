Type or paste your text - or upload a transcript file (.srt, .vtt, .sbv, .txt) - pick one of ten studio voices, and press Generate speech. The voice model runs inside this browser tab, so the same voice comes out on a phone, a laptop, or a work desktop, the audio is 44.1 kHz, and you can download it as MP3 or WAV. Nothing is uploaded.

The first run downloads the voice model, about 380 MB, and keeps it in this browser; after that the tool starts immediately and still works with the network off. If that download is too heavy right now, the quick device voice is one click away.

Prefer recording your own voice? Capture it with the voice recorder.
