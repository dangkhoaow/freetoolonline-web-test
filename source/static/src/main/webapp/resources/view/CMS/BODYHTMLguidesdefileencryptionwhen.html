Datei-Verschlüsselungstool - Wann Nutzen und Wie

Last reviewed: 2026-08-10
freetoolonline.com Editorial Team

Das Datei-Verschlüsselungstool verschlüsselt oder entschlüsselt eine Datei mit einem Passwort in diesem Browser: Datei auswählen, Passwort eingeben, dann auf Encrypt klicken für eine geschützte .enc-Kopie oder auf Decrypt, um die Originaldatei zurückzubekommen. Es wird nichts hochgeladen und nichts muss installiert werden.


Wann es passt

Das Datei-Verschlüsselungstool passt, wenn Sie eine Datei mit AES-256 in diesem Browser verschlüsseln wollen - ein Schlüssel aus Ihrem Passwort (PBKDF2, 250.000 Runden) plus frischem Salt und IV jedes Mal, sodass dieselbe Datei mit demselben Passwort zwei unterschiedliche .enc-Dateien erzeugt - das ist erwartet, kein Fehler.

Es schützt eine Datei auf einmal, und nur so lange das Passwort geheim bleibt, ist also kein Ersatz für eine Festplatten- oder Geräteverschlüsselung.


Die drei Schritte

Öffne das Datei-Verschlüsselungstool. Es muss nichts installiert werden, keine Anmeldung und kein Konto. Wähle deine Datei, dann gib ein Passwort in das Feld Password ein - die Schaltflächen Encrypt und Decrypt bleiben ausgegraut, bis beides ausgefüllt ist.

Klicke auf Encrypt, um eine normale Datei zu verschlüsseln, oder auf Decrypt bei einer .enc-Datei, die dieses Tool erstellt hat. Dann erscheint ein Download-Link mit der fertigen Datei: die .enc-Kopie beim Verschlüsseln, oder deine Originaldatei unter ihrem ursprünglichen Namen beim Entschlüsseln.


Was zu erwarten ist

Ein falsches Passwort oder eine .enc-Datei, die bearbeitet oder beschädigt wurde, wird mit einer klaren Fehlermeldung abgelehnt, statt eine defekte oder sinnlose Datei zu erzeugen.

Die .enc-Datei ist wegen eines kleinen Headers (eine Kennung plus ein frischer Salt und IV) etwa 32 Byte größer als das Original, und dein ursprünglicher Dateiname wird ebenfalls innerhalb der Datei verschlüsselt, sodass Decrypt ihn exakt wiederherstellen kann, ohne ihn separat zu speichern.

Es gibt keine Passwort-Wiederherstellung: dieses Tool speichert dein Passwort nirgendwo, daher macht ein verlorenes Passwort die verschlüsselte Datei dauerhaft nicht wiederherstellbar - schreibe es dir an einem sicheren Ort auf, bevor du diesen Tab schließt.


Vergleich mit einer Desktop-Anwendung oder einem Upload-Dienst

Das ist einer von drei gängigen Wegen, eine Datei zu verschlüsseln: ein browserbasiertes Tool wie dieses, eine Desktop-Anwendung, oder ein Upload-basierter Online-Dienst. Jeder hat andere Vor- und Nachteile darin, wohin deine Daten gehen und was du installieren musst.
