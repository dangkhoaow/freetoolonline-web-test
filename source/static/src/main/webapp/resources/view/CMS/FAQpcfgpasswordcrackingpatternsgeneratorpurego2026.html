Frequently Asked Questions

What is a PCFG base structure?

It is the shape of a password written as character-class segments: L for a run of letters, D for digits, S for symbols, with the number giving each segment's length. For example "monkey99!" is L6D2S1. A password-guessing model learns which structures are most common and tries those first.

Are the example passwords safe to use for my accounts?

No. The pattern examples deliberately follow common, guessable human structures so you can see how quickly a cracking model would reach them. For a real account, switch to the strong uniform-random mode, use at least 16 characters, and store the result in a password manager.

Does anything I generate leave my browser?

No. Every string is created locally with the Web Crypto secure random generator. Nothing is uploaded, logged, sent to a server, or checked against any breach database, so you can run it offline.
