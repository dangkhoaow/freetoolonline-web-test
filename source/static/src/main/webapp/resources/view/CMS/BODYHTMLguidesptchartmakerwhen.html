Quando Usar o Chart Maker Online

O Chart Maker Online é ideal quando você precisa de um gráfico de barras rápido a partir de poucas linhas e prefere não enviar os dados para um serviço de terceiros.

Instantâneos rápidos de dados

Quando você tem uma pequena tabela de números - vendas semanais, resultados de pesquisa, despesas mensais - e quer ver o padrão de relance, cole os valores e clique em Visualizar. Tudo roda no navegador, então seus números nunca saem da aba.

Apresentações e relatórios

Use para uma visão inicial dos seus dados antes de se comprometer com uma ferramenta completa de gráficos. Tire uma captura de tela ou copie o SVG para seus slides ou documento.

Quando a privacidade é importante

Como o Chart Maker roda inteiramente no navegador sem upload e sem conta, ele é adequado para situações em que compartilhar números brutos com um serviço web não é aceitável.
