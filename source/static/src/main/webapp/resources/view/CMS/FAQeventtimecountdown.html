Frequently Asked Questions

How do I share a countdown with someone in another timezone?

Set the event name, date, time, and timezone, then press Copy link. The URL carries the whole event, and anyone who opens it sees the same moment converted into their own timezone, with the countdown already ticking. Nothing is stored on a server - the link itself holds the event.

What happens when the event time arrives?

The display flips from "starts in" to "started" and begins counting up, showing how long ago the moment passed. The same shared link keeps working during and after the event.

Does daylight saving time break the countdown?

No. The date and time you enter are resolved into one exact instant using the browser's built-in timezone database, with the offset settled across daylight-saving transitions. The countdown is then computed from that instant, so it never jumps by an hour at a DST changeover.

Which timezones can I pick?

Every IANA timezone the browser knows - typically more than 400, searchable by typing part of the name, such as a city. On very old browsers that cannot list zones, a built-in set of 20 major zones is offered instead.

Does the countdown keep running if I close the tab?

No. It runs only while the page is open, and it does not send notifications or background alarms. Because the event is stored in the link as an exact instant, reopening the link later resumes the countdown at the true remaining time.
