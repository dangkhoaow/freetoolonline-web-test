Frequently Asked Questions

What does File Viewer do?

It opens a file you choose and renders it the way it is meant to look - images as images, PDFs page by page, text and JSON as readable text, audio and video with native playback controls - all without uploading it anywhere.

What happens with a file type it does not recognize?

You still see something: an unrecognized file falls back to a hex-and-ASCII dump of its first 4 KB, plus a details table with the name, size, type, and last-modified date.
