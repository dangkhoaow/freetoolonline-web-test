Como usar o Explorador 3D do Ano Galáctico: Órbita do Sol

  1. Abra o Explorador 3D do Ano Galáctico: Órbita do Sol e espere a cena carregar.
  2. Arraste para girar a visão e role para dar zoom no disco espiral e no anel da órbita.
  3. Escolha a vista de cima para ver a órbita como um círculo, ou a vista de perfil para ver o Sol subir e descer pelo plano do disco.
  4. Arraste o controle deslizante de tempo de 0 a 4.600 milhões de anos para mover o Sol para qualquer ponto desde sua formação.
  5. Pressione Reproduzir para animar o tempo continuamente, ou Pausar para manter uma posição e ler o painel de dados.
