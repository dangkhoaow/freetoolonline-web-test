Frequently Asked Questions

Is this Foxit, or connected to Foxit in any way?

No. This is an independent web page with no affiliation to Foxit; it borrows none of their code. It is a lightweight alternative for the single job of dropping a typed line onto a PDF page, run right in the tab.

Why pick this over installing the Foxit desktop program?

Reach for it when your only errand is stamping one short label and you would rather not install or license a full suite. It writes one line at a numeric X%/Y% coordinate on a single page - so it skips a drag-to-place preview, along with highlighting, freehand sketching, image stamps, and any rewriting or erasing of content already inside the file.

Does my PDF get sent anywhere when I use this alternative?

Nothing leaves your machine. The labelling happens locally in the browser, which is a large part of why a quick web option can stand in for a heavier installed editor here.

Which sibling tools cover the jobs this one skips?

For the same wording repeated on every page, hand it to the watermark tool; for completing the boxes of an existing PDF form, the form filler tool takes over.
