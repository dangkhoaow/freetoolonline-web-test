When to use Doppler Radial Velocity 3D Explorer

Use the Doppler Radial Velocity 3D Explorer when you need the star-wobble detection method itself - and skip it when you only need the transit-dimming method or the general wavelength-shift mechanism.

  • Classroom demos of how 51 Pegasi b was found
  • Comparing 51 Pegasi b and Jupiter-Sun wobble sizes
  • Contrasting radial velocity with transit detection

This page does not simulate a spectrograph and exaggerates the star wobble for teaching.
