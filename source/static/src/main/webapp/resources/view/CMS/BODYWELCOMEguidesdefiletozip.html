Mehr Tiefe: eine einzelne Datei verpacken, wenn ein Upload den rohen Dateityp ablehnt

Eine einzelne Datei in ein .zip zu verpacken, dient weniger dem Verkleinern als vielmehr dem Passieren einer Sperre. Viele Mailserver und Web-Upload-Felder lehnen einen rohen Anhang mit .exe, .js, .bat oder .html aus Sicherheitsgründen stillschweigend ab, akzeptieren dieselben Bytes aber, sobald sie in einem .zip-Container liegen. Ziehen Sie die eine Datei in das Upload-Feld, klicken Sie auf die Schaltfläche Zip, und das Archiv behält den ursprünglichen Dateinamen samt Endung in seinem Inneren bei, sodass der Empfänger genau das entpackt, was Sie gesendet haben. Rechnen Sie damit, dass die Verpackung nur wenige hundert Byte Overhead hinzufügt: eine 3 MB große kompilierte Binärdatei oder ein 4 MB großes PDF kommt als .zip von ungefähr gleicher Größe zurück, weil diese Formate bereits codiert sind und kaum noch etwas zum Zusammendrücken übrig bleibt. Das ist der Handel, den der Einzeldatei-Ablauf eingeht - Sie gewinnen einen Zustellumschlag, den das empfangende System akzeptiert, keinen kleineren Download, greifen Sie also dann dazu, wenn ein Upload-Formular Ihren Dateityp verweigert, und nicht, wenn Sie eine Größengrenze unterschreiten müssen.
