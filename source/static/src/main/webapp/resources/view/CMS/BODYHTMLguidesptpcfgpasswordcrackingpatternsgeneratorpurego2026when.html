Quando Usar o Gerador de Padrões de Senha PCFG

Última revisão: 2026-10-06

Recorra ao Gerador de Padrões de Senha PCFG quando quiser mostrar, não apenas dizer, por que uma senha é fraca: ele cria strings de exemplo reais que seguem as estruturas que os modelos de adivinhação tentam primeiro. É uma ferramenta de ensino e teste de políticas, não um medidor de força ou um cofre.


Quando é adequado

Serve para sessões de conscientização sobre segurança, revisões de política de senhas e criação de dados de teste. Amostrar estruturas por frequência real mostra, em uma única tela, por que "letras seguidas de dígitos" e "só letras" cobrem a maioria das senhas humanas, e o rótulo L/D/S junto a cada exemplo torna o ponto concreto. O modo forte uniforme-aleatório oferece um contraste seguro no mesmo lugar.


Estruturas básicas comuns, em resumo

As participações são aproximadas, extraídas de análises públicas de conjuntos de senhas vazadas; são ilustrativas, não uma medição em tempo real.


Quando escolher outra coisa

Se você só quer avaliar uma senha que já tem, use um verificador de força. Se precisa de uma senha para guardar de fato, gere uma no modo forte uniforme-aleatório e salve em um gerenciador de senhas. Esta ferramenta nunca avalia uma senha colada, armazena nada, ou contata um banco de dados de violações - cada string permanece no seu navegador.
