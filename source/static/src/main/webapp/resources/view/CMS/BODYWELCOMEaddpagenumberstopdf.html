Add Page Numbers to PDF

Last reviewed: 2026-07-22

Add page numbers to every page of a PDF, right in the browser.

How it works

Upload the PDF, pick the starting number, and click Add page numbers - the download prints "Page N" centered at the bottom of every page, counting up from the number you chose, so a multi-page report or contract gets a consistent running count without opening a desktop editor.

What it does not do

Applies one fixed bottom-center style and numbering sequence - does not support custom position, custom text/format, skipping a numbered cover page, or restarting the count partway through the document.

Your files stay private

The PDF you number stays inside this browser tab from upload to download - the numbering runs on your own device, so the document is never sent to or stored on a server.

Starting number, blank fields, and one file at a time

The starting-number field defaults to 1 and accepts any whole number 1 or higher. Leave it blank, or type 0 or a negative value, and add page numbers to PDF clamps it back to 1 automatically instead of failing - the tool never crashes on a bad starting number, it just numbers from page one. The file picker also accepts exactly one PDF per run: there is no batch mode here, so a folder of contracts or reports gets numbered one document at a time, each with its own starting count if you want reports to continue a running total across files rather than restart at 1 for every one.

The exact print specs behind "Page N"

The number that lands on each page is printed in 11-point Helvetica, in a medium gray (roughly 35% black), at 90% opacity, positioned 18 points up from the bottom edge and centered horizontally based on the rendered width of the label text - so "Page 1" and "Page 12" both land dead-center even though the two labels are different widths. That fixed spec is the same on every page of the document; there is no option to bump the font size, switch to a darker or colored ink, move the number to a top or corner position, or add surrounding text such as "of 24" - add page numbers to PDF prints the bare running number and nothing else.

What the downloaded file is named

Whatever the original PDF was called, the numbered copy always downloads as numbered.pdf - add page numbers to PDF does not preserve or reuse the source filename. If a naming scheme matters for the finished document (a client name, a date, a version tag), rename the downloaded file after it lands rather than relying on the tool to carry the original name across. If the uploaded file cannot be read as a PDF at all, add page numbers to PDF shows a plain status message explaining that the file could not be processed instead of leaving the page stuck or throwing a silent error.
