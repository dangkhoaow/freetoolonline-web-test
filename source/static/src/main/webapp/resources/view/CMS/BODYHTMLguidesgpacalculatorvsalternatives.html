The GPA Calculator is one of a few common ways to work out a weighted average across courses: a browser-based tool like this one, a spreadsheet formula, or a desktop grade-tracking app. Each trades off differently on setup time and where your data goes.

Use this tool when you want the result immediately with no formula to write. Use a spreadsheet instead when you already track grades there and want the GPA alongside other class data.

For a single straightforward percentage - a discount, a tax add-on, or a plain percent change - use the Percentage Calculator instead; a weighted GPA and a plain percentage are different calculations.

The calculation runs locally in the browser - no upload and no account.
