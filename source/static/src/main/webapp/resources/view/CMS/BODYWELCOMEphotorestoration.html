AI Photo Restoration

Last reviewed: 2026-08-23
freetoolonline.com editorial team

Sharpen, denoise, and upscale a blurry or compressed photo - 2x or 4x - right in this browser - no upload, no app to install.

Modes and first-run download

The first run downloads the model for the mode you picked once (about 8 MB for 2x, about 55 MB for 4x; cached offline after that); on the WASM fallback (no WebGPU) the 4x mode can take up to a minute to finish - the original photo previews immediately while you wait.

Private by design

Everything runs locally via Transformers.js / ONNX Runtime Web - the photo is never uploaded to a server; only the model weights load from the Hugging Face hub.

If something in the frame should go before you enlarge it - a stray object, a photobomber, a watermark - the object remover erases it first, the same way: entirely on your device, no upload.
