ROI-Rechner Online verwenden - Schritt fur Schritt

Zuletzt uberprüft: 2026-07-30

Der ROI-Rechner Online berechnet die Kapitalrendite in drei Schritten. Geben Sie den Einsatz ein, geben Sie den Ertrag ein und lesen Sie das Ergebnis - keine Installation und kein Konto erforderlich.

Schritt 1 - Anfangsinvestition eingeben

Geben Sie den investierten Gesamtbetrag in das Feld "Anfangsinvestition" ein. Dies ist das eingesetzte Kapital - der Kaufpreis von Aktien, das Budget einer Kampagne oder der bezahlte Immobilienpreis.

Schritt 2 - Endwert eingeben

Geben Sie den erhaltenen Gesamtertrag in das Feld "Endwert" ein. Bei Aktien ist das der Verkaufspreis. Bei einer Kampagne ist es der dem Einsatz zugeschriebene Umsatz. Das Ergebnis aktualisiert sich beim Tippen.

Schritt 3 - Haltedauer hinzufugen (optional)

Wenn Sie die Investition langer als ein Jahr gehalten haben, geben Sie die Anzahl der Jahre ein. Das Tool zeigt die jahrliche Rendite neben dem Gesamt-ROI an, sodass Sie Investitionen mit unterschiedlichen Laufzeiten vergleichen konnen.
