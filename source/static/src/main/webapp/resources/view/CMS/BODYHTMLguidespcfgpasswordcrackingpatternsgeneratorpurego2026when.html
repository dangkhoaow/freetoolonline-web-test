When to Use the PCFG Password Pattern Generator

Last reviewed: 2026-10-04

Reach for the PCFG Password Pattern Generator when you want to show, not just tell, why a password is weak: it builds real example strings that follow the structures guessing models try first. It is a teaching and policy-testing tool, not a strength meter or a vault.


When it fits

It fits security-awareness sessions, password-policy reviews, and test-data creation. Sampling structures by real-world frequency shows, in one screen, why "letters then digits" and "all letters" cover most human passwords, and the L/D/S label beside each example makes the point concrete. The strong uniform-random mode gives you a safe contrast in the same place.

When to pick something else

If you only want to score a password you already have, use a strength checker. If you need a password to actually keep, generate one in the strong uniform-random mode and save it in a password manager. This tool never scores a pasted password, stores anything, or contacts a breach database - every string stays in your browser.
