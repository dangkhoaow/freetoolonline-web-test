A ten-second check before you upload: open the source PDF and try to highlight a sentence with your cursor. If the words select, the file has a real text layer and extraction will come back clean; if nothing selects, the page is a scan or a photo with no text underneath, and OCR (optical character recognition) has to run first - a separate step this tool does not perform. That one test saves a round trip for the files it would otherwise return empty.
