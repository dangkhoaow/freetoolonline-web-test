Warum "Zip-Datei-Konverter" eine irreführende Suche ist

"In ZIP konvertieren" klingt wie JPG zu PNG oder HEIC zu JPG konvertieren, aber ZIP arbeitet auf einer anderen Schicht. JPG, PNG und HEIC sind Bildformate - sie beschreiben, wie Pixel innerhalb einer Datei codiert sind. ZIP ist ein Archivformat - es wickelt eine beliebige Anzahl von Dateien (jedes Formats) in einen einzigen .zip-Container und wendet allgemeine Komprimierung auf die Bytes an. Die Originaldateien behalten ihre Originalformate innerhalb des Archivs. Wenn Sie entpacken, erhalten Sie die gleichen JPGs, PDFs und DOCXs, mit denen Sie angefangen haben.

Das bedeutet, ein "Zip-Datei-Konverter" macht eigentlich eine von zwei Sachen, je nach Richtung. Hinein: Ihre losen Dateien nehmen und eine einzige .zip produzieren - das ist "erstellen" oder "bündeln", nicht "konvertieren". Hinaus: eine .zip lesen und jede Datei als sich selbst zurück schreiben - das ist "extrahieren" oder "entpacken", auch nicht "konvertieren". Das Wort "Konverter" bleibt hängen, weil jede andere Dateioperation im Browser Konverter heißt, aber die Mechanik hier ist anders.

Was ZIP wirklich komprimiert (und nicht komprimiert)

Was ZIP wirklich komprimiert (und nicht komprimiert) ist Text und viele Office-Dateien gut, während schon komprimierte JPG, MP4 und PDF oft kaum schrumpfen - Zip Compressor erfindet keine freien Bytes aus Medien.

  • Text, Code, CSV, Log-Dateien: 60-90% kleiner. Echte Komprimierung.
  • Office-Dokumente (DOCX, XLSX, PPTX): 1-5% kleiner. Diese sind intern bereits ZIP-Dateien.
  • JPG-, PNG-, WebP-, HEIC-Fotos: 0-2% kleiner. Der Bild-Codec hat die Pixel bereits komprimiert.
  • MP3-, AAC-, FLAC-, OGG-Audio: 0-1% kleiner. Bereits entropie-optimiert.
  • MP4-, MOV-, MKV-, WebM-Video: 0-1% kleiner. Am stärksten komprimiertes Format im allgemeinen Gebrauch.

Für Ordner, die von Fotos oder Videos dominiert sind, geht es beim ZIP-Schritt hauptsächlich um Bündeln (ein Download statt fünfzig), nicht um Schrumpfen. Wenn das Ziel war, eine einzelne grosse Mediendatei tatsächlich zu schrumpfen, ist ZIP das falsche Tool - greifen Sie zu Bildkomprimierung bei einem Foto (Compress Image), Formatkonvertierung bei iPhone-HEIC (HEIC to JPG), oder einem Datei-Transfer-Link für ein Video.

Häufig gestellte Fragen

Ist ZIP ein Dateiformat, in das ich vor dem Senden "konvertieren" sollte?

Nur wenn Sie mehrere Dateien für einen Empfänger haben. ZIP ist die richtige Antwort, wenn die Alternative ist, fünf Anhänge separat zu senden - eine .zip ist einfacher auf beiden Seiten. Für eine einzelne Datei ist ZIP unnötig und schrumpft sie oft nicht. Senden Sie die Datei selbst, oder komprimieren Sie sie direkt mit dem richtigen Tool pro Format (Compress Image für Fotos).

Warum endet meine .zip fast in derselben Größe wie die Originale?

Weil die Originale bereits komprimiert waren. JPG, MP3, MP4 und moderne Office-Dokumente tragen alle ihre eigene Komprimierung intern; DEFLATE innerhalb von ZIP kann die gleichen Bytes nicht ein zweites Mal quetschen. Wenn das Bündel immer noch zu groß zum Senden ist, ist die Antwort kein stärkerer Kompressor - es ist Komprimierung pro Format auf den größten Elementen oder ein Datei-Transfer-Link für Video.

Sollte ich 7z oder RAR statt ZIP verwenden?

Verwenden Sie ZIP, ausser Sie haben einen Grund. ZIP öffnet nativ auf Windows, macOS, iOS und Android ohne zusätzliche Software; 7z und RAR brauchen eine separate App auf der Seite des Empfängers. Der Komprimierungsverhältnis-Vorteil von 7z ist klein bei den Dateitypen, die Leute tatsächlich senden (bereits komprimierte Medien).
