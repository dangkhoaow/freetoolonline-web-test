Live AQI Checker by City - Kapan Digunakan

Last reviewed: 2026-08-04

Live AQI Checker by City layak dibuka saat Anda perlu pengecekan cepat sekali pakai tanpa instalasi apa pun. Halaman ini membahas kapan itu cocok dan kapan tidak.


Kapan cocok

Tabel perkiraan AQI puncak 3 hari di bawah hasil menjawab apakah kualitas udara akan membaik besok - berguna saat asap kebakaran hutan atau lonjakan polusi.


Yang bisa diharapkan

Data diambil langsung dari API kualitas udara gratis milik Open-Meteo - tidak ada yang diunggah dan tidak perlu akun; pencarian kota memakai API geocoding Open-Meteo.

Hanya menampilkan kualitas udara ambien luar ruangan - bukan pembacaan sensor udara dalam ruangan dan bukan pengganti himbauan kesehatan setempat saat ada asap.
