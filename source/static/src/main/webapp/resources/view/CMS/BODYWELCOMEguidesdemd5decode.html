Mehr Tiefe: die fünf echten Aufgaben hinter "MD5 decode"

Das Wort decode legt einen umkehrbaren Schritt nahe, doch MD5 erzeugt einen 32-stelligen Hexadezimal-Fingerabdruck, den kein Werkzeug in den ursprünglichen Text zurückverwandeln kann; deshalb steht dieses Wort fast immer für eine von fünf konkreten Aufgaben. Um aus Text einen Fingerabdruck zu bauen, öffnen Sie den MD5-Konverter und drücken die Schaltfläche To MD5; um den Text hinter einem vorhandenen Hash zu suchen, drücken Sie auf derselben Seite die Schaltfläche To Text, die zuerst die im localStorage Ihres Browsers gespeicherten Paare prüft und erst danach das Server-Wörterbuch abfragt, sodass ein nie zuvor gehashter Wert leer zurückkommt. Eine Datei zu prüfen ist eine ganz andere Aufgabe - dort vergleichen Sie zwei 32-Hex-Zeichenketten auf exakte Gleichheit, und MD5-Hashes korrekt lesen und vergleichen zeigt die Fallen, die identische Dateien unterschiedlich aussehen lassen, etwa Groß- gegen Kleinschreibung im Hex oder ein verirrtes führendes Leerzeichen. Passwörter zu speichern ist die eine Aufgabe, bei der MD5 ganz aufgegeben werden sollte: eine MD5-Alternative wählen legt den Kompromiss Zeile für Zeile dar, mit bcrypt und argon2id für Web-Logins, scrypt wenn Speicherhärte zählt und sha256-with-hmac für API-Tokens. Und wenn Sie die Mathematik dahinter wollen, warum Umkehrung unmöglich ist, statt einer Abkürzung, ist warum MD5 nicht entschlüsselt werden kann die Vertiefung.
