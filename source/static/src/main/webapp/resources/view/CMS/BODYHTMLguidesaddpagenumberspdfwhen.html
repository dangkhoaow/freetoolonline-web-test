Add Page Numbers To Pdf When To Use

Last reviewed: 2026-09-06

Add Page Numbers to PDF is worth opening when you need a quick, one-off run without installing anything. This page covers when that fits and when it does not.


When it fits

Applies one fixed bottom-center style and numbering sequence - does not support custom position, custom text/format, skipping a numbered cover page, or restarting the count partway through the document.


What to expect

The file is processed in this browser tab and is never uploaded to a server.

To split, merge, rotate, delete pages from, or watermark the PDF instead, see the related-tools section.


Starting number and one file at a time

Add Page Numbers to PDF shows a "Start numbering at" field before you run it. It defaults to 1, so leave it alone for a plain Page 1, Page 2, Page 3 sequence, or enter a different whole number - for example 5 - to have the first page read "Page 5" instead, which is useful when the file will be bound after a cover page or a document that already ends on page 4. The tool numbers one PDF at a time; it does not accept several files in a single run the way the merge tool on this site does. If several documents need one continuous numbering sequence, join them first with Join PDF from multiple files, then run this tool once on the combined result - running it separately on each source file would restart the count at 1 every time.

Frequently Asked Questions

What number does page numbering start at by default?

1. Enter a different whole number in the "Start numbering at" field before running the tool if you want the first page labeled something else, such as 5.

What happens if I leave the starting number field blank or type something invalid?

Add Page Numbers to PDF falls back to 1 automatically - it does not fail or refuse to run.

Can I add page numbers to more than one PDF in a single run?

No. This tool processes one PDF file at a time. To number pages across multiple documents as one continuous sequence, merge them first with Join PDF from multiple files, then run this tool on the merged file.

What is the downloaded file named?

numbered.pdf, regardless of the name of the file you uploaded.

Does the tool tell me the size of the finished file?

Yes. After processing, the status line shows the resulting file size so you can confirm the download before you open it.

Can I add page numbers to a password-protected PDF?

Only if you have the password. Run the file through Remove PDF Password first, then add page numbers to the copy that no longer needs a password - the same restriction applies to this site's merge and split PDF tools, which share the same in-browser engine.

If I add or remove pages later, does the numbering update automatically?

No. The numbers are printed directly onto each page in the file you download, so inserting, deleting, or reordering pages afterward will not shift them. Run the tool again on the updated file to get a fresh, correctly ordered sequence.

Should numbering be the last step, or can I do it before splitting, rotating, or merging?

Number last. Because the page numbers are baked into the page content rather than tracked separately, any splitting, deleting, rotating, or merging done after numbering can leave the printed numbers out of step with the new page order.
