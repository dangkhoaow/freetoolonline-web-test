It is honest about limits - an indicative browser benchmark, not a lab-grade suite; device heat, battery mode, and other tabs shift the numbers, so compare scores only between runs on the same device and browser.

Inside the escalating benchmark - how the nine tiers scale in depth

The benchmark climbs through nine tiers, doubling the instance count at each step from 1,000 icosahedrons up to 256,000, all drawn from a single InstancedMesh so the number reflects raw geometry throughput rather than draw-call overhead. Every tier opens with a one-second warmup that is thrown away, then three seconds of measured frames whose median frame time sets that tier's FPS; the run advances to the next tier only while the median holds at 55 FPS or better and stops at the first tier that falls below. Frame rates above 60 are counted as 60 when scoring, and the score sums instances times that capped FPS across completed tiers and divides by 1,000, so a 120 Hz display cannot inflate the total past an ordinary 60 Hz screen. A per-tier results table records what each step reached, and a rating line names the highest tier your device held at 45 FPS or more. You can end a run early with the Cancel button, and the test also aborts itself if you switch to another tab or the browser loses its WebGL context, since throttled background frames would otherwise corrupt the median.
