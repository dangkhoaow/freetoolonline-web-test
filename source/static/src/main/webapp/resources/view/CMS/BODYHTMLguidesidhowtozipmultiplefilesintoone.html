Cara Membundel Beberapa File ke Satu ZIP

Direview terakhir: 2026-04-27. Buka alat zip untuk menggabungkan file di browser Anda tanpa mengunggahnya.

Jawaban 30 detik. Membundel beberapa file ke dalam satu zip membutuhkan empat langkah di alat zip: pilih file, beri nama output (sesuatu yang deskriptif, tanpa spasi jika email adalah tujuan), atur kompresi Default untuk konten campuran atau Store untuk media yang sudah terkompresi, dan klik Unduh.

Empat langkah secara rinci

  1. Pilih file. Drag-and-drop adalah jalur tercepat di desktop; pemilih multi-file berfungsi di telepon. Alat menerima semua jenis file.
  2. Beri nama output. Alat secara default archive.zip - berfungsi tetapi tidak memberi tahu apa-apa kepada penerima. 2026-Q1-faktur.zip atau foto-liburan.zip mengurai lebih baik.
  3. Atur level kompresi. Default (level 6) untuk campuran. Best (level 9) ketika file sebagian besar adalah teks. Store (level 0) ketika semua di dalamnya sudah terkompresi.
  4. Unduh. Browser memberikan arsip yang sudah jadi. File asli tetap tidak tersentuh.

Seberapa kecil ukuran ZIP-nya

Efektivitas kompresi bergantung pada jenis isinya, bukan pada jumlah file yang dipilih.

Jenis filePengurangan ukuran umum
Teks, kode sumber, CSV, JSONLebih kecil 60-80%
Dokumen Office (Word, Excel, PowerPoint)Lebih kecil 10-25%
PDFLebih kecil 5-15%
Foto yang sudah terkompresi (JPG, PNG, HEIC)Lebih kecil 0-5%

Apa yang tidak dilakukan alat

Apa yang tidak dilakukan alat pada Cara membundel beberapa file ke satu ZIP adalah enkripsi default, sync ke cloud, atau mengganti nama setiap file - hanya mengemas yang Anda jatuhkan.

  • Menambahkan kata sandi saat pembuatan. Untuk arsip yang dilindungi kata sandi, lihat zip file dengan kata sandi.
  • Mempertahankan struktur folder lintas beberapa pilihan drag-and-drop. Jika Anda butuh tata letak bersarang di dalam zip, seret folder induk.
  • Mengedit file sebelum zip. Kompres gambar terlebih dahulu dengan kompres gambar jika ukuran penting.

Untuk alur kerja zip lainnya: file ke ZIP memandu pembuatan file langkah demi langkah; kompres file ZIP ke 2 MB menjelaskan cara memenuhi batas ukuran. Untuk lainnya, hub alat zip.

Pertanyaan yang sering diajukan

Apa yang saya dapatkan setelah men-zip beberapa file?

Satu arsip ZIP yang membundel setiap file yang Anda pilih. Unduh sebagai satu file; penerima mengekstraknya kembali ke tata letak yang sama seperti yang Anda kirim, termasuk struktur folder yang dipertahankan.

Mengapa folder foto hampir tidak mengecil saat di-zip?

File JPG, PNG, dan HEIC sudah dikompresi oleh formatnya sendiri. Membundel beberapa file seperti itu ke dalam satu ZIP hampir hanya mengemasnya - ukuran hanya turun 0-5%. Jika folder sebagian besar berisi foto dan ukuran penting, kompres gambar terlebih dahulu dengan kompres gambar, lalu zip hasilnya.

Ke mana file saya pergi selama ZIP dibuat?

Tidak ke mana-mana. ZIP dibuat sepenuhnya di perangkat Anda - file yang Anda pilih tidak pernah keluar dari browser Anda dan tidak ada langkah unggah. Setelah arsip siap, browser membuat tautan unduhan langsung dari ZIP yang sudah jadi di memori.
