Run camera test first to confirm webcam framing (front or rear), then microphone test for the audio level, then LCD test for the full-screen color cycle that surfaces dead pixels, and finally keyboard test to confirm every key registers. A flaky webcam caught at step one saves the time you would have spent on steps two through four; the order is deliberate, not alphabetical.
