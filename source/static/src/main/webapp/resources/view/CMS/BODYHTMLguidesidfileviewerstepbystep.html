File Viewer Langkah demi Langkah

Last reviewed: 2026-08-26

File Viewer berjalan dalam tiga langkah: buka alatnya, masukkan data Anda, lalu salin hasilnya. Halaman ini menjelaskan apa yang diperlukan pada setiap langkah.


Langkah 1 - buka alatnya

Buka File Viewer. Tidak ada yang perlu dipasang atau login sebelum Anda mulai.


Langkah 2 - masukkan data Anda

Dapat dicari berdasarkan nama field atau nilai melalui kotak pencarian.


Langkah 3 - salin hasilnya

Data masukan tidak diunggah ke server.

Untuk akses secara terprogram, lihat developer-tools terkait.
