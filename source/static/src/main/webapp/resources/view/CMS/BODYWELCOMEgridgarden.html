How the 28 levels build on each other

The 28 levels move through grid properties in roughly the order a real layout needs them: the early levels only ask for grid-column-start or grid-row-start to place a single item, the middle stretch introduces grid-template-columns and grid-template-rows to size the whole grid, and the final handful combine shorthand like grid-template and grid-area in one rule. By around level 20 a correct answer often chains two or three properties together instead of one, for example grid-column-start: 3; grid-row-start: 2; so both values have to match before the carrot patch waters. Each level's instruction panel names the exact property it is testing, so typing a near-miss like grid-column instead of grid-column-start leaves the patch dry and the Next button stays inactive. Because the sequence is cumulative, a level in the mid-to-late 20s can ask you to recall a property from ten or more levels earlier rather than teaching something new, which is the part a short summary of "CSS grid game, 28 levels" tends to skip.
