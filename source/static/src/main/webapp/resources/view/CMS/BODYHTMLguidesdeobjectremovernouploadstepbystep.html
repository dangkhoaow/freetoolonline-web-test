Objekt im Browser aus dem Foto entfernen - Schritt für Schritt

Last reviewed: 2026-08-14
freetoolonline.com Editorial Team

Diese Anleitung führt einmal komplett durch den Object Remover: Foto öffnen, das Störende übermalen, KI-Füllung oder den sofortigen Quick patch wählen und das Ergebnis als PNG sichern. Jeder Schritt findet auf Ihrem eigenen Gerät statt.


Erst das Beispiel ansehen, dann etwas öffnen

Beim Laden der Seite steht bereits ein vorbereitetes Vorher-Nachher-Paar auf dem Bildschirm - ein Foto mit einem Objekt und dasselbe Foto mit gelöschtem Objekt und gefüllter Lücke. Es erscheint ohne Klick und ohne Download und ist als vorab erstellt gekennzeichnet. Zehn Sekunden mit diesem Paar zeigen, wie eine fertige Füllung aussieht, bevor Ihr eigenes Bild ins Spiel kommt.


Der Durchlauf, Bedienelement für Bedienelement

SchrittBedienelementWas passiert
1Foto wählenDas Bild öffnet sich auf einer Leinwand in der Seite; es wird nirgendwohin gesendet
2Regler für die PinselgrößeLegt die Strichbreite fest, von 8 bis 80 Pixel, damit sich ein dünnes Kabel und eine ganze Person gleichermaßen sauber maskieren lassen
3Maske malenMit dem Zeiger ziehen, auf Touchscreens mit dem Finger; die bemalte Region erscheint als roter Schleier über dem Foto
4Objekt entfernen (KI)Der erste Klick startet einen einmaligen Modell-Download von rund 27 MB; danach wird die bemalte Region mit passendem Hintergrund gefüllt
5Quick patchDie Alternative ohne Download: füllt die bemalte Region sofort aus den umliegenden Pixeln, mit geringerer Qualität
6Maske löschenEntfernt den roten Schleier, damit Sie neu malen und es noch einmal versuchen können
7HerunterladenSichert das bearbeitete Bild als Standard-PNG

Schritt 4 im Detail: der einmalige Download

Das KI-Modell wird nur geladen, wenn Sie den KI-Knopf drücken, nie im Hintergrund, und die Größe - rund 27 MB - steht auf der Seite, bevor Sie beginnen. Nach diesem ersten Laden behält der Browser das Modell im Cache; ein zweites Objekt zu entfernen, heute oder nächste Woche, kostet keinen Download mehr. Das Laden selbst braucht eine Netzverbindung; sind Sie gerade ohne Internet, funktioniert der Quick-patch-Weg trotzdem.


Ihre Auflösung geht nicht verloren

Damit die Füllung schnell bleibt, arbeitet das Modell auf einer Bildversion, deren lange Kante auf 1024 Pixel begrenzt ist. Die Seite setzt das Ergebnis anschließend so zusammen, dass jeder nicht bemalte Pixel das Original in voller Auflösung bleibt - nur die bemalte Region trägt Modellausgabe. Ein 4000-Pixel-Foto kommt als 4000-Pixel-Foto zurück.


Wenn die Füllung falsch aussieht

Maske löschen und erneut malen, diesmal enger. Das Modell liefert am meisten, wenn der Strich das Objekt eng umschließt und der Hintergrund ringsum Himmel, Wand, Boden, Wasser oder eine andere sich wiederholende Textur ist, die es fortsetzen kann. Ein sehr großes Motiv vor unruhigen, einmaligen Details füllt sich womöglich nie sauber - das Modell erfindet plausiblen Hintergrund, statt wiederherzustellen, was wirklich hinter dem Objekt lag; prüfen Sie deshalb jedes Ergebnis vor dem Behalten. Als schnelle, grobe Alternative den Quick patch auf derselben Maske laufen lassen und vergleichen.


Ein Foto nach dem anderen

Einen Stapel- oder Ordnermodus gibt es nicht; jeder Durchlauf bearbeitet ein einzelnes Bild, und nichts bleibt erhalten, wenn Sie die Seite verlassen. Ist Ihr eigentliches Ziel ein transparenter Freisteller statt eines gelöschten Objekts, wechseln Sie zum Background Remover - das ist eine andere Aufgabe, die diese Seite bewusst auslässt.
