How to check earthquakes near you:
  1. Pick a time window - past hour, past day, or past week.
  2. Pick a minimum magnitude to filter out the smallest, rarely-felt events.
  3. Press "Check earthquakes" to load the current results from the USGS feed.
  4. Press "Sort by distance from me" and allow location access to re-sort the list nearest-first, with a distance column added.
