File Viewer Schritt für Schritt

Last reviewed: 2026-08-26

File Viewer läuft in drei Schritten ab: Tool öffnen, Eingabe bereitstellen und dann das Ergebnis kopieren. Diese Seite erklärt, was jeder Schritt erwartet.


Schritt 1 - Tool öffnen

Rufen Sie File Viewer auf. Vor dem Start muss nichts installiert werden und keine Anmeldung ist nötig.


Schritt 2 - Eingabe bereitstellen

Durchsuchbar nach Feldname oder Wert über das Suchfeld.


Schritt 3 - Ergebnis kopieren

Eingaben werden nicht hochgeladen.

Für den programmatischen Zugriff siehe die zugehörigen developer-tools.
