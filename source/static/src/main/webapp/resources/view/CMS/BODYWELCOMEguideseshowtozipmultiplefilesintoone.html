Qué nivel de compresión elegir

Ajusta el nivel de compresión al contenido del archivo. La herramienta ofrece tres niveles; la tabla siguiente muestra para qué sirve mejor cada uno.

Nivel de compresiónIdeal paraResultado
Store (0)Archivos ya comprimidos (MP4, JPG, HEIC)El más rápido; el tamaño baja solo un 0-5%
Default (6)Una mezcla de documentos y mediosEquilibrio entre velocidad y tamaño
Best (9)Sobre todo texto, código o PDFZIP más pequeño; más lento con entradas grandes
