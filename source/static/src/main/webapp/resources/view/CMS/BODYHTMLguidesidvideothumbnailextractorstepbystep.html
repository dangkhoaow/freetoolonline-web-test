Mengekstrak thumbnail dari video - langkah demi langkah

Terakhir ditinjau: 2026-09-17

Ekstraktor thumbnail video mengambil satu frame diam dari video pada titik waktu mana pun, sepenuhnya di browser - pilih file, geser ke momennya, lalu unduh frame itu sebagai PNG atau JPEG. Video tidak pernah diunggah ke server. Berikut setiap langkah dan apa yang akan terjadi.


Langkah 1 - buka alatnya dan lihat frame demo

Buka halaman ekstraktornya. Sebuah frame contoh dari klip kecil bawaan langsung muncul begitu halaman selesai dimuat, jadi Anda bisa memastikan ekstraktornya berjalan di browser Anda sebelum menyentuh file sendiri. Tidak ada yang perlu dipasang dan tidak perlu akun.


Langkah 2 - pilih video Anda

Gunakan pemilih file di bagian atas. MP4 (H.264) dan WebM berjalan di browser umum; MOV, M4V dan OGV tergantung browser. File terbuka langsung di pemutar milik halaman ini - file tidak pernah meninggalkan perangkat Anda. Jika browser tidak bisa mendekode codec-nya, halaman menampilkan pesan yang jelas alih-alih gambar hitam tanpa keterangan.


Langkah 3 - geser ke momen yang tepat

Geser slider waktu di bawah pratinjau. Pratinjau menunjukkan frame tempat Anda berada, dan frame yang Anda lihat adalah frame yang Anda simpan - tidak ada pengodean ulang antara pratinjau dan penyimpanan.


Langkah 4 - pilih format gambar

PNG adalah bawaan dan tanpa kehilangan kualitas. Beralihlah ke JPEG saat butuh file lebih kecil, dengan kualitas 95, 85 atau 70 persen. Apa pun pilihannya, frame diambil pada resolusi asli video.


Langkah 5 - tangkap dan unduh

Tekan "Capture this frame". Kartu thumbnail muncul dengan stempel waktu dan ukuran piksel, plus tautan unduh sendiri. Nama file membawa nama video sumber dan stempel waktunya, misalnya myclip-t2.5s.png, sehingga folder hasil tangkapan tetap mudah diurutkan.


Opsional - lembar kontak 6 frame

"Grab 6 evenly spaced frames" menangkap satu frame dari tiap seperenam klip dengan sekali klik - gambaran umum seluruh video tanpa menyusuri timeline secara manual. Anda bisa mengambil hingga 24 thumbnail per sesi.


Apa yang tidak dilakukan alat ini

Alat ini hanya menangkap frame diam: tidak mengonversi, memotong, atau menyunting video, dan tidak bisa membuka stream yang dilindungi DRM. Untuk file GIF gunakan ekstraktor frame GIF. Untuk kasus-kasus di mana pengambilan frame paling berguna, lihat kapan memakainya; untuk membandingkan dengan tangkapan layar dan pemutar desktop, lihat perbandingan alternatif.
