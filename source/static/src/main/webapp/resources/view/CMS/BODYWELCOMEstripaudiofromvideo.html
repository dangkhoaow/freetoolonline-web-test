Remove Audio from Video

Last reviewed: 2026-09-02

Remove the audio track from a video and keep everything else - picture, resolution, and file format stay exactly as they were. It is a single-click job on the whole file, done right in this browser tab.

What gets removed and what stays

The audio track is dropped in full while the video stream is copied byte-for-byte, with no re-encode, so the operation itself adds no quality loss. The output uses the same container and codec as the input and keeps the original extension, with a -no-audio suffix added to the filename. This mode removes the sound all at once; it does not selectively mute or duck one part of the clip. Because nothing is re-encoded, there are no extra settings and no start or end time fields to set for this mode.

Where the video is processed

Everything runs inside this browser tab through FFmpeg.wasm, self-hosted on this site and the same engine that powers the video trimmer here. Your file is read, processed, and saved back to your device locally; it is never uploaded to a server. Nothing is installed, no account is required, and the file is not kept once you leave the page. The only network request is the one-time load of the tool's own script and engine files from this same site.

Which files work and which are rejected

The input has to be a real video container - something like MP4, MOV, or WebM that actually holds a video track. Audio-only files such as MP3, WAV, AAC, OGG, FLAC, or M4A are turned away with a clear error before any processing starts, because once the sound is removed there would be nothing left to keep. DRM-protected or encrypted video also will not work: if a file only plays inside a locked-down app or store, the tool fails on it rather than silently stripping a track it cannot read.

When to trim or convert the video instead

Stripping audio leaves the length and format of the video alone. To shorten a clip, cut out a section, or keep only part of it, use a trimmer rather than this tool. To change the video into a different format, use the matching converter, because this mode does not re-encode to a new format. Links to those related tools appear in the section just below.

Why the first file takes longer than the next one

The first time Remove Audio from Video runs in a browser tab, it downloads FFmpeg.wasm - the WebAssembly engine that does the actual audio removal - directly from this site. The status line says exactly that: "Loading FFmpeg.wasm (~31MB, one-time)...". Every file processed after that, in the same tab, skips the download because the engine is already loaded in memory, so only the first file waits on it. Once the engine is ready and the audio is being removed, that loading text is replaced by a live percentage, such as "Removing audio: 42%", so there is something to watch instead of a blank status line. Closing the tab or reloading the page clears the loaded engine, so the download happens again on the next visit; how much of that repeat download is served from the browser's own cache rather than downloaded again depends on the browser, not on this tool.

What happens if the file cannot be processed

If Remove Audio from Video cannot process the uploaded file, most often because it is not really a video underneath its file extension or the video data itself is corrupted, the tool does not fail silently or hang. FFmpeg's own error message is shown directly inside a red result panel headed "Remove Audio from Video:", so the specific reason processing stopped is visible rather than a generic failure notice. A separate edge case, no file object being received at all, shows the same red panel with the text "No file received." instead. Neither case produces a download; the result area stays empty until a file is actually stripped successfully. Even on success, nothing downloads by itself - a "Download" link appears labeled with the exact output filename, and it has to be clicked by hand, the same as with any other file this tool produces.
