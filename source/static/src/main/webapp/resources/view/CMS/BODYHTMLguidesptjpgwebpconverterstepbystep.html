Converter JPG para WebP - passo a passo

Last reviewed: 2026-07-26
freetoolonline.com Editorial Team

Abra o JPG to WebP Converter, escolha um JPG neste dispositivo, ajuste a qualidade se precisar de um ficheiro menor e descarregue o WebP - a conversão em canvas não envia a imagem.


Passo 1 - abrir o conversor

Abra o JPG to WebP Converter. Nada para instalar nem iniciar sessão. A página monta um canvas HTML5 no separador para descodificar o JPG localmente.


Passo 2 - fornecer o JPG (fica neste dispositivo)

Escolha um ficheiro .jpg/.jpeg. O browser abre-o com um object URL local - sem ida ao servidor com os bytes de origem. Use quando o CMS ou o alojamento pede WebP mas o pipeline ainda exporta JPG.


Passo 3 - qualidade e descarga WebP

Ajuste as opções acima do seletor se precisar de um WebP menor; os padrões servem entrega web comum. A página recodifica no canvas e exporta um blob só do lado do cliente. Comparação: JPG para WebP vs alternativas. Decisão de contentor: quando usar o conversor.
