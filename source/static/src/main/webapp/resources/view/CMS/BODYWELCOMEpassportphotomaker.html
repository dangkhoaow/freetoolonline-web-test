Passport Photo Maker

Last reviewed: 2026-09-04

Crop a photo to an exact passport or visa photo size, right in this browser - no upload, no app to install.


Key features

  • Country and document presets: US and India 2x2in, Schengen, EU, UK and Australia 35x45mm, Canada 50x70mm, China visa 33x48mm, or a custom size in millimeters.
  • Drag the photo on the crop stage to position the face and use the zoom slider to fill the frame; dashed "top of head" and "chin" guide lines plus a center line help you line it up (visual aids only, no face detection).
  • The final photo is composited onto a plain white background at the preset's exact pixel size, computed at 300 DPI for print quality - a 2x2in preset renders at 600x600px.
  • Optionally check "Also generate a 4x6in print sheet" to download a tiled sheet with as many copies of the cropped photo as fit on one page.

When to use the AI backdrop

Took the photo against a bookshelf or a colored wall? Pick an AI backdrop before generating and an on-device portrait-matting model re-composites the person onto plain white, light blue, or light grey - the plain backdrops photo offices ask for. The ~26 MB model downloads once, stays cached in this browser, and is shared with the Background Remover tool, so there is nothing new to download if you already used that. The AI backdrop is opt-in: the default keeps the photo's own background with no download, and if the AI cannot run the plain white-fill crop is still delivered and the status message says so. For a transparent PNG or a blurred background, use the Background Remover; this page makes document-sized prints.


Privacy and how it works

Everything runs locally via the Canvas API - the chosen photo is opened directly in the browser and is never uploaded to a server, on either the plain-crop or the AI path. Need a different crop shape or a smaller file instead? The crop tool handles a free-form aspect ratio, and the image compressor shrinks file size without a fixed preset.

How the final photo is rendered and saved to your device

When you click Generate, the tool draws your positioned photo onto an HTML5 canvas at the preset's exact pixel size and composites it over a solid white background first, so a transparent PNG source never leaves see-through gaps in the print. Every size is computed at 300 DPI:

PresetPhysical sizePixels at 300 DPI
US / India2x2 in600 x 600 px
Schengen / EU / UK35 x 45 mmabout 413 x 531 px
Canada50 x 70 mmabout 591 x 827 px

The finished image is exported straight to a downloadable JPEG through the canvas toBlob path, so the file is assembled on your device with no server round-trip while it saves. Tick the print-sheet option and a second download link appears holding as many copies of the crop as fit tiled onto one 4x6 in sheet, each divided by a thin separator border for cutting. Because the photo is opened through a local object URL, the same bytes you dragged and zoomed into the frame are the ones written into the download, with nothing sent away and fetched back.
