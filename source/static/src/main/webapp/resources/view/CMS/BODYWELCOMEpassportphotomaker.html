Passport Photo Maker

Last reviewed: 2026-09-04

Crop a photo to an exact passport or visa photo size, right in this browser - no upload, no app to install.

The output is composited onto a plain white background at the preset's exact pixel size for 300 DPI printing; check "Also generate a 4x6in print sheet" to also download a tiled sheet with as many copies as fit on one page.

Took the photo against a bookshelf or a colored wall? Pick an AI backdrop before generating and an on-device portrait-matting model re-composites the person onto plain white, light blue, or light grey - the plain backdrops photo offices ask for. The ~26 MB model downloads once, stays cached in this browser, and is shared with the Background Remover tool - nothing new to download if you already used that. For a transparent PNG or a blurred background, use the Background Remover; this page makes document-sized prints.

Everything runs locally via the Canvas API - the photo is never uploaded to a server, on either the plain-crop or the AI path. Need a different crop shape or a smaller file instead? The crop tool handles a free-form aspect ratio, and the image compressor shrinks file size without a fixed preset.
