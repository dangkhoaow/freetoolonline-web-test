Frequently Asked Questions

What does Aspect Ratio Calculator do?

It reduces a width and height to the simplest whole-number ratio (for example 3840x2160 reduces to 16:9) and can scale a new width or height to the same ratio.

Does it crop or resize my actual file?

No. This is a math-only calculator - it does not open, upload, or modify any image or video file. It just works out the numbers so you can resize elsewhere with the correct dimensions.

Why does the ratio look different from what I expected?

The tool reduces to the lowest whole-number terms using the greatest common divisor, so a slightly non-standard size (for example 1900x1069) may simplify to an unfamiliar ratio rather than snapping to the nearest common one like 16:9.

What happens if I leave the new width or new height field blank, or type 0?

A blank field does nothing - the calculator only recalculates the other side once you type a number into it. Typing 0 does compute a matching 0 for the other field, but the usual explanation line below it (for example "At width 1280, height = 720") only appears for a size greater than 0, so a 0 result shows with no sentence underneath it.

How precise is the decimal ratio value?

The decimal value under the simplified ratio is shown to 4 digits after the decimal point (for example 1.7778 for 16:9), while the simplified ratio itself is always displayed as whole numbers.

Is there a maximum width or height I can enter?

No. Both original-width and original-height fields accept any positive number with no enforced upper limit, so an unusually large size such as 100000 by 56250 (still a 16:9 pair) computes a valid simplified ratio and decimal value the same way a normal-sized input would - useful when checking a print or billboard dimension rather than a screen resolution.
