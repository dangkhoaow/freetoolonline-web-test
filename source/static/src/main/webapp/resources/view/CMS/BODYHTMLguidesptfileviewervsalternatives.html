Last reviewed: 2026-08-26

O Visualizador de Arquivos é uma das três formas comuns de fazer isso: uma ferramenta baseada no navegador como esta, um aplicativo de desktop ou um serviço online baseado em upload. Cada uma equilibra de forma diferente para onde o seu arquivo vai e o que você precisa instalar.
