Live Earthquake Tracker - Im Vergleich

Last reviewed: 2026-08-04

Live Earthquake Tracker ist eine von mehreren üblichen Möglichkeiten, die jüngste seismische Aktivität zu prüfen: ein browserbasiertes Tool wie dieses, die offizielle USGS-Website, oder eine spezielle Erdbeben-App. Jede Variante wägt Filterung und Einrichtung unterschiedlich ab.


Vergleich von Live Earthquake Tracker

AspektLive Earthquake Tracker (dieses Tool)USGS-Website (offiziell)Spezielle Erdbeben-App
Installation oder Konto erforderlichNeinNeinMeist ja (App-Installation, manchmal Konto)
Angebotene Zeitfenster3 (letzte Stunde, Tag, Woche)Mehrere, über eine separate Karten-/SuchoberflächeJe nach App unterschiedlich
Sortierung nach EntfernungJa, mit einem Klick + Browser-StandortÜber separate KartensucheJe nach App unterschiedlich, oft per Push-Benachrichtigung
DatenquelleDirekter Browser-Abruf vom GeoJSON-Feed des USGSNative USGS-DatenOft vom USGS oder einem privaten Anbieter neu verpackt

Der Vorteil des Tools ist alles auf einem Bildschirm, mit einer stets sichtbaren Referenztabelle der Magnitudenskala und einem einzigen Klick für die Sortierung nach Entfernung; eine spezielle App kann Benachrichtigungen im Hintergrund senden, was dieses Browser-Tool nicht tut.
