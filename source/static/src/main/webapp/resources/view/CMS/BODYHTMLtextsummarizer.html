Pick the summary length (key bullets, a short paragraph, or a detailed digest) and copy the result with one click.

  1. Paste or type the text you want shortened into the input box - a sample text and its summary are already on screen, so you can see the output shape before pasting anything.
  2. Choose the summary length: key bullets, a short paragraph, or a detailed digest.
  3. Press Summarize. The status line names which engine produced the result: your browser's built-in AI, an on-device model you loaded, or the instant no-model pass.
  4. For a model-written summary, press Load model once - the download size is shown before it starts, and the model is cached for later visits.
  5. Press Copy to put the summary on your clipboard. The text you paste stays in this browser tab on every engine.
