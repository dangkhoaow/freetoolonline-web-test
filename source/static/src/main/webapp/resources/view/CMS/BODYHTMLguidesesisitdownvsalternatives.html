Comprobación Local vs Webs de Caídas y Ping - Comparativa

Última revisión: 2026-08-21

El comprobador Is It Down, las webs de reportes colectivos de caídas y un ping en el terminal responden tres preguntas diferentes. El comprobador sondea un sitio directamente desde tu dispositivo en el navegador; las webs de caídas agregan reportes de otras personas; el ping prueba la ruta de red desde la línea de comandos. Aquí va una comparativa honesta para elegir bien.

Cuándo gana la comprobación local

Es el primer movimiento honesto más rápido: una petición directa de tu navegador al sitio, una tarjeta Reachable con el tiempo de respuesta en milisegundos, o una tarjeta Not reachable que nombra las tres causas posibles - el sitio está caído, tu red, DNS o bloqueador de anuncios lo bloquea, o el sitio rechaza comprobaciones entre sitios. Siete sitios populares se comprueban al cargar y ningún servicio de terceros recibe la dirección que escribes.


Cuándo gana una web de caídas o el ping

Las webs de reportes colectivos son la única forma de confirmar "caído para todos" - una afirmación que este comprobador deliberadamente nunca hace, porque tiene un único punto de observación. El ping de terminal sigue siendo útil para detalles de la ruta de red como la pérdida de paquetes, pero muchos sitios bloquean ICMP, no siempre hay un terminal a mano y un ping bloqueado prueba poco sobre la puerta de entrada de una web. En la práctica: comprueba aquí primero, resuelve el "solo yo" con una segunda red y acude a una web colectiva solo cuando necesites confirmación global.
