Foxit Pdf Editor Browser

Last reviewed: 2026-08-19

Add one line of typed text to a PDF page, right in this browser tab. You choose the page, the exact position, the font size, and the color, then download the file with your text placed. The PDF is processed on your device and is never uploaded to a server.

How to place text on a PDF page

  1. Choose the PDF file you want to mark up.
  2. Type the line of text you want to add.
  3. Pick the page number and the X%/Y% position on that page, measured from the top-left corner.
  4. Set the font size and a text color.
  5. Click Add text, then download the PDF with your text placed at that spot.

What it does and what it leaves alone

This tool places one line of typed text at one numeric position on one chosen page. It does not offer a visual click-to-place preview, and it does not highlight, draw freehand, stamp images, or edit and remove text or annotations that are already in the PDF. To stamp the same text on every page, use the watermark tool; to fill in an existing PDF's form fields, use the form filler tool.
