Cómo Usar el Explorador 3D de Planetas Errantes - Paso a Paso

Última revisión: 2026-08-30
freetoolonline.com editorial team

Abre el Explorador 3D de Planetas Errantes, elige una masa de lente y pulsa "Play event" para ver a una estrella de fondo brillar brevemente - sin ninguna estrella anfitriona en la escena.


Elige una masa de lente

Pulsa "Sun-like star", "Jupiter-mass planet" o "Earth-mass planet" para cambiar la masa de la lente. El panel de datos se actualiza con la duración real y publicada del evento para esa clase de masa - semanas para una estrella, horas para un planeta con masa de Júpiter, y solo 41,5 minutos para el verdadero récord, OGLE-2016-BLG-1928.


Reproduce o desplaza el evento

Pulsa "Play event" para ver un ciclo completo de brillo, o arrastra el control deslizante de progreso del evento para congelar cualquier momento. El gráfico de la curva de luz bajo la escena traza la forma exacta del brillo en ese momento, con un marcador rojo mostrando tu posición actual.


Revela la lente invisible

Pulsa "Show inferred path" para añadir un marcador oscuro y una línea discontinua tenue mostrando por dónde pasa el planeta errante. Esto es solo un recurso didáctico - por defecto nada marca la lente, igual que vería un telescopio real.


Compara las dos estimaciones de población

Pulsa "Showing: 2011 estimate" para alternar el panel de datos a la revisión de 2017 y volver. Ambos números son resultados reales y publicados - no una única cifra definitiva.


Arrastra para orbitar y usa pantalla completa

Arrastra para orbitar la cámara alrededor del campo de estrellas, desplázate o pellizca para hacer zoom, y usa el botón de pantalla completa para expandir toda la escena y verla con más claridad.
