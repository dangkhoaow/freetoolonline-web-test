Quando Usar o Bennu + OSIRIS-REx TAG Sample Return 3D Explorer - Melhores Sessões e Limites

Última revisão: 2026-08-09

Abra o Bennu + OSIRIS-REx TAG Sample Return 3D Explorer quando precisar de uma visão clara da coleta real de amostra por toque-e-fuga da NASA em 2020 no asteroide Bennu e da surpreendente descoberta de superfície "piscina de bolinhas" que ela revelou - não é um rastreador em tempo real nem uma simulação de dinâmica de contato.


Uma lição sobre retorno de amostra

Uma lição começa clicando em "Simulate TAG" e observando o braço da sonda afundar na superfície de Bennu, depois lendo no painel de dados a massa real da amostra, a data de retorno e os números de risco de impacto.


Sessões para as quais este explorador não serve

Sessões para as quais esta página não serve são uma simulação de descida e contato integrada numericamente - a forma irregular de Bennu é uma forma procedural de ensino e a sequência da TAG é uma máquina de estados roteirizada cronometrada para clareza, não um solucionador físico - ou um rastreamento em tempo real de Bennu ou da sonda renomeada OSIRIS-APEx hoje. Para a missão de retorno de amostra por toque-e-fuga de outra agência, com sua própria cratera de impactador artificial, use o Hayabusa2-Ryugu Sample Return 3D Explorer; para uma sonda que colidiu deliberadamente com um asteroide para testar a defesa planetária, use o DART Asteroid Deflection 3D Explorer. Percorra os controles no guia passo a passo.
