How the optimizer hits PageSpeed Insights' "properly sized images" and "modern format" targets

PageSpeed Insights flags two things on image-heavy pages: images served larger than their display box ("properly sized images") and older formats where a WebP copy would be smaller ("modern image formats"). The optimizer works against both by tuning JPG quality, or converting to WebP, toward the byte budget Google expects for that image's on-page display dimensions - not the source dimensions - so a 4000-pixel photo shown in a 800-pixel column is driven down to the smaller target instead of shipping the full-resolution original. On a large source, that usually lands a 40-70% byte reduction with no visible quality loss; the format-by-format table above shows the narrower 20-50% band you get for JPEG that was already near-optimal. Leave AI auto-mode on and it balances file size against perceived sharpness for you, or open Settings to pin a specific target quality when a particular image needs a gentler pass. The before-and-after preview is there precisely so you can confirm the smaller copy still looks right before you download it, and re-export at a different quality if the first pass went too far.
