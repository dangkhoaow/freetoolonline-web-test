Depth: how to walk the level slider to a target file size instead of guessing

This page is a decision guide, so the actual compressing happens on /compress-image.html once you know which number to type into the Quality field. The fastest way to hit a specific cap is a binary search rather than nudging the level one point at a time: start at 85, and if the exported file is still over your ceiling drop straight to 70, then to 50, and only raise back toward 100 when you are comfortably under the cap with room to spare. For a 12-megapixel JPEG photo the four anchors land in noticeably different places, so if a 4 MB original has to fit under a 500 KB email limit, level 85 usually gets you into the low hundreds of KB with no visible loss, while level 50 will clear the cap easily but shows blocky artifacts along high-contrast edges at normal viewing distance. Level 100 is worth knowing about but is not lossless for JPEG; it stays near-indistinguishable from the source while the file barely shrinks, which is the wrong trade when the whole goal is a smaller file. When even level 50 will not fit, the level slider has run out of room and the real lever is pixel dimensions, so shrink the image first on /resize-image.html and then compress the smaller version. If the artifacts bother you before the size does, that is usually a format mismatch rather than a level problem, and switching a flat-color graphic from JPEG to PNG (or a photo to WebP) fixes it more cleanly than any single quality number.
