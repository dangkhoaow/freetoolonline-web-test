Cara Bermain Space Huggers - Langkah demi Langkah

Halaman Space Huggers memuat game platformer tembak-dan-lari berukuran sekitar 0,5 MB dalam sebuah iframe. Bertarung melintasi planet yang dibuat secara prosedural, tembak dan hindari musuh, dan bersihkan setiap level untuk maju. Tekan Play untuk mulai.

Last reviewed: 2026-08-01

Papan ketik: tombol panah bergerak dan melompat, Z menembak, X menghindar (juga memadamkan api pada karaktermu), C melempar granat (3 per nyawa), R memulai ulang. Hingga 4 pemain bisa bergabung dengan gamepad yang terhubung. Tidak ada mouse, tidak ada sentuhan, tidak ada menu pengaturan ulang tombol.

Langkah 1 - tekan Play di halaman ini

Tekan Play untuk memuat iframe (sekitar 0,5 MB: engine, level, musuh, dan musik latar). Space Huggers adalah entri kompetisi js13k oleh Frank Force, berlisensi GPL-3.0; berkas LICENSE dan kredit disertakan bersama berkas game.

Langkah 2 - pelajari kontrolnya

Space Huggers menggunakan tombol panah untuk bergerak dan melompat, Z untuk menembak, X untuk menghindar (juga memadamkan api di badanmu), dan C untuk melempar satu dari 3 granat per nyawa. Tekan R untuk memulai ulang. Hingga 4 pemain bisa bermain kooperatif lokal dengan gamepad yang terhubung.

Langkah 3 - bersihkan level

Bunuh semua musuh di level saat ini untuk maju. Level dibuat secara prosedural, jadi tidak ada dua permainan yang sama. Tembakan dan granat menghancurkan balok dan penghalang, dan api dari ledakan bisa menyebar ke seluruh level.

Langkah 4 - kelola nyawamu

Kamu mulai dengan 10 nyawa dan mendapat 3 nyawa tambahan setiap kali membersihkan satu level. Space Huggers adalah roguelike tanpa akhir yang pasti - permainan berlanjut sampai nyawamu habis.

Langkah 5 - main lagi

Space Huggers tidak menyimpan progres atau skor di mana pun - setiap sesi adalah permainan baru. Tutup tab dan mulai lagi kapan saja.
