Contact us by email - free feature

Open the contact form above, fill in Name, Email, and Message, then click Send. The note posts to the editorial inbox in the background - no mail client, no page reload, no account or signup required. Every message is anonymous by default; there is no profile or captcha between you and the Send button.

Writing your message

The message area is a rich-text editor capped at 2,000 characters. Paste in a numbered list of requirements and it stays a numbered list; a bold subject line stays bold; an inline link to a screenshot stays clickable. The editorial reader sees your note as formatted rather than as a wall of plain text. If a brief runs long, note that Send keeps only the first 2,000 characters of the message and quietly drops anything past that, so put the essential ask near the top rather than at the very end.

Three field checks run before the note leaves the browser: a blank Name, a malformed Email address, or an empty Message body each surface a short red prompt next to the Send button pointing at the one field to fix. The Message check runs on the text after trimming blank space, so a box holding only spaces or a blank line still counts as empty and still blocks Send, even though something was technically typed into it. The Name and Email boxes each accept up to 250 characters, so a long company name or a plus-tagged reply address fits without being clipped - and each box enforces that limit as you type rather than at Send, simply refusing further keystrokes once it is full, so whatever is visible in the box is exactly what the editors receive.

After you click Send

After Send, an inline status line shows what the inbox received: a blue confirmation for success, an "already received" notice if the same message arrived a moment earlier, or a red retry prompt if the network call did not complete. The page does not reload, so your message stays in the editor while the status updates. While the request is in flight the whole form - the Name and Email boxes, the message editor, and the Send button together - locks and greys out so nothing can be changed mid-send; if the call fails, every field unlocks again automatically and your typed note stays exactly as you left it, so you click Send a second time instead of retyping anything.

Use the form for advertising requests, outsourcing pitches, tool feedback, and feature requests. Every note - regardless of topic - reaches the same editorial inbox in one step. Because that Send is a single shot with no thread to return to, a note that carries its full request travels furthest. For an advertising or partnership enquiry, name the exact page or ad placement you have in mind and say how to reach you beyond email; for a tool that misbehaved, describe what you did, what you expected, and which browser you were using. The more concrete the first message, the sooner the editors can reply with something useful instead of writing back to ask for the basics.

How the form behaves, and how a reply reaches you

  • No email program or configured mail account is needed, so you can send from any browser, including a work or shared computer, without looking up or pasting in an address first.
  • The cursor lands in the Name field the moment the page opens, so you can start typing without clicking first; and if a red prompt flags the Message box, it clears as soon as you resume typing there, so you are never left staring at a stale warning while you correct the note.
  • The Send button itself shows the note's progress - its paper-plane label reads Send, changes to Sending while the note posts, then settles on a greyed-out Sent once the inbox confirms, so you can see the message left the browser and a second click cannot fire the same note twice by accident.
  • Any reply arrives by email at the address you typed in the Email field, not as a notice inside this page, so use an inbox you actually read. There is no thread or ticket number to check back on; if a reply seems slow to arrive, look in your spam folder.
  • A screenshot pasted straight into the message box is dropped - the note travels as text, not as an attachment - so upload the image somewhere first and paste the link instead; a shared-drive or image-host URL stays clickable in the note the editors receive.
  • A one-line question is as welcome as a detailed brief: there is no minimum message length and no required subject line.
