Eine lange Aufnahme muss keinen schweren Download bedeuten. Wenn WebM für die geplante Weitergabe nicht praktisch ist, lädt ein einziger Klick ein einmaliges Modul direkt im Browser, etwa 31 MB groß, und wandelt die Aufnahme in das verbreitete H.264-Video mit AAC-Ton um - so öffnet sich die exportierte MP4-Datei zuverlässig auf Geräten und Playern, die das gängigere Format erwarten, ganz ohne ein einziges Bild an einen Server zu senden.
