Gunakan untuk menyiapkan permalink blog, jalur CMS, atau nama file situs statis dari sebuah judul. Tempel satu frasa per baris untuk batch; pilih "-" atau "_" sebagai pemisah.

Slugify menghapus diakritik Latin dan Vietnam lewat Unicode normalize (NFD) dan berjalan lokal - tanpa unggah dan tanpa akun.
