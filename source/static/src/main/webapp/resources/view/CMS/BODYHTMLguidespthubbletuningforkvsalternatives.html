Explorador 3D do Diapasão de Hubble vs Simulador 3D de Galáxia

Última revisão: 2026-08-13
equipe editorial freetoolonline.com

Ambas as páginas renderizam ciência real de galáxias em um único carregamento - 0 MB instalados, USD 0, sem conta. O Explorador 3D do Diapasão de Hubble cobre o SISTEMA de classificação que ordena toda galáxia em um tipo; o Simulador 3D de Galáxia cobre a estrutura interna, a escala e a contagem de estrelas de UMA galáxia espiral em detalhe.

Onde o Simulador de Galáxia vence

O Simulador de Galáxia vence quando a questão é como a estrutura de uma galáxia espiral realmente se parece em escala - é a única página do site que permite regenerar uma espiral nova e sentir como a estrutura emerge da pura contagem de pontos.


Onde o Explorador do Diapasão de Hubble vence

O Explorador do Diapasão de Hubble vence quando a questão é como QUALQUER galáxia é ordenada em um tipo - é a única página do site que percorre o diagrama de classificação real que os astrônomos ainda usam, ramo por ramo, com exemplos reais e nomeados para você testar seu conhecimento.


Uma regra razoável

Como regra razoável, use primeiro o Explorador do Diapasão de Hubble para aprender o sistema de classificação e onde uma galáxia como a Via Láctea se encaixa nele, depois use o Simulador de Galáxia para ver como a estrutura de uma galáxia espiral se parece de perto.
