Cara Menjelajahi Pulsar Timing Array 3D Explorer

Terakhir ditinjau: 2026-08-04

Ditinjau oleh Tim editorial FreetoolOnline

Buka Pulsar Timing Array 3D Explorer, geser penggeser sudut pisah, dan lihat korelasi Hellings-Downs antara pulsar referensi emas dan pulsar uji magenta naik, turun ke negatif, lalu naik kembali, dihitung secara langsung.

  1. Buka /space-3d/pulsar-timing-array.html dan tunggu Bumi, susunan pulsar, dan pasangan yang disorot dirender.
  2. Geser penggeser sudut pisah dari 0 ke 180 derajat dan lihat pulsar uji magenta bergerak sepanjang lengkung putus-putus, menjauh dari pulsar referensi emas.
  3. Tekan "Play sweep" untuk menjalankan siklus penuh 0 hingga 180 derajat secara otomatis.
  4. Centang "Show correlation-curve chart" untuk menampilkan grafik inline yang memetakan korelasi di setiap sudut, dengan penanda di posisi Anda saat ini.
  5. Baca panel fakta untuk angka korelasi Hellings-Downs langsung dan apakah pasangan berkorelasi positif, berkorelasi negatif, atau mendekati nol.
  6. Seret untuk mengorbit adegan dan gulir atau cubit untuk memperbesar demi melihat susunan pulsar lebih jelas.
