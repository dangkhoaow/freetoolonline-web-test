If you have several PNGs to vectorise, add them to the tracer together and the finished files come back bundled in a single ZIP rather than one download at a time, so a whole icon set is one trip instead of many. Processing runs on the server rather than on your device, and each result sits in temporary storage that clears after a short retention window - so download and save the SVG you want to keep soon after it appears rather than leaving it to fetch later.
