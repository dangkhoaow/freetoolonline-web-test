Apa yang sebenarnya dilakukan pembuat ZIP online

Apa yang sebenarnya dilakukan pembuat ZIP online adalah membundle file menjadi satu .zip yang bisa diunduh di browser - di Make ZIP File Online ia juga bisa mengunci sandi dan menamai arsip sebelum disimpan.

Kapan membuat ZIP benar-benar menghemat ruang

ZIP menyusutkan masukan hanya ketika masukan tersebut dapat dipadatkan. Teks polos, log, CSV, JSON, kode sumber, dan bitmap yang tidak terkompresi biasanya turun ke 30-60% dari ukuran aslinya saat dizip bersama karena byte-nya berulang dan algoritma ZIP menghilangkan pengulangan. Foto dalam JPG, video dalam MP4, audio dalam MP3, dan sebagian besar PDF sudah dipadatkan oleh codec mereka sendiri, sehingga ZIP membungkusnya dengan perubahan ukuran sekitar 0-5% dan dapat sedikit bertambah karena overhead pengemasan. Trik untuk pengiriman yang lebih kecil adalah mengezip file yang dapat dipadatkan bersama untuk mendapatkan keuntungan ukuran yang sebenarnya dan menangani media secara terpisah (mengubah ukuran atau menyandikan ulang), bukan mengezip semuanya dan berharap.

Cara membuat file ZIP di browser

  1. Buka /zip-tools/zip-file.html.
  2. Jatuhkan atau pilih file (folder juga bisa; subfolder dipertahankan).
  3. Opsional: buka Pengaturan, tetapkan nama file, dan tambahkan kata sandi plus metode enkripsi bila arsip perlu melewati saluran di mana kata sandi dibagikan terpisah.
  4. Klik Zip. Halaman mengunggah masukan melalui HTTPS, membangun arsip di sisi server, dan menampilkan tautan unduhan.
  5. Simpan .zip. Jika Anda menetapkan kata sandi, kirim melalui saluran terpisah dari file.

Membuka ZIP di sisi penerima

File .zip standar bisa dibuka dengan ekstraktor yang sudah tertanam di setiap sistem operasi masa kini, jadi penerima tidak perlu memasang apa pun. Di Windows, klik kanan file lalu pilih Extract All; di macOS, klik dua kali dan arsip terbuka menjadi folder di sebelahnya; pengelola file Linux menyediakan Extract di menu klik kanan. Di ponsel caranya sama: iPhone mengunduh arsip ke aplikasi Files, satu ketukan sudah menampilkan isinya, sedangkan Android menaruhnya di Downloads, tempat pengelola file sistem menawarkan Extract dari menu tekan lama. Jika penerima memakai laptop kantor terkunci yang memblokir perangkat lunak pihak ketiga, arsip bisa dibuka langsung di tab browser lewat /unzip-file.html.

Menggabungkan dan memperkecil adalah dua tujuan berbeda

Sebelum membuat ZIP, ada baiknya tahu mana dari dua tujuan itu yang sebenarnya sedang Anda kerjakan. ZIP memakai DEFLATE, jadi masukan berbentuk teks - kode sumber, CSV, JSON, log server - sering turun setengah atau lebih. Sebaliknya, folder berisi 40 foto liburan keluar hampir sama besar dengan aslinya, karena setiap JPG sudah dikompresi saat ditulis. Itu tidak membuat ZIP jadi sia-sia: alasan sebenarnya di sana adalah penyerahan sebagai satu file, sekali unduh alih-alih 40 kali, bukan penghematan ukuran. Beri nama arsip sesuai topiknya di panel Settings sebelum dibuat, maka penerima melihat topiknya saat file tiba alih-alih nama umum, dan tidak perlu menamai ulang.

Yang tidak dilakukan pembuat ZIP

Pembuat ini menyusun arsip baru; ia tidak membuka arsip yang kata sandinya tidak diketahui, dan tidak bisa melepas enkripsi yang dipasang orang lain. /remove-zip-password.html menghapus kata sandi hanya jika Anda sudah mengetahuinya. Pembuat ini juga tidak menghasilkan 7z atau RAR. Keduanya memang memadatkan sedikit lebih baik daripada ZIP, tetapi menuntut pemasangan pihak ketiga di sebagian besar perangkat penerima, sehingga tetap memakai ZIP itulah yang menjaga arsip bisa dibuka di mana saja. Jika Anda sampai di sini karena ingin membuka arsip kiriman orang lain dan bukan membuat yang baru, itu tugas kebalikannya: /unzip-file.html mengekstrak .zip yang sudah ada.

Pertanyaan yang sering diajukan

Kemana file saya pergi selama ZIP dibuat?

File diunggah melalui HTTPS ke layanan pemrosesan yang membangun arsip dan mengembalikan tautan unduhan. Salinan kerja disingkirkan dari server setelah jendela retensi singkat; tidak ada retensi permanen.

Bisakah saya membuat ZIP tanpa mengunggah apa pun ke server?

Bisa, dengan opsi terpisah langsung di browser pada alat pelaksana: pilih file atau folder dan arsip dibangun sepenuhnya di perangkat Anda, tanpa unggahan dan dengan indikator ukuran langsung. Mode di browser ini tidak mendukung kata sandi; gunakan mode unggah di atas saat Anda memerlukan enkripsi AES.
