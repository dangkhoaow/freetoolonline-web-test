AI Watermark Detector

Last reviewed: 2026-08-22

Check whether an image carries the provenance marks AI generators write into their files. The checker reads the file's own bytes in your browser and lists every mark it finds: Content Credentials (C2PA), the IPTC "AI-generated" label, generator signatures such as DALL-E or Adobe Firefly, and Stable Diffusion prompt chunks.

Downloads from DALL-E 3, GPT-4o, and Sora carry a C2PA manifest plus the IPTC "trainedAlgorithmicMedia" label. Adobe Firefly names itself in the metadata. Stable Diffusion and ComfyUI embed the generation prompt inside PNG text chunks. Each found mark is shown as an evidence row - what it is, where it sits, what it says.

A clean result needs more care than a found one. These marks live in metadata, so a screenshot or re-save removes them, and Gemini's SynthID watermark hides in the pixels where only Google's own checker can read it. "No marks found" means exactly that - never proof that a person made the image.

The scan is a byte-level read of the file you choose: nothing is uploaded and there is no model download. To see every tag an image carries - camera, date, GPS - use the image EXIF metadata viewer. Checking writing instead of an image? The AI text detector scans text for machine-writing signals.
