Bước 1 - mở công cụ

Mở JPG to WebP Converter. Không cần cài đặt hay đăng nhập. Trang tạo canvas HTML5 trong tab để bước tiếp theo giải mã JPG cục bộ.


Bước 2 - chọn JPG (giữ trên thiết bị)

Chọn file .jpg / .jpeg từ ổ đĩa. Trình duyệt mở bằng object URL cục bộ - không gửi byte nguồn lên server. Dùng khi CMS hoặc host tĩnh muốn WebP nhưng pipeline vẫn xuất JPG.


Bước 3 - chỉnh chất lượng rồi tải WebP

Chỉnh các tùy chọn phía trên ô chọn file khi cần WebP nhỏ hơn; mặc định phù hợp giao web thông thường. Trang mã hóa lại trên canvas và xuất blob tải về hoàn toàn phía client.
