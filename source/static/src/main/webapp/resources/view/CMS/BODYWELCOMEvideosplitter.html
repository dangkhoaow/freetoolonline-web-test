Video Splitter

Last reviewed: 2026-07-17
Free Tool Online Editorial Team

Enter one split point in seconds or mm:ss, and this tool cuts your video into two separate clips at that exact spot - everything before the point, and everything after.


Key features

  • Both clips keep the original video and audio codecs, because the cut runs as a lossless copy rather than a re-encode - so there is no quality loss and no long wait.
  • Each of the two clips downloads as its own separate file.

Runs in your browser

Everything happens inside this browser tab via FFmpeg.wasm, so the file you upload is never sent anywhere. The source file is not retained after processing.
