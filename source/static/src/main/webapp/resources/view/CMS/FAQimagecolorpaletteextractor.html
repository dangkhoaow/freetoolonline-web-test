Frequently Asked Questions

How does it decide which colors to return?

It draws your image onto an HTML5 canvas, downscales it for speed, and groups near-identical pixels to find the most frequent tones. Each swatch is a dominant color from the image, ranked by how much of the picture it covers, so you get the colors that define the photo rather than a handful of random pixels.

Will the extracted colors exactly match my image?

They match the image's dominant tones, not every pixel: because similar pixels are grouped and averaged, a swatch is the blended average of a range of near-identical colors. If you need one precise shade or a brand-new color from scratch, use the Color Picker instead - the extractor only reports colors that are already in your image.

What complementary tools work well alongside image color palette extractor?

To pick one exact shade on a color wheel, use the Color Picker; to test text-and-background contrast, use the WCAG Contrast Checker.
