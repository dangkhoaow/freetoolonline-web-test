Wie man eine Nachricht in einem Bild versteckt (Steganografie, kostenlos + im Browser)

Steganografie versteckt eine kurze Textnachricht in den Pixeln eines gewöhnlichen Bildes, sodass das Bild unverändert aussieht, aber heimlich Ihre Notiz trägt. Diese Anleitung zeigt, wie man eine Nachricht in einem PNG versteckt und sie später wieder ausliest, optional mit einem Passwort gesperrt - alles im Browser, sodass das Bild und die Nachricht Ihr Gerät nie verlassen.

Wie man eine Nachricht in einem Bild versteckt

  1. Öffnen Sie das Steganografie-Werkzeug und lassen Sie den Modus auf "Eine Nachricht in einem Bild verstecken".
  2. Wählen Sie ein Trägerbild. Ein PNG funktioniert am besten; ein größeres Bild fasst eine längere Nachricht.
  3. Geben Sie die geheime Nachricht ein, die Sie verstecken möchten. Das Werkzeug zeigt die maximale Zeichenzahl, die dieses Bild fassen kann, bevor Sie einbetten.
  4. Wenn Sie möchten, fügen Sie ein Passwort hinzu, damit nur wer es kennt die Nachricht wieder lesen kann.
  5. Klicken Sie auf die Verstecken-Schaltfläche und laden Sie das Ergebnis herunter. Behalten Sie es als PNG.

Wie man eine versteckte Nachricht wieder ausliest

  1. Öffnen Sie dasselbe Werkzeug und stellen Sie den Modus auf "Eine versteckte Nachricht anzeigen".
  2. Wählen Sie das PNG, das mit diesem Werkzeug erstellt wurde.
  3. Wenn die Nachricht gesperrt war, geben Sie das Passwort ein. Der versteckte Text erscheint auf der Seite.
