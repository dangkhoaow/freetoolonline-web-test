Ordenar linhas de texto passo a passo: coloque uma lista em ordem no navegador

A ferramenta gratuita Sort Text Lines deste site reordena um bloco de texto uma linha de cada vez, de A-Z ou de Z-A, totalmente no seu navegador. Este guia mostra os passos exatos e explica como a ferramenta decide a ordem.

Resposta em 30 segundos. Abra o Sort Text Lines, cole sua lista com um item por linha na caixa de cima e clique em Sort A-Z para ordem crescente ou Sort Z-A para ordem decrescente. A lista reordenada aparece na caixa de saída abaixo, pronta para copiar.

Como ordenar suas linhas

  1. Abra a ferramenta Sort Text Lines.
  2. Digite ou cole seu texto na caixa de entrada, mantendo um item em cada linha - a ferramenta trata cada quebra de linha como o limite entre dois itens.
  3. Clique em Sort A-Z para ordenar as linhas de forma crescente, ou Sort Z-A para ordená-las de forma decrescente.
  4. Leia a lista reordenada na caixa de saída abaixo e copie-a. Clique no outro botão a qualquer momento para inverter a ordem.

Como a ordem é decidida

A ordenação usa a comparação de texto do navegador que respeita o idioma, então as linhas são ordenadas letra por letra. Vale a pena saber duas coisas antes de confiar no resultado:

  • Maiúsculas e minúsculas ficam juntas. As versões em maiúscula e minúscula da mesma palavra ficam lado a lado, então "apple" e "Apple" terminam adjacentes, e não em dois blocos separados.
  • Números são comparados como texto, não como valores. Como cada linha é comparada caractere por caractere, "10" e "100" vem antes de "2" (a ferramenta lê o "1" inicial antes do "2"). Para uma lista de números simples, complete-os com a mesma largura - "02", "10", "100" - para obter a ordem numérica esperada.

Usos comuns

Colocar em ordem alfabética uma lista de nomes ou endereços de e-mail; organizar um conjunto de tags, palavras-chave ou classes CSS; ordenar as linhas de um arquivo de configuração ou de uma lista de palavras antes de rodar um diff para que os dois lados fiquem alinhados; ou simplesmente arrumar uma lista colada para que duplicatas e falhas sejam mais fáceis de notar a olho.

Sort Text Lines contra uma planilha ou editor de desktop

Uma planilha pode ordenar uma coluna, mas primeiro você precisa colar a lista em um intervalo de células, selecioná-la e abrir uma caixa de ordenação; um editor de código de desktop pode ordenar linhas selecionadas, mas geralmente precisa de um plugin ou de um comando. O Sort Text Lines é uma única caixa com dois botões - sem upload, sem etapa de importação e sem instalação - o que o torna mais rápido quando a lista ainda não está dentro de um documento. Para trabalho pesado com várias colunas ou ordenação numérica, uma planilha ainda é a melhor opção.

Privacidade

A ordenação roda inteiramente na aba do seu navegador usando JavaScript simples. Nada do que você digita ou cola é enviado, mandado para um serviço de análise ou gravado em algum servidor - atualizar ou sair da página limpa a caixa, sem histórico e sem conta.

Perguntas frequentes

Como a ferramenta sabe onde um item termina e o próximo começa?

Cada linha é um item. A ferramenta divide seu texto nas quebras de linha, ordena a lista resultante e a junta de novo com quebras de linha, então coloque exatamente uma entrada em cada linha.

Por que "10" ficou antes de "2" na minha lista ordenada?

As linhas são comparadas como texto, caractere por caractere, e não como números, então "10" vem antes de "2" porque "1" vem antes de "2". Para ordenar números simples em ordem numérica, complete-os primeiro com a mesma quantidade de dígitos (02, 10, 100).

Posso desfazer uma ordenação ou recuperar a ordem original?

A caixa de saída guarda o resultado ordenado; seu texto original permanece na caixa de entrada até você mudá-lo. Ordenar não sobrescreve a entrada, então você pode clicar em Sort A-Z e Sort Z-A quantas vezes quiser para comparar as duas ordens.

Meu texto é enviado ou salvo em algum lugar?

Não. A ordenação roda inteiramente no seu navegador; nada do que você digita ou cola é enviado a um servidor, e nada é salvo depois que você atualiza ou sai da página.
