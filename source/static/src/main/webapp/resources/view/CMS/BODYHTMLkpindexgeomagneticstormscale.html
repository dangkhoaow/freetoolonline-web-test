The outlined cell is the current Kp value; 5-9 map to NOAA's real G1-G5 storm scale.
Illustrative trace pattern (not a live magnetometer feed) - its swing widens as Kp rises.

NOAA's G-scale turns the 3-hour Kp geomagnetic index into a public-facing severity label: Kp=5 is G1 (Minor), rising to Kp=9 as G5 (Extreme). The May 2024 "Gannon storm" reached Kp=9 (G5), the strongest geomagnetic storm since the October 2003 Halloween storms.

Drag to orbit and scroll or pinch to zoom. For the light-emission mechanism behind aurora itself, see the Aurora 3D Explorer; for one specific historical superstorm, see the Carrington Event 3D Explorer; for the field's static structure, see the Earth Magnetosphere 3D Explorer.
