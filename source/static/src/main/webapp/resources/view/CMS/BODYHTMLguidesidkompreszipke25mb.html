Mengapa 25 MB, dan kapan target ini realistis

Angka 25 MB berasal dari batas lampiran Gmail dan sebagian besar layanan webmail konsumen modern - lebih besar dari batas 20 MB atau 2 MB yang dipakai sejumlah sistem email perusahaan lama. Apakah folder Anda bisa turun ke bawah 25 MB tergantung sepenuhnya pada isinya: DEFLATE (algoritma di dalam format ZIP) memadatkan byte yang berulang, sehingga teks biasa, log server, ekspor CSV, berkas JSON, dan kode sumber biasanya menyusut ke kisaran 20-40% dari ukuran asli setelah dibundel. Foto JPG, klip video MP4, audio MP3, dan sebagian besar PDF sudah dipadatkan oleh codec masing-masing sebelum masuk ke arsip, sehingga wadah ZIP hanya membungkusnya dengan perubahan ukuran sekitar 0-5% - kadang malah sedikit lebih besar karena overhead pengemasan.

Cara mengecek apakah folder Anda muat di 25 MB

  1. Buka /zip-tools/zip-file.html di tab baru.
  2. Seret file atau folder yang ingin dikirim. Sub-folder tetap dipertahankan strukturnya di dalam arsip.
  3. Untuk jalur di browser (tanpa unggah), gunakan panel input klien: level kompresi 0-9 dapat diatur, dan pembaca langsung melihat pembacaan rasio ukuran asli vs hasil zip sebelum mengunduh.
  4. Untuk jalur server (mendukung password dan enkripsi Standard/AES-128/AES-256), isi nama arsip dan kata sandi opsional di panel Settings, lalu klik tombol pembuatan arsip.
  5. Periksa ukuran akhir yang ditampilkan alat sebelum mengirim - jika masih di atas 25 MB, lanjut ke pola pemisahan di bawah.

Ketika 25 MB tidak tercapai: pisahkan berdasarkan jenis file

Ketika satu folder mencampur dokumen teks dengan foto atau video, ZIP gabungan sering gagal menembus 25 MB karena bagian media menahan angka tetap besar sedangkan bagian teks sudah mengecil jauh. Pola yang lebih andal adalah membundel input yang benar-benar dapat dipadatkan (log, CSV, dokumen kode, file konfigurasi) ke dalam satu arsip yang nyata menyusut, lalu mengirim media (foto, video, audio) secara terpisah - via tautan berbagi file atau unggahan cloud - di mana batas 25 MB lampiran email tidak berlaku. Dua paruh pengiriman ini masing-masing lolos pemeriksaan ukuran, bahkan ketika satu ZIP gabungan tidak akan lolos.
