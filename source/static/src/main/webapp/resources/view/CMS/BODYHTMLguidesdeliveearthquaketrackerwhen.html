Live Earthquake Tracker - Wann Nutzen

Last reviewed: 2026-08-04

Live Earthquake Tracker lohnt sich immer dann, wenn Sie schnell die jüngste seismische Aktivität prüfen möchten. Diese Seite erklärt, wann das passt und was das Tool nicht ersetzt.


Wann es passt

Nutzen Sie es direkt nachdem Sie ein Beben gespürt haben und die offizielle Magnitude und den Ort wissen möchten, bevor Sie eine Woche an Aktivität in einer besuchten Region prüfen, oder aus allgemeiner Neugier, was der USGS derzeit weltweit meldet.


Was Sie erwarten können

Sie erhalten denselben Live-Feed des USGS, den das Tool direkt in Ihrem Browser liest: Magnitude, Ort, Zeit und Tiefe, plus eine stets sichtbare Referenztabelle der Magnitudenskala. Die Daten können dem tatsächlichen Ereignis um einige Minuten hinterherhinken, und die Abdeckung ist für die USA/vernetzte Regionen am stärksten - dies ist also eine schnelle Referenzprüfung, kein Frühwarnsystem. Folgen Sie während eines laufenden Ereignisses stets den offiziellen lokalen Notfallanweisungen.
