User Agent Parser - Kapan Digunakan

Last reviewed: 2026-07-24

Buka User Agent Parser saat Anda perlu pemeriksaan cepat, sekali pakai, tanpa memasang apa pun. Halaman ini menjelaskan kapan itu cocok dan kapan tidak.


Kapan cocok

Pakai saat tiket dukungan, log akses server, atau ekspor analitik menyertakan string User-Agent mentah dan Anda perlu tahu browser, sistem, atau perangkat di baliknya tanpa mencari tabel referensi string UA secara manual. Ini juga berguna untuk memeriksa apakah string User-Agent sebuah bot atau crawler mengidentifikasi dirinya sesuai klaim dokumentasinya.


Yang perlu diketahui

Tempel string tersebut (atau biarkan kosong untuk membaca milik browser Anda sendiri) dan alat ini mengembalikan nama dan versi browser, mesin render, sistem operasi, dan kelas perangkat - semuanya diurai secara lokal di browser Anda, tanpa mengirim apa pun ke server. Alat ini mengenali browser dan sistem desktop serta seluler utama saat ini; string yang tidak dikenal masih mengembalikan teks mentah plus kolom apa pun yang bisa dideteksi dengan yakin.
