Beyond typing and saving, the editor adds a few conveniences worth knowing about: a minimap on the right edge gives a bird's-eye view of a long file, code folding lets you collapse a function or block you are not working on, and matching brackets highlight together so a missing closing brace is easy to spot. Pasted code reformats to match the chosen language's indentation automatically, which helps when pulling a snippet from a different source. None of these conveniences need a setting to turn on - they are active as soon as the editor loads, alongside the word wrap and line numbers already visible in the margin.
