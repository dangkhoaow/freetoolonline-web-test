Add Watermark to PDF

Last reviewed: 2026-09-03

Add a watermark to every page of a PDF, right in the browser.

Applies one fixed diagonal text style (gray, semi-transparent, centered) - does not support custom position, color, size, image watermarks, or a different watermark per page.

The watermark text size adjusts automatically to fit each page's width, so the same text stays readable whether the PDF is portrait or landscape, letter or A4.

The same watermark text is stamped on every page of a multi-page PDF in one pass - no repeated uploads or per-page steps.

The whole watermarking pass runs on your device in this tab; the PDF never leaves the browser or reaches a server.


Compared with a desktop app or an upload-based service

Three common ways to stamp a watermark on a PDF are a browser-based tool like this one, a desktop application, or an upload-based online service. They differ in where your file goes and what you have to install first.

Exactly how the stamp is sized and placed

Add Watermark to PDF starts every stamp at 48pt and shrinks it in 2pt steps, down to a floor of 8pt, until the text fits inside 70% of that specific page's width. Because that check runs separately per page, the same watermark text can come out at different sizes across one PDF - full size on a wide landscape page, smaller on a narrow portrait page next to it. The font itself is a fixed Helvetica Bold, and the stamp is always drawn at a 45-degree angle, 35% opacity, in a fixed gray tone, centered on both the horizontal and vertical middle of the page - none of those five values (font, angle, opacity, color, or position) can be changed from the page.

The watermark text field accepts up to 60 characters; the field itself refuses to accept more, so there is no separate length warning to watch for. Add Watermark to PDF also saves the finished file using the same object-stream re-save pdf-lib step this site's separate PDF compress tool uses, so a watermarked download often comes out a little smaller than a plain re-save of the same source file, even though this tool does not report a size change the way the compress tool does. The download is always named watermarked.pdf, whatever the source file was called.
