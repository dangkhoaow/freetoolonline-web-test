Gerador de Tabelas Markdown Online Passo a Passo

Última revisão: 2026-09-04

O Gerador de Tabelas Markdown Online funciona em três passos: abra a ferramenta, forneça sua entrada e depois baixe o resultado. Esta página explica o que cada passo espera.


Passo 1 - abra a ferramenta

Vá para o Gerador de Tabelas Markdown Online. Nada precisa ser instalado ou logado antes de você começar.


Passo 2 - forneça sua entrada

Escolha se a primeira linha é o cabeçalho e se as colunas se alinham à esquerda, ao centro ou à direita.


Passo 3 - obtenha o resultado

A linha separadora de alinhamento é escrita com os marcadores de dois-pontos corretos conforme sua escolha.

Caracteres de barra vertical literais dentro de uma célula são escapados como barra-invertida-barra-vertical para não quebrarem a tabela.
