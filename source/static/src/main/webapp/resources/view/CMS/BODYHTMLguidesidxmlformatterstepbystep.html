XML Formatter Online - Panduan Langkah demi Langkah

Last reviewed: 2026-07-30

Buka XML Formatter Online, tempelkan XML mentah Anda, klik tombol, dan salin hasilnya. Tanpa instalasi, tanpa akun - seluruh proses membutuhkan kurang dari 10 detik.

Langkah 1 - Buka alat

Kunjungi developer-tools/xml-formatter.html. Alat ini memuat secara instan di browser - tidak ada yang perlu diinstal atau diunduh.

Langkah 2 - Tempelkan XML Anda

Klik area teks di sebelah kiri dan tempelkan XML Anda. Bisa berupa respons API yang dikompresi, file konfigurasi, blok SVG, atau string XML yang valid.

Langkah 3 - Klik Format dan tinjau

Klik tombol XML Formatter Online. XML dengan indentasi muncul segera di panel kanan - setiap elemen bersarang diindentasi dua spasi dan elemen kosong muncul sebagai tag penutup diri.

Langkah 4 - Salin hasilnya

Klik Copy Output untuk menyalin XML yang telah diformat ke clipboard. Tidak ada data yang meninggalkan browser Anda kapan pun.
