Cómo Usar el Explorador 3D de Refracción Atmosférica del Atardecer - Paso a Paso

Última revisión: 2026-08-14

Abre el Explorador 3D de Refracción Atmosférica del Atardecer, arrastra el control deslizante "Altitud verdadera del Sol" o pulsa "Play sunset" hacia el horizonte, y observa cómo el marcador verdadero y el disco aparente se separan.



Mueve el Sol hacia el horizonte

Arrastra el control deslizante "Altitud verdadera del Sol", o pulsa "Play sunset" para bajarlo automáticamente desde unos grados por encima del horizonte hasta bien por debajo de él.


Observa cómo el marcador verdadero se separa del disco aparente

El anillo tenue y punteado es la dirección verdadera (geométrica) del Sol; el disco brillante es lo que tu ojo realmente ve. A medida que la altitud se acerca a cero, el disco se eleva visiblemente por encima del marcador y se achata en un óvalo.


Observa la ventana del destello verde

Cerca del cruce con el horizonte, el panel de datos señala una "ventana del destello verde" - el breve momento en que la última fracción visible del borde superior puede destellar en verde.


Activa el aire limpio y estable

Pulsa "Clean, stable air" para ampliar la ventana del destello verde y exagerar levemente el achatamiento, reflejando cómo las condiciones propicias para espejismos hacen que el destello sea más fácil de captar.


Arrastra para orbitar y usa la pantalla completa

Arrastra para orbitar la cámara, desplázate o pellizca para hacer zoom, y usa el botón de Pantalla Completa para expandir todo el panel y obtener una vista más clara.
