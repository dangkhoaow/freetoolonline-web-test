Recent Earthquakes Near Me (USGS Live Feed)

Last reviewed: 2026-08-04

Check the US Geological Survey's live earthquake feed for the past hour, day, or week, filtered by a minimum magnitude.

Pick a time window and a magnitude floor, or press "Sort by distance from me" for a browser-location lookup, and the tool lists matching earthquakes with magnitude, place, time, and depth - nearest first when location is used, most recent first otherwise. Each place name links to the official USGS event page.

A magnitude-scale reference table stays on the page at all times, and when nothing matches your filters you get a clear message instead of a blank panel.
