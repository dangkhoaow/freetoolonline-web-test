Editing workflow: trim first, then resize, then set motion

The practical order that avoids re-doing work is trim, then size, then frame rate. Set the start-point and duration sliders first, since they decide how much footage exists to resize and re-encode - both sliders are bound by the length of the video actually uploaded, not by a separate fixed window. Next, type a width or height (or check AutoW/AutoH so the unset side scales to match); this is where a source clip meant for a large screen gets sized down for a forum post or a chat thumbnail. Set the frame rate last: 1-60 fps is available on every use, and a lower fps produces a smaller file for chat-app previews while a higher fps keeps fast motion smooth.

Because the Result GIF preview renders directly in the page after Make finishes, the reader can check whether the trim, size, or frame rate needs adjusting and re-run the edit before committing to a download - no extra editing application is opened at any point in this sequence.

What this editor does not do

GIF Maker's editing surface covers trim, resize, and frame rate - it does not add captions, crop to a shape, apply filters, or accept a folder of still images as input; the accepted uploads are video files (.mov, .flv, .mp4, .wmv, .gif, .avi). The output also carries no audio track, since the GIF format itself does not store one - trimming, resizing, and setting the frame rate change how the clip looks and how large the file is, not whether sound survives into the result.

FAQ

Can I resize the GIF after I have already trimmed it?

Yes. The width, height, and frame-rate fields sit below the trim sliders on the same page and can be changed before pressing Make - none of the earlier edits are locked in until the GIF is generated.

Does the width/height editor keep the clip's proportions automatically?

Only if you check AutoW or AutoH. Checking one of those boxes scales the unset side to match the side you typed, so the frame keeps its original proportions; leaving both unchecked lets you set width and height independently.

Can I preview my edits before the GIF downloads?

Yes. After Make finishes, a Result GIF preview renders in the page so the trim, size, and frame rate can be checked before downloading or copying the direct link.

Does the editor support cropping or adding text captions?

No. The editing controls on this tool are trim (start point and duration), resize (width and height), and frame rate - there is no crop tool, caption tool, or filter control on the page.
