Frequently Asked Questions

What does Rotate PDF do?

Rotate every page of a PDF by 90, 180, or 270 degrees, right in the browser.

When should I reach for rotate pdf?

The angle applies uniformly to the whole document; it does not support rotating individual pages to different angles.

What complementary tools work well alongside rotate pdf?

To split, merge, or compress the PDF instead, see the related-tools section.

Does rotating reset a page's orientation, or add to what it already has?

It adds to whatever rotation the page already carries and wraps the total at 360 degrees - it is not an absolute reset to the angle you picked. A page that already has a 90-degree rotation baked in, rotated another 90 degrees here, ends up at 180 degrees.

Can I rotate several PDF files in one run?

No. Rotate PDF processes one file per run. To rotate more files, run the tool again for each one; the separate Merge PDFs tool is the one that accepts multiple files at once.

How do I rotate a page 90 degrees counter-clockwise?

Pick 270 degrees clockwise. There is no dedicated counter-clockwise option, and turning a page three-quarters clockwise lands it in the same place as turning it one-quarter counter-clockwise.

Does the download keep my original file name?

No. The rotated file always downloads as rotated.pdf, regardless of what the original PDF was named, so rename it afterward if you want to keep track of which source file it came from.
