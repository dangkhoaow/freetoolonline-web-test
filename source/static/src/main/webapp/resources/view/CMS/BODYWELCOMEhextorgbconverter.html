Hex to RGB Converter Online

Last reviewed: 2026-09-04

Convert a HEX input into a RGB output - one step, in the browser.


Key features

  • Keeps HEX, RGB, and HSL in sync as you change the color.
  • Type a code like #3366FF or #36F - three-digit shorthand expands automatically.
  • Or pick a color with the swatch picker.
  • Each row has its own Copy button that sends the formatted result to your clipboard.

When to use it

Typical use: when your downstream platform accepts RGB but not HEX.

If you are weighing two colors for text readability rather than converting one, the Color Contrast Checker in the related tools reports WCAG ratios; the developer tools hub lists the rest of the set.


Privacy

Nothing you type leaves this device: the conversion is plain arithmetic running in your browser, with no upload and no account.
