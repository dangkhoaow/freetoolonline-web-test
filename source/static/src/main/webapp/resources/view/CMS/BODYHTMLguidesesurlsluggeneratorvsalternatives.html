URL Slug Generator es una de tres formas comunes de armar un permalink: una herramienta en el navegador como esta, una aplicacion de escritorio, o un servicio en linea con subida. Cada una compensa de forma distinta a donde va tu titulo y que necesitas instalar.

Usalo para preparar permalinks de blog, rutas de CMS o nombres de archivo de sitio estatico a partir de un titulo. Pega una frase por linea para lote; elige "-" o "_" como separador.

Slugify quita acentos latinos y vietnamitas con Unicode normalize (NFD) y corre localmente - sin subir nada y sin cuenta.
