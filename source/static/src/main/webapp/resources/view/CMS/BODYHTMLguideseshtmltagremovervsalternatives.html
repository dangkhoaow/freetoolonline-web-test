HTML Tag Remover es una de tres formas comunes de obtener texto plano a partir de HTML: herramienta en el navegador como esta, editor de escritorio o servicio online con subida. Cada una equilibra de forma distinta dónde va el markup y qué hay que instalar.

Pega HTML y quita etiquetas a texto plano en el navegador - sin subida y sin cuenta. Se eliminan etiquetas, scripts y estilos; Copiar pone el texto en el portapapeles.

Prefiérelo cuando necesitas texto legible de un fragmento HTML pegado sin instalar editor ni enviar markup a un servidor. Distinto del Codificador de Entidades HTML y de HTML a Markdown en el mismo hub.
