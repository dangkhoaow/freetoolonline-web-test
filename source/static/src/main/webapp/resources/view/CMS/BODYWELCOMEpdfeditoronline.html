Pdf Editor Online

Last reviewed: 2026-09-03

This online PDF editor adds a line of your own text to an existing PDF page and hands back the edited file, all inside the browser tab.

Key features

  • Type one line of text and choose which page it lands on.
  • Fix where the line sits with two numbers - a width percentage measured from the left and a height percentage from the top.
  • Pick the font size and the color the added line uses.

What this editor does not do

There is no point-and-click canvas or live preview to drop the line by eye and nudge it around. Highlighting, freehand pen strokes, and stamped images stay outside what this editor writes, and it never rewrites or removes text and annotations already inside the PDF you opened; the one line you type is all it adds.

Your files stay in this browser tab

Everything the PDF editor touches stays inside this browser tab: the PDF you open, the line of text you type, and the numeric X%/Y% page position you choose are read and written on your own device, and the edited file is assembled into a download right here with no server round-trip.

No account or sign-up is needed, and the page never stores the PDF or the typed text once you close the tab - open it again any time to make another pass with a different page, position, size, or color.

Text length, size and position limits

The typed text box accepts up to 200 characters. The X and Y position boxes accept 0 to 100 percent and clamp to that range if you type outside it - enter 150 and it becomes 100. The font size box works a little differently at the low end: it accepts 6 to 96 points, but typing an invalid value or anything under 6 resets the size to the 14pt default rather than flooring it at 6pt, while typing anything over 96 caps it at 96pt. Until you change them, the page opens with the font size already set to 14pt and both position boxes already set to 10%, so a first run always starts from a safe, on-page spot instead of an empty guess.

Choosing a page number past the end of the file does not crash the tool. As soon as you pick a PDF, Pdf Editor Online reads its page count and resets the page box back to 1 if it was already set beyond that count; if the box still holds a number beyond the page count when you press Add text, the tool refuses with a message naming exactly how many pages the file has instead of guessing. Pressing Add text with the text box empty is handled the same way - a short prompt asks for the text first, and nothing downloads.

The vertical position also has a built-in edge guard: setting Y to 0 percent or 100 percent does not push the added line off the top or bottom of the page. Pdf Editor Online nudges the text back onto the visible page by just enough that the letters are never clipped at the edge. The added text always uses the same plain typeface - the size and color boxes change how big and what color it is, but not which font it uses.
