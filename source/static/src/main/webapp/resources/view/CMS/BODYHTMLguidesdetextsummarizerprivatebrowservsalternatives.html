Last reviewed: 2026-08-09

Text-Zusammenfasser - Privat, in Ihrem Browser ist eine von drei gängigen Möglichkeiten dafür: ein browserbasiertes Tool wie dieses, eine Desktop-Anwendung oder ein Online-Dienst mit Upload. Jede hat andere Kompromisse dabei, wohin Ihre Daten gehen und was installiert werden muss.

Ein Beispieltext und seine einfache Zusammenfassung erscheinen als Demo, sobald die Seite lädt, sodass Sie die Form der Ausgabe sehen, bevor Sie etwas einfügen.

Wenn Ihr Browser eingebaute KI mitbringt, nutzt die Seite sie ohne Download; andernfalls laden Sie ein kleines Modell direkt auf dem Gerät (Größe wird vor dem Download angezeigt, für das nächste Mal zwischengespeichert) oder bleiben im sofortigen Modus ohne Modell.
