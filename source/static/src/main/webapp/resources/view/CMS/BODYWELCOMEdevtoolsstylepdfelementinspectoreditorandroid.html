Add Text to PDF on Android

Last reviewed: 2026-08-19

Add typed text to a PDF page, right in the browser on your Android phone.

What this tool does

It places one line of typed text at one numeric X%/Y% position on one chosen page. You set the page number and the horizontal and vertical percentage, type your line, and the tool writes it into a downloadable copy of the PDF. As soon as you pick a file it reads how many pages the document holds and caps the page box to that count, so you can aim at the right page before you type. Set a font size and tap a color swatch, add your text, and the edited copy downloads straight to your phone - and if the text box is left empty or the page number falls outside the document, the tool says so plainly instead of failing without a word.

What it does not do

  • No visual click-to-place preview - you position text by numeric X%/Y%.
  • No highlighting, freehand drawing, or image stamps.
  • No editing or removing of text or annotations already in the PDF.

Your file stays on the phone

The file is processed in this browser tab and is never uploaded to a server.
