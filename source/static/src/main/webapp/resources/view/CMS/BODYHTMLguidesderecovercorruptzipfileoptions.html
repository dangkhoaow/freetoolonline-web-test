Beschädigte Zip-Datei Wiederherstellen - Optionen

Zuletzt geprüft 2026-04-27. Browser-Werkzeuge können wiederherstellbare Teile einer beschädigten Zip extrahieren; vollständige Reparatur erfordert normalerweise ein Desktop-Werkzeug.

30-Sekunden-Antwort. Eine "beschädigte" Zip bedeutet meist eines von vier Dingen, jedes mit eigener Lösung. Laden Sie zuerst erneut herunter - die meisten beschädigten Zips sind unterbrochene Downloads. Wenn das fehlschlägt, versuchen Sie eine Teilextraktion der lesbaren Dateien. Dann führen Sie ein Desktop-Reparaturwerkzeug aus. Wenn alles fehlschlägt, sind die Daten weg - bitten Sie den Absender um erneutes Senden.

Schritt 1 - erneut herunterladen

Die meisten "Zip beschädigt"-Meldungen kommen von einem abgebrochenen Download. Der Browser hat die Übertragung früh gestoppt, oder ein CDN hat eine Teildatei geliefert. Lösungen, die in Sekunden vor jedem Reparaturwerkzeug funktionieren: leeren Sie den Browser-Cache und laden Sie erneut herunter; ziehen Sie die Datei mit einem anderen Werkzeug (curl auf Desktop, ein Download-Manager auf Mobil); oder bitten Sie um einen frischen Link, wenn das Original von einer Chat-App kam, in der Anhangs-URLs ablaufen.

Die Diagnose: führen Sie eine Prüfsumme auf der heruntergeladenen Zip aus und vergleichen Sie mit der des Absenders. Wenn sie sich unterscheiden, ist die Datei das Problem, nicht die Zip selbst.

Schritt 2 - Teilextraktion

Teilextraktion rettet die lesbaren Dateien aus einer beschädigten Zip, wenn eine vollständige Extraktion fehlschlägt.

Das zentrale Verzeichnis einer Zip sitzt am Ende der Datei. Wenn die Beschädigung am Ende ist, ist jede Datei darin unerreichbar - auch wenn die Bytes noch da sind. Wenn die Beschädigung in der Mitte ist, extrahieren Dateien vor dem beschädigten Bereich noch.

Versuchen Sie eine Datei entpacken im Browser. Wenn es Inhalte auflistet, aber beim Extrahieren Fehler macht, ist das zentrale Verzeichnis intakt und ein oder mehrere Dateieinträge sind beschädigt. Einige Entpackungswerkzeuge (7-Zip auf Windows, The Unarchiver auf macOS) können alles vor der Beschädigung extrahieren und den Rest überspringen. Lohnt einen Versuch, wenn nur eine Teilmenge der Dateien wichtig ist.

Schritt 3 - Desktop-Reparaturwerkzeuge

Wenn die Teilextraktion fehlschlägt, können Reparaturwerkzeuge das zentrale Verzeichnis durch Scannen nach Dateiköpfen im Körper neu aufbauen. Zwei kostenlose Optionen:

  • 7-Zip auf Windows. Rechtsklick auf die beschädigte Zip, wähle 7-Zip > Open. Wenn es den Körper scannen kann, listet es, was es findet - sogar ohne zentrales Verzeichnis.
  • zip auf Linux/macOS. Der Befehl zip -FF broken.zip --out fixed.zip versucht, eine Zip mit beschädigter Struktur zu reparieren. Funktioniert für viele Fälle, in denen die Datei mitten in einem Eintrag endet.

Wenn der Rohscan von 7-Zip oder der Befehl zip -FF nicht genug wiederherstellt, führt ein spezielles Windows-Reparaturwerkzeug wie DiskInternals ZIP Repair oder ZIP Repair Pro über eine geführte Oberfläche statt einer Befehlszeile einen tieferen Strukturscan durch - allerdings als kostenpflichtiges statt kostenloses Werkzeug.

Browserbasierte Reparatur ist selten, weil die Algorithmen große Dateien scannen und auf lokaler Festplatte schneller laufen. Wenn Sie keinen Desktop verfügbar haben, ist der richtige Weg normalerweise, den Absender um erneutes Senden zu bitten.

Schritt 4 - wann aufgeben

Wenn die Zip mit Verschlüsselung erstellt wurde und die Beschädigung irgendwo nahe den Dateiköpfen ist, sind die Inhalte wahrscheinlich nicht wiederherstellbar. Dasselbe, wenn der Speicherträger (ein versagendes USB-Laufwerk, eine beschädigte SD-Karte) die Quelle war - die Beschädigung ist in den Bytes selbst, nicht in der Verpackung. Der richtige Schritt ist, den ursprünglichen Absender um erneutes Senden zu bitten oder aus einem Backup wiederherzustellen, wenn eines existiert.

Vorbeugung in der Zukunft

Vorbeugung ist einfacher als Reparatur: Fügen Sie jeder Zip, die Sie senden oder archivieren, eine Prüfsumme bei.

Für Dateien, die wichtig sind, senden Sie eine Prüfsumme neben der Zip. Der Empfänger kann verifizieren, dass der Download Byte-perfekt ist, bevor er Zeit auf eine Reparatur verschwendet. MD5 oder SHA-256 funktionieren beide; SHA-256 ist die sicherere Wahl. Siehe warum MD5 nicht entschlüsselt werden kann für den Sicherheitskontext. Für alles Zip-bezogene, siehe den Zip-Werkzeug-Hub. Um aus den wiederhergestellten Dateien ein neues Archiv zu erstellen, verwenden Sie Zip-Datei. Verwandte Anleitungen: Datei in Zip für das Hinzufügen von Dateien zu einem neuen Archiv, und Zip-Datei auf 2 MB komprimieren für das Verkleinern vor dem Versenden.
