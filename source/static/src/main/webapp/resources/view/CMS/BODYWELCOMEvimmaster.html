Vim Master is a free browser Vim lesson game with no account or install. Press Play, then Start Learning to clear onboarding, then type real Vim keys in a simulated editor to clear each JSON lesson. Nothing is uploaded - progress stays on your device.

Key features

  • Clear short JSON lessons inside a simulated editor by typing Vim motion keys to hit each objective.
  • Earn XP and build combos as you clear lessons, with badges and retention tracked on-device.
  • Open cheat-mode practice to drill Vim keys without the scored lesson objectives.
  • Press Play once to load about 584 KB from the game host into an in-page frame, then it stays cached.
  • Keep every score, badge, and lesson under ftol:vimmaster keys on your device - nothing is uploaded.
  • Go fullscreen after Play for a bigger editor, and use a physical keyboard on desktop or a large tablet.

How to play

Press Play to load the game, click Start Learning to dismiss the onboarding, then type real Vim keys in the simulated editor to clear each objective. A physical keyboard is required, so it works best on desktop or a large tablet.
