Drug Recall Lookup

Last reviewed: 2026-09-12

Check whether a medicine in your cabinet has a US FDA recall. Type a brand, a generic name, or the maker (Tylenol, acetaminophen, a pharmacy chain) and the page lists matching enforcement reports, newest first, straight from the official openFDA database.

The latest drug recalls render the moment the page loads, before you type anything, so you can see what a real result looks like first.


Key features

  • One search checks four fields at once - the product description, the recalling firm name, and the openFDA brand and generic names - so the brand name and the active ingredient both find the same reports.
  • An optional state dropdown narrows results to recalling firms based in one US state; where the medicine was actually distributed is shown separately on each report card.
  • Each report card shows the product description, a brand/generic line when openFDA enrichment is present, the recalling firm with city and state, the recall classification, whether the recall was voluntary or FDA-mandated, the reason, the affected lot codes, the initiation date, the current status, and the distribution pattern.
  • Class I results - FDA's most serious category, meaning a reasonable probability of serious health consequences or death - render with a prominent red banner and per-card badges, so the dangerous matches are impossible to miss.
  • A no-match search states plainly that no report matches the query, echoes the query back, suggests trying the generic name instead of the brand, and links to fda.gov/safety/recalls to confirm - never a blank panel.
  • Results are sorted newest first by report date.

Privacy

Your search goes only to the official US-government openFDA API - never to this site's servers - and this page does not store it. There is no upload and no server-side processing on this site; openFDA is keyless and free, so no account is needed on either side.

Recall classifications and coverage

The built-in classification table explains Class I, Class II, and Class III severity, plus a numbered what-to-do list for a recalled medicine at home - including why you should ask a pharmacist before stopping a prescription. This page covers human drugs only - prescription and over-the-counter. Medical device and animal-drug recalls are separate FDA systems, dietary supplements are FDA-regulated foods (use the food recall lookup for those), and enforcement reports lag breaking news by days to weeks, so this is not a live-alert feed. For vehicle safety campaigns, use the vehicle recall lookup instead. This tool is informational - it is not medical advice.
