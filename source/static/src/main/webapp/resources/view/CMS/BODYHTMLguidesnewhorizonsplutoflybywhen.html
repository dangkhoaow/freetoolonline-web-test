When to use New Horizons Pluto Flyby 3D Explorer

Use this explorer when you want to show how a single spacecraft can reach two real destinations nine years apart on one continuous trajectory, using a planet's gravity instead of extra fuel.

  • Teaching how a Jupiter gravity assist bends and speeds up a spacecraft with no extra fuel
  • Explaining the difference between a primary mission (Pluto) and an extended mission (Arrokoth)
  • Showing why the 2015 Pluto flyby and the 2019 Arrokoth flyby are two moments on the same trajectory

This is an educational trajectory approximation, not a precomputed ephemeris.
