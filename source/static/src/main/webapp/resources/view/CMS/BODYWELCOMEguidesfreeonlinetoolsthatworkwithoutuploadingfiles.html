The honest limits before you shrink a big file

Working inside a browser tab is not magic, and the ceiling is worth knowing before you decide where to compress. A tab holds somewhere between a few hundred megabytes and roughly two gigabytes in memory, so a very large archive or a four-gigabyte video can refuse to load where a desktop program would not blink. Heavy graphics work runs slower in a tab than in a native app, and a web tool only ever sees the one file you hand it - it cannot reach into a folder or rewrite files in place. Refresh the page mid-task and any unsaved work is usually gone, which is the quiet cost of keeping the whole job on your own device.
