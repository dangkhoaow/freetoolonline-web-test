Chart Maker Online Schritt für Schritt verwenden

Wandeln Sie Zahlenreihen in wenigen Sekunden im Browser in ein Balkendiagramm um. Kein Upload und kein Konto erforderlich - alles wird lokal auf Ihrem Gerät verarbeitet.

Schritt 1 - Chart Maker öffnen

Rufen Sie Chart Maker Online auf. Die Seite lädt mit Beispieldaten von Montag bis Freitag. Klicken Sie auf Visualize, um das Diagramm sofort zu sehen.

Schritt 2 - Daten einfügen

Löschen Sie die Beispieldaten und geben Sie Ihre eigenen Zeilen im Format Bezeichnung, Wert ein - ein Paar pro Zeile. Klicken Sie auf Visualize, um das Diagramm zu erstellen.

Was das Tool nicht kann

Chart Maker stellt keine Verbindung zu Live-Datenquellen wie Google Sheets her. Für die Datenkonvertierung verwenden Sie den CSV-zu-JSON-Konverter.
