Food Recall Lookup

Last reviewed: 2026-08-26

Check whether a food product or brand has a US FDA recall. Type a product or brand (blueberries, a cheese brand, a salad-kit maker) and the page lists matching enforcement reports, newest first, straight from the official openFDA database.

The latest recalls render the moment the page loads, before you type anything, so you can see what a real result looks like first.


Key features

  • Search checks both the product description and the recalling firm name, so a brand name or an ingredient both work.
  • An optional state dropdown narrows results to recalling firms based in one US state; where the product was actually distributed is shown separately on each report card.
  • Each report card shows the product description, recalling firm with city and state, the recall classification, the reason for recall, the affected lot codes, the initiation date, the current status, and the distribution pattern.
  • Class I results - FDA's most serious category, meaning a reasonable probability of serious health consequences or death - render with a prominent red banner and per-card badges, so the dangerous matches are impossible to miss.
  • A no-match search states plainly that no report matches the query, echoes the query back, and links to fda.gov/safety/recalls to confirm - never a blank panel.
  • Results are sorted newest first by report date.

Privacy

Your search goes only to the official US-government openFDA API - never to this site's servers - and this page does not store it. There is no upload and no server-side processing on this site; openFDA is keyless and free, so no account is needed on either side.

Recall classifications and coverage

The built-in classification table explains Class I, Class II, and Class III severity, plus a numbered what-to-do list for a recalled product at home. This page covers FDA-regulated foods only - USDA FSIS meat, poultry, and egg-product recalls live at fsis.usda.gov instead - and enforcement reports lag breaking news by days to weeks, so this is not a live-alert feed. For vehicle safety campaigns, use the vehicle recall lookup instead.
