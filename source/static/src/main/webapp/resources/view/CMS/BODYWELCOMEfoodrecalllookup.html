Food Recall Lookup

Last reviewed: 2026-08-23

Check whether a food product has a US FDA recall - type the product or brand (blueberries, a cheese brand, a salad-kit maker) and the page lists matching enforcement reports, newest first. The latest recalls render the moment the page loads, so you can see what results look like before typing anything.

Each report card shows the exact product description, the recalling firm and its home state, the recall classification, the reason (for example the pathogen or undeclared allergen), the affected lot codes, the initiation date, the current status, and where the product was distributed. The search checks both the product description and the firm name, and an optional state dropdown narrows results to firms based in one state.

Class I results - FDA's most serious category, meaning a reasonable probability of serious health consequences or death - render with a prominent red banner and per-card badges, so the dangerous matches are impossible to miss. A no-match result states plainly that the database has no matching report, with a link to confirm at fda.gov.

The page covers FDA-regulated foods only; USDA FSIS meat, poultry, and egg-product recalls live at fsis.usda.gov instead, and enforcement reports lag breaking news by days to weeks - the built-in classification table and what-to-do list explain how to read a match. Your search goes only to the official US-government openFDA API - never to this site's servers - and this page does not store it. For vehicle safety campaigns, use the vehicle recall lookup instead.
