Type a medicine, brand, or active-ingredient keyword - the tool searches the product description, the recalling firm name, and the openFDA brand and generic name fields in one pass, so "Tylenol" and "acetaminophen" both find the same reports. Matching enforcement reports list newest first, with an optional filter by the recalling firm's state. Each report card carries the classification badge, reason, lot codes, initiation date, status, and distribution; Class I matches are flagged in red, and the classification table below explains what each class means.
