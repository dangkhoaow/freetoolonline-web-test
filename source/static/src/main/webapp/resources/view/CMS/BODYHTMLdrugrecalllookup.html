Type a medicine, brand, or active-ingredient keyword - the tool searches the product description, the recalling firm name, and the openFDA brand and generic name fields in one pass, so "Tylenol" and "acetaminophen" both find the same reports. Matching enforcement reports list newest first, with an optional filter by the recalling firm's state. Every result card shows its classification badge, the stated reason, affected lot codes, the date it was opened, current status, and where it was distributed - a Class I match renders with a red marker, and the table beneath the results spells out what each class means for a medicine in your cabinet.
