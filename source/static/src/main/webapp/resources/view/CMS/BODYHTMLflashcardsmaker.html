Paste study notes and click Generate card drafts to get question-and-answer drafts you can add to the deck - it doubles as a quiz-question generator for any pasted text. Everything runs in this browser; your notes never leave the device. Without an AI model the drafts come from term-definition and fill-in-the-blank extraction; the optional on-device model writes smarter questions.

Optional: load an on-device AI model for smarter drafts. Each option shows its one-time download size before anything starts; the model is cached by this browser and shared with the other AI tools on this site.
