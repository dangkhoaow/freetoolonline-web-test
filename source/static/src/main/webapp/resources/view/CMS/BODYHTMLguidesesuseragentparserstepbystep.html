User Agent Parser - Paso a Paso

Last reviewed: 2026-07-24

User Agent Parser funciona en tres pasos: abre la herramienta, proporciona tu entrada, luego copia el resultado. Esta página detalla lo que espera cada paso.


Paso 1 - abre la herramienta

Ve a User Agent Parser. No necesitas instalar nada ni iniciar sesión antes de empezar.


Paso 2 - proporciona tu entrada

Pega cualquier cadena de User-Agent en el cuadro izquierdo, o déjalo vacío para que la herramienta lea automáticamente el User-Agent de tu propio navegador. Haz clic en el botón para decodificarla.


Paso 3 - copia el resultado

El cuadro derecho se llena con el nombre y versión del navegador, el motor de renderizado, el sistema operativo y la clase de dispositivo, seguidos de la cadena en bruto original. Usa el botón Copy Output para copiarlo al portapapeles. Todo esto sucede localmente en tu navegador - nada de lo que pegas se envía a un servidor.

Todo se ejecuta localmente en el navegador - sin subida y sin cuenta.
