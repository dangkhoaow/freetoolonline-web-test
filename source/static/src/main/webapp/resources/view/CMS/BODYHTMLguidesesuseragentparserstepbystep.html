User Agent Parser - Paso a Paso

Last reviewed: 2026-07-24

User Agent Parser funciona en tres pasos: abre la herramienta, proporciona tu entrada, luego copia el resultado. Esta pagina detalla lo que espera cada paso.


Paso 1 - abre la herramienta

Ve a User Agent Parser. No necesitas instalar nada ni iniciar sesion antes de empezar.


Paso 2 - proporciona tu entrada

Pega cualquier cadena de User-Agent en el cuadro izquierdo, o dejalo vacio para que la herramienta lea automaticamente el User-Agent de tu propio navegador. Haz clic en el boton para decodificarla.


Paso 3 - copia el resultado

El cuadro derecho se llena con el nombre y version del navegador, el motor de renderizado, el sistema operativo y la clase de dispositivo, seguidos de la cadena en bruto original. Usa el boton Copy Output para copiarlo al portapapeles. Todo esto sucede localmente en tu navegador - nada de lo que pegas se envia a un servidor.

Todo se ejecuta localmente en el navegador - sin subida y sin cuenta.
