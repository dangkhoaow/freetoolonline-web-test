When the upload path is the better fit - a PDF set too large for the in-browser merge to comfortably hold in memory - the files travel to the server over HTTPS, get combined there, and the sources are automatically deleted again after a short retention window once the merged file is ready to download. The in-browser panel skips that step entirely by keeping everything on your device; upload leaves a server copy for only that short window, the same cleanup the site's other server-side PDF tools use.
