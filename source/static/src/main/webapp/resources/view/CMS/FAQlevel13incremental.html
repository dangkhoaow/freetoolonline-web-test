Frequently Asked Questions

What does Level 13 do?

It is a text-based survival incremental that runs entirely in the browser tab: explore a ruined underground City, scavenge resources, build up a camp, and rebuild lost technology through a tech tree, one click at a time. It runs on the open-source Level 13 engine.

Does it work on a phone?

Yes. Every action is a click or a tap, so the interface works the same on a phone touchscreen as on a desktop mouse - there is no keyboard shortcut scheme to learn.

Is my progress saved?

Yes - progress autosaves in this browser roughly every 2 minutes, plus a manual save option, and multiple save slots let you keep more than one run side by side. There is no account or server, so clearing this browser's site data erases the save.

Is the world the same every time?

No - each new game generates a unique underground map from a random seed. Only that seed needs to be kept between sessions, not the whole map, which is why saves are small.
