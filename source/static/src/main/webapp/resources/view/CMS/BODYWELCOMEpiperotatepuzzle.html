Every board is a fresh layout, not just a bigger one

Clearing a level does more than add tiles. The puzzle builds each board procedurally and cycles through five layout styles - maze, grid, sparse, dense, and symmetric - so the routing challenge keeps changing even between boards of the same size. A sparse board gives you fewer tiles to rotate while a dense one packs the grid, and a symmetric board lays out a mirrored pattern to read. Because every board is generated on the fly, no two runs hand you the same pipes twice.
