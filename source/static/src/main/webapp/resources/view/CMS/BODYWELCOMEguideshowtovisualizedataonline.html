A column of numbers copied straight out of a spreadsheet pastes in as CSV with no reformatting; an API response pastes in as JSON just as directly, and a short "Label, Value" list works the same way. The textarea checks which of the three shapes the pasted text matches and draws the chart from whichever one you used, so the format you already have is the format the tool expects - there is no step where you convert your data into something else first.
