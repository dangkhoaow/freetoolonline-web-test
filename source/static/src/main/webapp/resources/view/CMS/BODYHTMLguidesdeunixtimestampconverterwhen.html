Unix Timestamp Converter - wann einsetzen

Last reviewed: 2026-09-02

Greifen Sie zum Unix Timestamp Converter, wann immer eine rohe Epoch-Zahl zu einem lesbaren Datum werden soll - oder ein Datum zu einem Epoch-Wert - ohne Terminal und ohne Code. Er läuft vollständig in Ihrem Browser, der Wert verlässt Ihr Gerät also nie.


Einen Log-Eintrag oder eine API-Antwort lesen

Server-Logs, JSON-API-Antworten und Webhook-Payloads enthalten oft Felder wie created_at: 1756800000. Diese Zahl eingefügt zeigt die ISO-8601-UTC-Form, Ihre Ortszeit mit UTC-Versatz und eine relative Angabe wie "3 days ago" - genug, um auf einen Blick zu erkennen, ob ein Ereignis vor oder nach einem Deploy passiert ist.


Einen Datenbank-Export prüfen

Exporte speichern Zeit je nach Engine und Spaltentyp in Sekunden, Millisekunden, Mikrosekunden oder Nanosekunden. Der Converter erkennt die Einheit an der Ziffernanzahl - Sie können also jede Form einfügen, ohne vorher herauszufinden, welche Einheit die Spalte verwendet.


Eine Abfrage oder ein Test-Fixture bauen

Die Gegenrichtung passt, wenn eine Abfrage oder ein Test einen Epoch-Wert braucht: Datum wie 2026-09-02T12:00:00Z einfügen und die Unix-Sekunden oder -Millisekunden in Code oder SQL kopieren.


Wann es nicht das richtige Tool ist

Die Seite wandelt einen Wert pro Klick um. Für eine ganze Spalte von Timestamps sind eine Tabellenformel oder ein Skript besser geeignet; für wiederkehrende Cron-Zeitpläne siehe die verwandten Entwickler-Tools am Fuß der Tool-Seite.
