Resize PNG and JPG Images Online for Free

Last reviewed: 2026-09-05

Drop a PNG or JPG into the resizer, enter the target pixel dimensions, and download the scaled image - no install, runs in the browser.

Image resizer scales a PNG or JPG to a specific width and height in pixels while keeping the aspect ratio locked.

  1. Upload a PNG or JPG image.
  2. Enter a target max width and max height in pixels; the tool scales down without distortion.
  3. Download the resized image.

Tip: For sharp icon work, start from a vector source instead of resizing a raster up; bicubic interpolation handles photographs cleanly but cannot recover lost detail.


Choosing the new pixel size

Set the target in the Max Width and Max Height boxes above - 1024x768 is common for desktop wallpaper, 800x600 for old print imports. The tool fits the image inside that box and always keeps the original proportions; there is no separate toggle to stretch width and height independently, so a destination that needs a fixed non-proportional frame calls for a general photo editor instead. One resample pass handles the job either way, keeping edges clean whether the image ends up smaller or larger.


Resizing up to six images in one batch

Drop in several images instead of one and each resized result lands in its own slot, up to six at a time. Once two or more are ready, the Download button next to the Direct link field bundles every one of them into a single ZIP instead of saving each file separately. Every image in that batch takes the same target dimensions, so a mixed batch that needs different sizes still means running the smaller group through a second pass.


Picking the output format for the destination

The format choice runs alongside the resize when the destination drives it: JPG for photos shared widely on the web or social, PNG for screenshots and diagrams with sharp edges or transparency that JPG would soften, and WebP for modern web pages where smaller bytes matter more than universal recipient compatibility. Leaving the format alone is fine when the original already matches the destination, and switching is a one-toggle step that runs in the same pass as the dimension change rather than a separate download-and-reopen round-trip.

Read JPG vs PNG for the web for the decision that usually follows a resize: smaller dimensions shift the trade-off because JPG artifacts hide better at low resolution, while PNG keeps the byte count reasonable on icons and small graphics. The guide includes a quick decision rule keyed to image content.


Hitting a target file size, or a size in centimetres

Two size questions send readers here that this tool answers indirectly. Reaching a specific file size, like a 100 KB upload cap, is a compression job rather than a dimension change: shrinking width and height does lower the byte count, but to land on a fixed target by trading quality for size, use the image compressor instead, then return here only if the pixel dimensions still need adjusting. Sizing in centimetres needs a resolution to convert, because this tool works in pixels: at the 96 pixels-per-inch screen reference a 10 cm width is about 378 pixels, while print work at 300 DPI makes the same 10 cm 1181 pixels, so decide the resolution first and enter that pixel figure in the box above.


What the resizer does not change

Resizing is the geometry step in photo editing; it does not crop, retouch, or adjust colour. For broader photo work in the browser, the photo editor covers crop, rotation, brightness, contrast, and saturation alongside the dimension change, and the image tools hub lists the per-task tools (compress, convert, crop) that pair well with a resize in a typical save-for-web flow.
