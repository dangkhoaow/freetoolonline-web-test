Live Earthquake Tracker Step By Step

Last reviewed: 2026-08-04

Live Earthquake Tracker checks the USGS live earthquake feed in three steps: pick your filters, run the check, then read the result. This page walks through what each step expects.


Step 1 - pick your filters

Go to Live Earthquake Tracker and choose a time window (past hour, day, or week) and a minimum magnitude (all, M1.0+, M2.5+, or M4.5+).


Step 2 - run the check

Press "Check earthquakes". The page loads live USGS data directly in your browser - no upload, no account, no install. A default "past day, all magnitudes" lookup also runs automatically when the page opens, so there is always something visible before you interact with it.


Step 3 - read the result

Results are sorted most recent first, each row showing magnitude (color-banded by severity), place, time-ago, and depth; the place name links to the official USGS event page. Press "Sort by distance from me" to re-sort nearest-first with a distance column, once you grant location permission. If nothing matches your magnitude floor, the page shows the clear "No earthquakes at or above that magnitude" message instead of a blank panel.
