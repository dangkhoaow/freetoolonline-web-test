When to use Chelyabinsk Meteor 3D Explorer

Use this explorer when you want a clear picture of why a shallow, high-altitude airburst can shatter windows without leaving a classic crater.

  • Showing the real ~18-degree shallow entry and ~16.5-second brightening
  • Explaining the ~440 kt energy scale and ~23 km peak-brightness altitude
  • Separating Chelyabinsk from the unrelated same-day 2012 DA14 flyby

This is an educational visualization, not a hydrocode airburst simulation.
