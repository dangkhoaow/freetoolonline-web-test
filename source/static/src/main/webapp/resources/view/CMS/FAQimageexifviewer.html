Frequently Asked Questions

What does Image EXIF Metadata Viewer do?

It reads what camera, date, and GPS tags a photo still carries and shows them grouped into Camera, Date / Time, GPS, and Other tables, so you know exactly what is embedded before you share it.

When should I reach for image exif metadata viewer?

Reach for it before posting or sending a photo, to check whether it embeds your location, camera model, or capture time. When you then want those tags gone, open the image metadata remover.

What complementary tools work well alongside image exif metadata viewer?

Reading uses the vendored exifr library and stays in the browser. To delete the tags you find here, Download Without Metadata re-encodes the photo on a canvas, and the dedicated image metadata remover does the same in a strip-first workflow.
