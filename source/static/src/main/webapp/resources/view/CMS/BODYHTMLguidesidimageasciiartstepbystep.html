Gambar ke Seni ASCII, Langkah demi Langkah

Terakhir ditinjau: 2026-09-19

Pengubah gambar ke seni ASCII hanya butuh dua aksi - pilih foto, simpan hasil. Semuanya berjalan di browser; gambar tidak pernah diunggah. Berikut tiap langkah dengan pengaturan yang penting di titik itu.


Langkah 1 - buka alatnya

Kunjungi Image to ASCII Art Online. Sebuah bola demo sudah terkonversi saat halaman dimuat, jadi Anda bisa mencoba semua kontrol sebelum memilih berkas. Tidak ada yang diinstal dan tidak ada akun yang diminta.


Langkah 2 - pilih gambar Anda

Gunakan pemilih berkas di atas. Berkas PNG, JPEG, WebP, GIF, dan BMP terbuka langsung di tab; dari GIF animasi hanya frame pertama yang dibaca - ekstrak frame tertentu dengan pengekstrak frame GIF jika butuh frame lain. Konversi berjalan ulang begitu berkas termuat.


Langkah 3 - atur lebar, palet, dan arah

Lebar menawarkan 40, 80, 120, atau 240 kolom - 40 pas untuk jendela chat, 80 cocok untuk README dan terminal, 120 dan 240 untuk cetakan dengan detail halus; jumlah baris mengikuti bentuk gambar secara otomatis. Pemilih palet mengganti set karakter: padat (@%#*+=-:. ), ringan, angka, atau blok Unicode. Centang Balikkan saat seni akan berada di latar gelap, misalnya terminal.


Langkah 4 - pilih mode keluaran

Teks murni adalah bawaan yang bisa disalin. Mengubah mode ke HTML berwarna menggambar ulang karakter yang sama dengan warna piksel aproksimasi - berguna untuk halaman web; bentuk teks murninya tetap monokrom.


Langkah 5 - salin atau unduh

Tiga tombol di bawah keluaran: Salin teks menaruh karakter di clipboard, Unduh .txt menyimpan teks mentah, dan Unduh PNG merender seni ke gambar berlatar transparan seukuran kisi karakter. PNG mengikuti mode saat ini, jadi konversi berwarna diekspor berwarna.


Jika hasil terlihat salah

Hasil tampak gepeng: koreksi rasio mengasumsikan font monospace standar, jadi tempel keluaran .txt ke editor dengan font monospace sungguhan. Detail buram: naikkan jumlah kolom atau pakai palet padat. Seni tak terlihat di latar Anda: alihkan Balikkan. Pekerjaan yang paling cocok ada di kapan memakainya; perbandingan dengan rute lain ada di perbandingan.
