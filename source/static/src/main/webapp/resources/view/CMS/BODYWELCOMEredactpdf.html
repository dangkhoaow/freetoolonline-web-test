Redact PDF - Black Out Text Permanently, No Upload

Last reviewed: 2026-09-02

Black out names, numbers, and any sensitive text in a PDF so the content is truly deleted from the file - not just covered by a rectangle - entirely in this browser, with no upload.

How the redaction works

The output is a rebuilt PDF where every page is an image: the original text, fonts, and document properties are not copied over, which is exactly why nothing under a box can be recovered - and why no text on any page can be selected or searched afterwards.

Key features

  • Choose a PDF, drag boxes over anything to remove (or use the suggestion buttons), then press the red button: the tool rebuilds the file on this device so whatever a box covers no longer exists anywhere in it.
  • Two suggestion helpers draw draft boxes for you to review: an instant pattern pass for emails, phone numbers, card numbers, and IBANs, and an optional on-device AI pass for names, organizations, and places (about 105 MB, downloaded once on your click, size stated first).
  • Suggestions are drafts, never automatic redaction. Each suggested box can be deleted with a click, boxes can be drawn by hand on any page, and nothing changes until the red button is pressed.

Limits to know before you start

Scanned pages carry no embedded text, so the suggestion helpers cannot see them (hand-drawn boxes still work there), and password-protected PDFs must have their password removed first - files over 50 pages should be split first so no page is silently missed.

Redaction vs password protection

ActionWhat it controlsCan it be undone?
Redaction (this tool)Deletes the content for everyoneNo - a redaction cannot be recovered
Password protectionControls who can open the fileYes - a password can be removed later
