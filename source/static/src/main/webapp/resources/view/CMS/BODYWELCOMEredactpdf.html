Redact PDF - Black Out Text Permanently, No Upload

Last reviewed: 2026-09-02

Black out names, numbers, and any sensitive text in a PDF so the content is truly deleted from the file - not just covered by a rectangle - entirely in this browser, with no upload.

Two suggestion helpers draw draft boxes for you to review: an instant pattern pass for emails, phone numbers, card numbers, and IBANs, and an optional on-device AI pass for names, organizations, and places (about 105 MB, downloaded once on your click, size stated first).

The output is a rebuilt PDF where every page is an image: the original text, fonts, and document properties are not copied over, which is exactly why nothing under a box can be recovered - and why no text on any page can be selected or searched afterwards.

Suggestions are drafts, never automatic redaction. Each suggested box can be deleted with a click, boxes can be drawn by hand on any page, and nothing changes until the red button is pressed. Two limits to know up front: scanned pages carry no embedded text, so the suggestion helpers cannot see them (hand-drawn boxes still work there), and password-protected PDFs must have their password removed first - files over 50 pages should be split first so no page is silently missed.

Related jobs on this site: to scrub names and numbers out of plain text instead of a PDF, use the Text Anonymizer (it shares the same on-device AI model, so the download happens only once between the two pages). To make the redacted file's remaining text searchable again, run it through OCR PDF. And note the difference from password protection: a password controls who can OPEN the file, while redaction DELETES content for everyone - a password can be removed later, a redaction cannot.
