Client Side PDF editor Toolkit

Last reviewed: 2026-08-19

Drop a typed line onto a PDF page without leaving the browser. Load the file, type your text, then set the page number, the X%/Y% position, the font size, and a color before clicking Add text - the toolkit renders and downloads the result on your device.

How it works

  • Type one line of text and place it at one numeric X%/Y% position (measured from the top-left) on one chosen page.
  • Choose how big the line should be and what colour it uses, then save the finished file straight to your device.

What it does not do

  • No visual click-to-place preview.
  • No highlighting, freehand drawing, or image stamps.
  • No editing or removing of text or annotations already in the PDF.

Privacy

Everything happens where you dropped the file: the PDF you load, the line of text you type, the page and X%/Y% placement you pick, and the rendered download all stay inside this browser tab. The toolkit reads and writes your text on the device and builds the finished file entirely client-side, so none of it reaches a server.
