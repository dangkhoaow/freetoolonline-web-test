Image EXIF Metadata Viewer Từng Bước

Last reviewed: 2026-07-21

Image EXIF Metadata Viewer gồm ba bước: mở tool, chọn ảnh local, đọc thẻ (strip tuỳ chọn).


Bước 1 - mở tool

Vào Image EXIF Metadata Viewer. Không cần cài đặt hay đăng nhập.


Bước 2 - chọn ảnh

Dùng bộ chọn file cho JPEG, PNG, WebP, HEIC hoặc TIFF trên thiết bị. Có preview. Read Metadata tắt đến khi chọn file.


Bước 3 - đọc thẻ (strip tuỳ chọn)

Bấm Read Metadata. Bảng Camera, Date / Time, GPS, Other hiện ra. Có GPS thì cảnh báo đó hiện toạ độ và link OpenStreetMap. Download Without Metadata lưu JPEG 0.95 không EXIF. Clear xoá phiên - không upload.
