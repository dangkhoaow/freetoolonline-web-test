Why there is no percentage score here. No tool can reliably determine whether text was written by an LLM: statistical detectors false-positive on real human writing, and OpenAI withdrew its own classifier for low accuracy. Gemini can watermark text statistically (SynthID-Text), but only Google can check it - ChatGPT and Claude output carries no readable watermark in plain text. What this page CAN do honestly is show you concrete, checkable artifacts - invisible characters, lookalike letters, punctuation and repetition patterns - and tell you what each usually means. Humans and word processors produce many of these too, so treat every row as a lead, never as proof.
