Cómo Explorar el Explorador 3D del Monte Olimpo

Última revisión: 2026-07-25

Revisado por Equipo editorial de FreetoolOnline

Abra el Explorador 3D del Monte Olimpo, arrastre el control de exageración vertical para ver la pendiente real, y active las columnas de comparación con el Everest/Mauna Loa mientras el panel de datos se actualiza con las cifras reales publicadas.

  1. Abra /space-3d/olympus-mons-mars-volcano.html y espere a que aparezcan el volcán, la llanura rojiza y el panel de datos.
  2. Arrastre el control de exageración vertical (1x a 8x, valor predeterminado 4x) para ver el escudo más alto - y observe cómo se ve casi plano a 1x, que es la pendiente real y suave.
  3. Active o desactive "Show Everest / Mauna Loa scale comparison" para agregar o quitar las dos columnas de referencia.
  4. Haga clic en "View caldera from above" para llevar la cámara a un ángulo casi cenital sobre el complejo de la caldera.
  5. Arrastre para orbitar y desplácese o pellizque para acercar y ver la caldera de cerca.
  6. Lea el panel de datos para conocer el diámetro de la base, la altura de la cumbre, el tamaño de la caldera y las cifras de comparación con el Everest/Mauna Loa.
