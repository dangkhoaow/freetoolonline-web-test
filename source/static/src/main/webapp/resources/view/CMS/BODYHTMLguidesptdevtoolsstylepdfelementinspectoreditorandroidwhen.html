Um Inspetor e Editor de Elementos PDF no Estilo DevTools para Android - Quando Usar

Última revisão: 2026-08-19

Um inspetor e editor de elementos PDF no estilo DevTools para Android vale a pena abrir quando você precisa de uma execução rápida e pontual, sem instalar nada. Esta página explica quando isso serve e quando não serve.


Quando serve

Coloca uma linha de texto digitado em uma posição numérica X%/Y% em uma página escolhida - não oferece uma pré-visualização visual de clicar para posicionar, não suporta marcação com destaque, desenho à mão livre, carimbos de imagem, nem edição ou remoção de texto ou anotações já existentes no PDF.


O que esperar

O arquivo é processado nesta aba do navegador e nunca é enviado para um servidor.

Para carimbar o mesmo texto em todas as páginas, use a ferramenta de marca d'água; para preencher os campos de formulário de um PDF existente, use a ferramenta de preenchimento de formulários.
