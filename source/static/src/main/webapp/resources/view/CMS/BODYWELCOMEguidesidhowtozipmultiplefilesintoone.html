Lakukan proses zip yang sebenarnya dengan alat ZIP file: seret semua file sekaligus, atau satu folder utuh, lalu klik Zip untuk menggabungkannya menjadi satu arsip yang tetap menjaga struktur folder aslinya bagi siapa pun yang membukanya.

Level kompresi mana yang dipilih

Sesuaikan level kompresi dengan isi arsip. Alat ini menyediakan tiga level; tabel di bawah menunjukkan kegunaan terbaik masing-masing.

Bagaimana arsip dibuat di perangkat Anda sendiri

Karena proses penggabungan berjalan di dalam halaman pada perangkat Anda sendiri, file yang Anda tambahkan tidak pernah dikirim ke server dan tidak ada yang perlu dipasang sebelum mulai, sehingga dokumen sensitif tetap jauh dari disk pihak lain. Sebelum mengunduh, ketik nama untuk arsip jadi di kolom nama keluaran alih-alih menerima nama default yang umum, sehingga paket yang disimpan sebagai tax-2026.zip langsung memberi tahu penerima isi paket tersebut sekilas. Tidak ada batas tetap berapa banyak item yang bisa Anda tambahkan dalam satu proses - plafon praktisnya adalah memori yang tersedia di perangkat Anda, jadi seratus struk kecil menyusut menjadi satu arsip dalam sekitar satu detik, sementara beberapa gigabyte video mentah membuat tab sibuk jauh lebih lama. Jika menyeret sekumpulan file ke halaman terasa merepotkan, pemilih file yang sama juga memungkinkan Anda mengeklik untuk menelusuri dan menambahkan file satu per satu. Setelah arsip siap, file langsung tersimpan ke lokasi unduhan biasa Anda, siap untuk dilampirkan atau diserahkan.
