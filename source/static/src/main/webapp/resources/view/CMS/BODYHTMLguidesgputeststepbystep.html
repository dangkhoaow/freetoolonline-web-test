How to Run the GPU Test Benchmark - Step by Step

Last reviewed: 2026-07-12

GPU Test checks what your browser's graphics stack can do and then runs an escalating in-browser benchmark to see how it holds up under load. This guide covers the capability report, running the benchmark, reading the score, and keeping a history of your runs.


Read the capability report

Open the page and a table renders immediately, before the 3D engine loads: WebGL 1 and 2 support, the renderer and vendor your browser reports (or a note that the browser masks them for privacy), the max texture size, max render buffer, max viewport, MSAA sample count on WebGL2, whether WebGPU is present, and your device pixel ratio, screen resolution, reported CPU thread count, and device memory.


Press Run benchmark

Click Run benchmark and the page loads a 3D scene built from a single instanced mesh of icosahedrons. The test runs in tiers that double from 1,000 instances up to 256,000: each tier gets a 1-second warmup that is thrown away, then 3 seconds of measured frames, and the run advances to the next tier only while the median frame rate holds at 55 FPS or higher.


Read the score

The score is the sum, across every completed tier, of instances multiplied by the frame rate capped at 60 (so a high-refresh display does not inflate the number), divided by 1,000. A per-tier results table shows the breakdown, and a rating line names the highest tier your device held at 45 FPS or more.


Let it stop safely, or cancel it yourself

If you switch tabs mid-run, the test cancels itself and explains why: a backgrounded tab throttles frame timing and would corrupt the result. Losing the WebGL context does the same. You can also press Cancel at any point to stop a run on demand.


Check your run history

Your last 20 runs, with date, score, top tier, FPS, pixel ratio, screen size, and renderer string, are saved under this table, kept in this browser's local storage. Nothing is uploaded anywhere, so the history is local to this browser and this device.


Go fullscreen and look around

The page-level Fullscreen button plays the test bigger, the idle test scene supports drag-to-orbit and wheel or pinch to zoom, and the engine requests high-performance graphics preference from your device for the run.
