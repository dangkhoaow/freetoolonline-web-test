File Viewer theo từng bước

Last reviewed: 2026-08-26

File Viewer chạy qua ba bước: mở công cụ, cung cấp dữ liệu đầu vào, rồi sao chép kết quả. Trang này hướng dẫn từng bước cần những gì.


Bước 1 - mở công cụ

Truy cập File Viewer. Bạn không cần cài đặt hay đăng nhập trước khi bắt đầu.


Bước 2 - cung cấp dữ liệu đầu vào

Có thể tìm kiếm theo tên trường hoặc theo giá trị bằng ô tìm kiếm.


Bước 3 - sao chép kết quả

Dữ liệu đầu vào không được tải lên máy chủ.

Nếu cần truy cập theo hướng lập trình, hãy xem các công cụ developer-tools liên quan.
