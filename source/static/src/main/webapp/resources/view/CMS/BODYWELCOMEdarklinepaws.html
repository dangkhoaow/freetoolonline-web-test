DarkLine Paws is a free browser 3-in-1 cat game bundle you can play without an account or install. Press Play to load the ~36 KB bundle in a same-origin iframe, then pick a mode from the in-game dropdown. Nothing leaves this device except the initial page and game files from this site.

Three games in one menu

  • Deadly Maze: a raycasted first-person maze that opens first. Press BEGIN ADVENTURE, pick a maze layout, then Start Game. Move with WASD or the arrow keys, strafe with A/D, and hold Shift to run while you search for the witch's house. Red tiles damage you, green tiles heal, and a glowing goal tile ends the run in victory.
  • Tic-Tac-Toe: a duel against a cat AI that plays a perfect minimax strategy. It never loses - the best you can force is a draw.
  • Cat Climber runner: a rooftop building-hop where Space or a click times each jump between buildings, and a fixed final building ends the run.

Controls and privacy

Switch modes from the maze's own dropdown, and press Escape inside either side game to return to the maze menu. Play is session-only across all three modes, so there is no save data stored on your device. Adapted from DarkLine-Paws (MIT, shaurya6903, JS13K 2025 Black Cat theme).
