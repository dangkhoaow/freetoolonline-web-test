Server Survival TD is a free browser cloud-infrastructure tower defense - no account, no install. Press Play and defend a cloud system, keeping reputation alive as requests-per-second climb.


Key features

  • Place cloud services - CDN, database, firewall, and more - on a 3D grid.
  • Connect traffic paths between the nodes so requests can flow.
  • Survive rising RPS surges and malicious traffic without letting reputation collapse.
  • About ~13 MB loads after you press Play; later visits use the browser cache.
  • Adapted from the open-source Server Survival project (MIT); runtime libraries are vendored locally.

When to use it

Reach for this when you want a systems-thinking session instead of a classic map-draft wave game. If you would rather draft a fixed map, try Neon Tower Rush; for a short plant-and-wave round, try Garden Defense.

Your data stays on this device

Progress, sound preferences, locale, and campaign data stay under ftol:serversurvivaltd keys in your own browser. Nothing is uploaded.
