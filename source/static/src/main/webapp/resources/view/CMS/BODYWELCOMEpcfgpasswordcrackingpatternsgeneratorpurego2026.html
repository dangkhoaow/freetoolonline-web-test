PCFG Password Pattern Generator

Last reviewed: 2026-10-04

This tool builds example passwords that follow the base structures a PCFG password-guessing model learns from real leaked password sets. Pick a structure like L6D2S1 - six letters, two digits, one symbol - or let the tool sample structures by how often they appear, then read the structure label printed beside each generated string.

A PCFG (probabilistic context-free grammar) treats every password as a sequence of character-class segments: L for a run of letters, D for digits, S for symbols. Guessing tools rank these structures by frequency and try the common ones first, which is why "monkey99!" (L6D2S1) falls far faster than its eight-character length suggests. Seeing your own habits written in the L/D/S notation is the quickest way to understand why a longer, patternless password wins.

Three ways to generate

  • Sample common patterns by frequency - the tool picks a base structure weighted by its real-world share, so the mix of examples you see matches how guessing tools prioritize their attempts.
  • Generate from one specific base structure - pick a row from the table above (say LDS) and see several examples that all follow that exact letters-digits-symbol shape, filled with the common digit/symbol choices real people use (1, 123, 2024-2026, !, @).
  • Strong uniform-random password - every character is picked independently from a full letter/digit/symbol pool (ambiguous characters like l/o/0/1 removed), with an entropy-in-bits figure next to the result, for a password meant for real use.

Everything stays on your device

The generator runs entirely in your browser. Every character comes from the Web Crypto secure random generator, nothing is uploaded or logged, and no password is ever sent to a server or checked against any database. For a password you will actually use, switch to the strong uniform-random mode and store the result in a password manager.
