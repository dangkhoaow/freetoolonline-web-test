Image to ASCII Art Online

Last reviewed: 2026-09-19

Turn any photo into ASCII character art right in your browser. Pick a width and a character palette, and the tool reads the brightness of each block of the image and maps it to a character - then you copy the text or download it as a .txt file or a transparent PNG. Nothing is uploaded; the picture stays on your device.


Key features

  • Four character palettes - dense, light, numeric, and Unicode blocks - so the art can read as fine shading or bold blocks.
  • Output width of 40, 80, 120, or 240 columns; the number of rows follows the image's own aspect ratio.
  • An invert toggle switches between print style (dark characters on a light background) and terminal style (light characters on a dark background).
  • Two output modes: plain monospace text you can copy, or colored HTML that keeps the approximate pixel color.
  • Copy the result with one click, or download it as a raw .txt file or as a PNG rendered on a transparent background.

When to use it

Reach for this when you want picture-like art somewhere only plain characters are allowed - a README header, a terminal splash screen, a code comment, or a forum post where an image cannot go. A demo image converts as soon as the page loads, so you can see real ASCII output before you choose your own file.
