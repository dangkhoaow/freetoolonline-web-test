Frequently Asked Questions

What does Add Watermark to PDF do?

Add a watermark to every page of a PDF, right in the browser.

When should I reach for add watermark to pdf?

Applies one fixed diagonal text style (gray, semi-transparent, centered) - does not support custom position, color, size, image watermarks, or a different watermark per page.

What complementary tools work well alongside add watermark to pdf?

To split, merge, rotate, or delete pages from the PDF instead, see the related-tools section.

Can I watermark a PDF that has a password on it?

A PDF with owner or permission restrictions but no password required just to open it still loads and gets watermarked normally. A PDF that needs a password before it will even open fails to load, and the tool shows "Could not process the PDF" instead of a blank or frozen page.

Is there a limit on how long the watermark text can be?

Yes - the watermark text field has a 60-character cap built into the field itself, so it simply stops accepting more typing past that length rather than truncating the text afterward.

What happens if I click Add watermark without typing any text?

Nothing is processed. The tool shows "Type the watermark text first." and the PDF you already chose stays selected, so you only need to type the text and click again.

Does adding a watermark make the PDF file bigger?

Not necessarily. The save step uses the same object-stream re-save this site's PDF compress tool relies on, so a watermarked file sometimes comes out a little smaller than a plain copy of the source PDF, even though this tool does not display a size comparison for the watermark step itself.
