How the password removal works

Type the exact password into the password field, then drop your .zip onto the upload area. The service reads that one passphrase over HTTPS, re-saves the archive without its encryption layer, and hands back a download link for the unlocked copy - your original archive on disk is never touched. If the password field is left blank or the password is wrong, the backend rejects the job outright rather than returning a half-processed file, because the service reads the password directly from that field before it can proceed. The unlocked copy is held only briefly on the server and rotates off after a short retention window, so download it before you close the tab.

What this tool can't do (forgotten passwords)

This is not a brute-force cracker - it cannot guess or recover a password you do not know. AES-128 and AES-256 derive their encryption key directly from the password, so the archive stays mathematically locked without it, regardless of file size or how old the archive is. If you forgot a password you set yourself, the safest path is to create a fresh archive with the ZIP file compressor and share the new password through a separate channel. If someone else sent you the archive, ask them for the password directly - there is no online unlocker that defeats strong ZIP encryption.
