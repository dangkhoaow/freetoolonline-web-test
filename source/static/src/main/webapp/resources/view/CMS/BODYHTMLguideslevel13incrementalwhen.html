When to Play Level 13

Level 13 fits when you want a click-driven survival incremental that saves your progress between visits, with no keyboard or gamepad to learn.

Last reviewed: 2026-08-05

When you want progress that sticks around

Level 13 autosaves roughly every 2 minutes plus a manual save option, with multiple save slots - close the tab and your camp is still there next time, as long as you keep this browser's site data.

When you don't want to learn controls

Every action is a click - there is no keyboard scheme, no gamepad support, and no key-remap menu. Pick it when a keyboard-driven arcade game feels like too much to learn.

When you want a long-running session

A tech tree of workshops, greenhouses, and hospitals slowly unlocks as you find blueprints - the incremental compounds the longer a single run goes, so it fits a session you plan to return to.

When to pick another game instead

Want a fast action session with no progress to manage instead? Try Space Huggers (roguelike run-and-gun, nothing saved between sessions) or Retro Tank Battle (best destroyed-tanks count saved, arcade controls). Want gamepad-driven local co-op? Space Huggers supports up to 4 players.
