O leitor que chegou aqui procurando "comprimir pasta zipada" geralmente já tem o .zip pronto e quer torná-lo menor antes de enviar por email ou subir para um serviço de transferência. O caminho mais curto é o compactador ZIP com nível de compressão máximo; o caminho que entrega resultado real é descompactar primeiro, reduzir as imagens individuais com o compressor de imagens, e depois re-zipar.

A resposta honesta (honest answer) para "como faço essa pasta zipada ficar menor": re-compressing a `.zip` almost never shrinks it, because the ZIP deflate algorithm already removed the byte-level redundancy on the first pass. Rodar o mesmo algorithm numa cadeia de bytes que já parece aleatória não acha mais nada para shrink; the result fica dentro de 1% do tamanho do `.zip` original.
