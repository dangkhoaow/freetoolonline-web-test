Test Your Keyboard for Optimal Performance

Last updated: Aug 14, 2026

Press keys on the on-screen QWERTY layout and each keydown highlights the matching key, so a dead key, a stuck modifier, or a mismatched layout shows up immediately. The check runs entirely in your browser - no upload, no log, no server round-trip - so a password fragment or draft sentence you type during the test never leaves the device.

Keys that stay dark even when the keyboard is fine

A few keys stay dark on a perfectly good keyboard, and knowing which ones saves a false alarm. OS-reserved combinations - Alt+F4 on Windows, Cmd+Q and Cmd+Tab on macOS - are caught by the operating system before the browser ever receives the keydown event, so they will not highlight by design. Most laptop Fn keys behave the same way: they remap other keys at the firmware level and emit no keydown of their own, so an unlit Fn is expected rather than a fault. The numeric keypad is the real fault to rule out first - turn Num Lock on before testing it, because with Num Lock off the 0 through 9 and decimal keys send navigation codes instead of digit keydowns and look completely dead.

What this test cannot measure

  • Polling rate - how often the keyboard reports its state to the OS
  • Key-press latency - the round-trip time from physical actuation to on-screen response
  • N-key rollover and anti-ghosting - how many simultaneous keys the hardware can report
  • Actuation force - the analog resistance of a mechanical switch, and switch feel generally

Those four need a vendor utility for the specific keyboard or a dedicated hardware tester. For the everyday "is this key still working" question this check is enough: treat it as the first gate and the vendor tool as the second when you need performance numbers.

The full pass before a gaming session or a keyboard return

Cycle through every key and confirm each press registered on the matching on-screen key - do not stop at the letters. Include the special keys: Caps Lock, Num Lock, shift, Ctrl, Alt, and the whole function row. That complete pass is what separates one dead switch from a layout problem, and it is worth the ten seconds before a remote-work shift, a gaming session, or a decision on whether to return a faulty board.
