Como Usar o Chart Maker Online - Passo a Passo

Transforme linhas de números em um gráfico de barras no navegador em menos de um minuto. Sem upload e sem conta - tudo é processado localmente no seu dispositivo.

Passo 1 - Abra o Chart Maker

Acesse o Chart Maker Online. A página carrega com dados de exemplo já preenchidos - segunda a sexta com cinco valores. Você pode ver o gráfico imediatamente ao clicar em Visualizar.

Passo 2 - Cole seus dados

Apague os dados de exemplo e digite ou cole suas próprias linhas. Cada linha segue o padrão: Rótulo, Valor - um par por linha. Exemplo:

T1, 42000
T2, 55000
T3, 48000
T4, 61000

Passo 3 - Clique em Visualizar

Clique no botão azul Visualize. O gráfico é renderizado como um gráfico de barras SVG diretamente abaixo da área de entrada.

O que a ferramenta não faz

O Chart Maker não se conecta a fontes de dados ao vivo como Google Sheets ou banco de dados - cole ou carregue seus dados diretamente. Para converter ou limpar os dados antes de gerar o gráfico, veja o Conversor CSV para JSON.
