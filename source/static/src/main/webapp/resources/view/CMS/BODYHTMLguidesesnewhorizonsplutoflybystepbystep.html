Como usar el Explorador 3D del Sobrevuelo de Plutón de New Horizons

  1. Abre el Explorador 3D del Sobrevuelo de Plutón de New Horizons y espera a que la escena se cargue.
  2. Arrastra para orbitar la vista y desplaza para acercar el trayecto del lanzamiento a Plutón.
  3. Elige Sobrevuelo de Plutón para el trayecto de la misión principal o Mas Arrokoth para el trayecto extendido.
  4. Arrastra el control de fase de 0 a 99 para mover la sonda a cualquier punto del trayecto.
  5. Pulsa Reproducir para animar la trayectoria completa de forma continua, o Pausar para mantener una posición.
