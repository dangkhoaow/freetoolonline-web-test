Where the Yarkovsky Effect Explorer wins

The Yarkovsky Effect Explorer wins when the question is about how an asteroid's orbit itself drifts over time - the semimajor-axis change that matters for long-term impact-risk refinement, as it did for Bennu.


Where the YORP Effect Explorer wins

The YORP Effect Explorer wins when the question is about why an asteroid's rotation rate itself speeds up or slows down, and why that is a torque, not a force - it is the only page on the site with a torque-couple visualization and a spin-up/spin-down toggle.


A reasonable rule

As a reasonable rule, use the Yarkovsky Effect Explorer first to see how sunlight can quietly reshape an asteroid's orbit, then use the YORP Effect Explorer to learn the companion mechanism that reshapes the same body's spin instead.
