Visor de Archivos Paso a Paso

Last reviewed: 2026-08-26

El Visor de Archivos funciona en tres pasos: abre la herramienta, proporciona tu archivo y luego copia el resultado. Esta página explica lo que espera cada paso.


Paso 1 - abrir la herramienta

Ve al Visor de Archivos. No necesitas instalar nada ni iniciar sesión antes de empezar.


Paso 2 - proporciona tu archivo

Puedes buscar por nombre de campo o por valor usando el cuadro de búsqueda.


Paso 3 - copia el resultado

Los archivos no se suben a ningún servidor.

Para acceso programático, consulta las herramientas de desarrollador relacionadas.
