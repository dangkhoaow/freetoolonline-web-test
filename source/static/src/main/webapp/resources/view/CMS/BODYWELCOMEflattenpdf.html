Picking the engine and density

The engine is the first practical choice: ImageMagick gives layered PDFs a uniform raster pass, while GhostScript suits vector-heavy files where the line work must stay sharp through the bake. With ImageMagick selected, the density picker lands the same upload at any of the three densities above - archive, sharing, or print - without re-running it.

Why flatten a PDF at all

The value of flatten is permanence and parity, not just byte-count: a form-filled tax document, a signed contract, or a layered scan stays visually identical in whichever reader the recipient opens. What the bake changes permanently

Baking is one-way: there is no per-layer opt-out and no matching un-flatten step, so once the fields are baked the original interactivity is gone for good, along with any risk of accidental edits. Comments and highlight annotations are treated the same way as fields - drawn permanently onto the page surface, so a reviewer's markup becomes part of the sheet rather than a layer a later reader could toggle off or delete. Flatten does not add or remove a passcode, so a document that needs protection should pass through the password add or password remove tool first, then come back here to bake the remaining layers. A scanned page also stays a picture after the pass, because no text recognition runs during a flatten: if you need selectable text, run the scan through a text-recognition step before flattening it.

No account, and the download link expires

The server flatten step above needs no account or sign-in - the upload runs on an anonymous session. The download link that comes back is not permanent: the flattened file rotates off the server automatically a short time after processing finishes, so save it to your device before starting a second upload or closing the tab rather than treating the link as storage. Keep the original PDF on hand until you have confirmed the flattened copy opens correctly in your own reader.

Two in-browser panels skip the upload

Two panels below the Flatten button skip the server upload entirely, and neither replaces it. Optimize in browser re-saves the PDF with packed object streams on your device and reports the exact size before and after, so the byte savings are measured, not estimated. Rotate in browser turns some or all pages 90, 180, or 270 degrees - type a page range such as 2-5, or leave it on all - and the file never leaves your device.

How flatten relates to compressing a PDF for free

Flatten is not a dedicated compressor, but the layer-merge usually reduces file size on layered PDFs as a side effect - signed contracts, scanned forms, and design exports often shrink noticeably. The byte-count drop comes for free on inputs that have many layers to begin with, so for a strictly compress-oriented workflow on flat documents pick a tool whose job is image or document compression: flatten will not shrink an already-single-layer PDF.
