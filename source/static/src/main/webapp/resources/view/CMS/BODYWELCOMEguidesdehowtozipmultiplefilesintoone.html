Welche Komprimierungsstufe wählen

Richten Sie die Komprimierungsstufe nach dem Inhalt des Archivs aus. Das Werkzeug bietet drei Stufen; die Tabelle unten zeigt, wofür sich jede am besten eignet.

KomprimierungsstufeAm besten fürErgebnis
Store (0)Bereits komprimierte Dateien (MP4, JPG, HEIC)Am schnellsten; Größe sinkt nur um 0-5%
Default (6)Eine Mischung aus Dokumenten und MedienAusgewogen zwischen Geschwindigkeit und Größe
Best (9)Überwiegend Text, Code oder PDFsKleinste ZIP; langsamer bei großen Eingaben
