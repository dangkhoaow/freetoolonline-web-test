Das eigentliche Zippen erledigen Sie mit dem ZIP-Datei-Tool: Ziehen Sie alle Dateien auf einmal - oder einen ganzen Ordner - hinein und klicken Sie auf Zip, um sie zu einem Archiv zu bündeln, das die ursprüngliche Ordnerstruktur für den Empfänger beibehält.

Wie das Archiv auf Ihrem eigenen Gerät erstellt wird

Weil das Bündeln innerhalb der Seite auf Ihrem eigenen Gerät läuft, verlassen die hinzugefügten Dateien niemals Ihren Rechner, und vor dem Start muss nichts installiert werden, sodass vertrauliche Unterlagen von fremden Festplatten fernbleiben. Geben Sie vor dem Download im Feld für den Ausgabenamen einen Namen für das fertige Archiv ein, statt den allgemeinen Standard zu übernehmen, damit ein als tax-2026.zip gespeichertes Bündel dem Empfänger auf einen Blick zeigt, was es enthält. Es gibt keine feste Grenze dafür, wie viele Elemente Sie in einem Durchgang hinzufügen können - die praktische Obergrenze ist der verfügbare Arbeitsspeicher Ihres Geräts, sodass hundert kleine Belege in etwa einer Sekunde zu einem Archiv zusammenschrumpfen, während mehrere Gigabyte Rohvideo den Tab spürbar länger beschäftigen. Wenn das Ziehen eines Stapels auf die Seite umständlich ist, lässt Sie derselbe Dateiwähler auch durchsuchen und die Dateien einzeln hinzufügen. Sobald das Archiv fertig ist, wird es direkt an Ihrem üblichen Download-Speicherort gespeichert, bereit zum Anhängen oder Weitergeben.
