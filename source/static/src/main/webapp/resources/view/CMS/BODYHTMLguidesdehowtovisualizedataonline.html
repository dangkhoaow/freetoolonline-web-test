Daten online visualisieren - ein Diagramm aus Ihren Zahlen erstellen

Ein Datenvisualisierer verwandelt Zahlenzeilen in ein Diagramm in Ihrem Browser. Fügen Sie CSV, JSON oder einfache Label, Wert-Zeilen ein, wählen Sie einen Diagrammtyp und sehen Sie es sofort gezeichnet. Balken, Linie, Kreis und mehr sind nur einen Klick entfernt. Alles läuft auf Ihrem Gerät, ohne Upload und ohne Konto.

Schritte

  1. Fügen Sie Ihre Daten als CSV mit einer Kopfzeile, als JSON oder als ein Paar "Label, Wert" pro Zeile ein - oder laden Sie ein eingebautes Beispiel mit einem Klick.
  2. Wählen Sie einen Diagrammtyp: Balken, Linie, Kreis, Ring, Polarbereich, Radar, Streuung, Blase oder gestapelte Balken.
  3. Geben Sie dem Diagramm einen Titel und klicken Sie auf Visualisieren; das Diagramm wird neu gezeichnet, wenn Sie Typ, Titel oder Daten ändern.
  4. Öffnen Sie ein letztes Diagramm aus der Liste erneut - die letzten Diagramme werden in diesem Browser gemerkt.

Eingabeformate

Drei Eingabeformate werden automatisch erkannt. CSV nutzt eine Kopfzeile mit Komma- oder Zeilenumbruch-Trennzeichen. JSON kann ein Array von Objekten sein (ein Namensschlüssel plus numerische Wertschlüssel) oder ein einfaches Schlüssel/Wert-Objekt. Einfacher Text ist ein Paar "Label, Wert" pro Zeile. Das Beispiel unten zeichnet fünf Werte als Balkendiagramm.

KI-Einblick auf dem Gerät

In einem Browser mit WebGPU können Sie einen optionalen privaten KI-Einblick ausführen. Das kleine Sprachmodell wird einmal heruntergeladen und läuft auf Ihrem Gerät, liest Ihre Daten und baut das Diagramm neu auf - nichts wird hochgeladen. Ohne WebGPU arbeitet die Diagramm-Engine allein, sodass das Werkzeug Ihre Daten immer zeichnet.

Datenschutz

Alles läuft in Ihrem Browser. Es gibt kein Upload-Widget und kein Konto; die letzten Diagramme bleiben nur auf Ihrem Gerät und Ihre Daten verlassen die Seite nie.

Für die strukturellen Unterschiede zwischen CSV und JSON als Datenaustauschformate, siehe CSV vs JSON data formats.
