Quando usar o N-Body Sandbox 3D Explorer

Last reviewed: 2026-08-11
freetoolonline.com editorial team

Abra o N-Body Sandbox 3D Explorer quando quiser posicionar os corpos você mesmo e ver o que a gravidade faz com eles - órbitas que se mantêm, quase-colisões que lançam um corpo para longe e capturas que você não planejou. Escolha outra página quando precisar de uma figura fixa e repetível ou de um diagrama estático de um único poço gravitacional.


Bons motivos para abrir o N-Body Sandbox

O N-Body Sandbox 3D Explorer se justifica quando a lição é o comportamento, e não uma única resposta arrumada.

  • Demonstrações em aula de órbitas emergentes, espalhamentos e capturas
  • Mostrar que o caos cresce à medida que se acrescentam corpos, o que é uma propriedade real desses sistemas e não um defeito
  • Apresentar a constante newtoniana G real ao lado de um sistema que o leitor construiu

Dispense o N-Body Sandbox quando o objetivo for uma coreografia fixa para apontar, ou uma imagem parada de um único poço gravitacional. Os dois exploradores irmãos abaixo fazem essas tarefas diretamente.


Montar um sistema no N-Body Sandbox

O N-Body Sandbox 3D Explorer abre com um sistema inicial de quatro corpos: uma massa central pesada e três mais leves já em movimento. A partir daí a sequência é curta.

  1. Abra o N-Body Sandbox 3D Explorer e deixe o sistema inicial de quatro corpos assumir o seu movimento.
  2. Leia o painel de dados: o valor real de G, quantos corpos estão na cena entre os 16 que o sandbox permite, quantos estão em órbitas ligadas e quantos estão escapando ou sendo espalhados.
  3. Escolha Light body ou Heavy body para o próximo corpo que for acrescentar. O painel confirma a escolha na linha do próximo corpo.
  4. Clique no chão para inserir esse corpo. Cada corpo novo chega com uma pequena velocidade aleatória, então começa em uma trajetória em vez de cair direto para o centro.
  5. Arraste para orbitar a câmera e role ou faça pinça para aproximar enquanto os rastros que desvanecem mostram por onde cada corpo passou. Pause congela a cena para uma captura de tela; Reset volta aos quatro corpos originais.

Acrescentar um corpo pesado ao lado de uma órbita existente é a forma mais rápida de quebrar um padrão estável de propósito - a contagem de órbitas ligadas no painel cai assim que um dos corpos mais leves ganha energia suficiente para ir embora.

Limites que vale conhecer antes de ensinar com ele

O movimento na tela do N-Body Sandbox 3D Explorer usa uma constante gravitacional escalada para que a dinâmica continue visível dentro de uma tela; o valor real do CODATA na tabela aparece para fins de literacia, não para mover as esferas. A força a curta distância é suavizada, prática padrão em código de N corpos, o que evita que a força exploda quando dois corpos passam muito perto. O resultado é um sandbox educativo e não uma efemérides de uso geral, portanto trate as posições como ilustrativas.

Abra o N-Body Sandbox 3D Explorer para construir um sistema, ou passe para o Three-Body Problem 3D e o Gravity Well 3D para as visões de figura fixa e de poço estático.
