Frequently asked questions

Why does Windows show my HEIC photo as a blank thumbnail?

Windows does not ship the HEIF codec by default, so File Explorer and the Photos app cannot decode a .heic file and show a blank or "can't open" placeholder. It is a codec problem, not a damaged file. Once you add the HEIF Image Extensions (Fix 1) or convert the photo to JPG (Fix 3), every Windows app that uses the system image stack renders it normally.

Do these fixes need administrator rights on my PC?

It depends on the fix. Installing HEIF Image Extensions from the Microsoft Store (Fix 1) and CopyTrans HEIC both need admin rights and Store access. IrfanView in portable mode (Fix 2) runs from a folder without writing to system folders or the registry, so it works without admin rights. Converting online with HEIC to JPG (Fix 3) needs nothing installed at all - only a web browser.

Does converting HEIC to JPG keep the photo's date and GPS location?

Yes. The HEIC to JPG conversion preserves EXIF metadata - capture date, camera model, and GPS coordinates if present - in the output JPG by default. If you want to remove that metadata before sharing, uncheck the EXIF option in the Settings panel on the tool page before converting.

The Microsoft Store is blocked on my work PC - what can I do?

When group policy greys out the Microsoft Store, Fix 1 is unavailable. Use IrfanView portable (Fix 2), which runs from a USB stick or a home folder without installing anything system-wide, or convert the photo to JPG online (Fix 3) using only a browser. Both paths avoid the Store entirely.

Can I open HEIC on Windows 8 or an older version?

Not with Microsoft's first-party path - HEIF Image Extensions require Windows 10 or 11. On Windows 8, 8.1, or earlier, use a third-party viewer such as IrfanView with the HEIF plugin (Fix 2) or convert the file to JPG online (Fix 3), since Windows already handles JPG on every version.
