Live AQI Checker by City - Schritt für Schritt

Last reviewed: 2026-08-04

Live AQI Checker by City läuft in drei Schritten ab: das Tool öffnen, eine Stadt eingeben und dann das Ergebnis ablesen. Diese Seite erklärt, was jeder Schritt erwartet.


Schritt 1 - das Tool öffnen

Öffnen Sie Live AQI Checker by City. Vor dem Start muss nichts installiert werden und keine Anmeldung ist nötig.


Schritt 2 - die Eingabe machen

Geben Sie einen Stadtnamen ein und klicken Sie auf Check air quality, oder klicken Sie auf Use my location, damit der Browser Ihre Koordinaten übermittelt - in beiden Fällen ist kein Konto und keine Installation nötig.


Schritt 3 - das Ergebnis ablesen

Das Ergebnis zeigt die aktuelle US-AQI-Zahl, ihre Kategorie sowie die PM2,5- / PM10- / Ozonwerte, dazu eine 3-Tages-Vorhersagetabelle des Spitzen-AQI, die beantwortet, ob sich die Luftqualität morgen verbessert - nützlich bei Waldbrandrauch oder Verschmutzungsspitzen.

Die Daten stammen live von der kostenlosen Luftqualitäts-API von Open-Meteo - es wird nichts hochgeladen und kein Konto benötigt; die Stadtsuche nutzt die Geocoding-API von Open-Meteo.

Zeigt nur die Außenluftqualität - keine Innenraum-Sensormessung und kein Ersatz für lokale Gesundheitswarnungen bei einer Rauchlage.
