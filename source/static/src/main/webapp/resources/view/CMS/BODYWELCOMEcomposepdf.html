Create Custom PDFs with Flexible Text Styling

Last reviewed: 2026-08-02

Compose PDF online lets you type or paste content in a simple editor, set a filename, and click Submit to download a PDF file. The tool runs server-side; no install or account is needed. Click Reload to clear the editor when formatting gets messy.


Recoverable from a formatting mistake

Recoverable from a formatting mistake means you click Reload instead of fighting pasted styling that collided with what you typed. The editor accepts inline bold, colour, and line breaks the same way a quick email composer does, but pasted content can carry the wrong look. Reload resets the workspace to a clean draft in one click; you lose the current draft on purpose and start over without restarting the browser.

Split a PDF you already have into smaller files. To break it down by single pages or by range, open Split PDF by range or Split PDF to each pages on the hub.

The two splitters differ by the output they write, and naming the difference saves a wrong pick. Split PDF by range pulls a chosen page span - pages 4 to 9, say - out as one new document, which is what you want when a contiguous section has to travel as a single file. Split PDF to each pages instead writes every page as its own separate file, which fits when each sheet is sent, signed, or stored on its own.

Merge several existing PDFs into one document. If your task is to take two or more already-built PDFs and combine them into one file, open Join PDFs from multiple files instead - that tool accepts the existing PDFs as uploads and writes the merged output.

Shrink a PDF you already have. If the file on hand is an already-built PDF that needs to get smaller, this composer is not the route - it creates a fresh document and does not shrink an existing one. What the export keeps, and what a Reload throws away

The composer exports what you can see in the editor: heading levels, bulleted and numbered lists, tables, and any manual page break you inserted all survive into the downloaded PDF, so a two-page report stays two pages rather than reflowing. Pasting from Word or Google Docs is where it gets fiddly - the paste often carries an inherited font size, a leftover background shade, or a stray bullet that the plain editor cannot always strip, and that stray styling rides into the PDF looking wrong. When that happens the fix is the Reload button, not more formatting fights: Reload wipes the workspace back to an empty draft in one click, and the current draft is discarded on purpose so you can retype or re-paste as plain text. Because this is the typed-text-in, PDF-out direction, there is no round-trip back to an editable source once you download, so keep your working copy in the tool (or in the document you pasted from) until the exported PDF reads the way you want.
