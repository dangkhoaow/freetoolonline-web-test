XML Formatter Online

Last reviewed: 2026-07-30

Paste any well-formed XML - an API response, a config file, an SVG, an RSS feed - and the tool pretty-prints it with consistent indentation. Formatting runs entirely in your browser using the built-in DOMParser; nothing is uploaded to any server.


Key features

  • Formats and re-indents raw or minified XML in the browser via DOMParser, with the tidy result shown in the output pane ready to copy.
  • Two in-browser text areas - an input pane for pasting your raw or minified XML and a read-only output pane for the formatted result.
  • One-click copy sends the formatted output straight to your clipboard.
  • Multi-level nested structures are indented two spaces per level.

What the formatter handles

The formatter handles XML declarations, self-closing empty elements (rendered as <tag />), and single-text-child elements kept on one line so the output stays readable. Text, CDATA, comments, and processing instructions are preserved as the markup is re-indented.


Your XML stays in the browser

Formatting runs entirely client-side with the built-in DOMParser, so the XML never leaves your device and no file is uploaded to any server.
