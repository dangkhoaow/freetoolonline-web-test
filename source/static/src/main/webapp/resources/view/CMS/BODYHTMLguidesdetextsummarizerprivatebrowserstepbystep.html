Text-Zusammenfasser - Privat, im Browser - Schritt für Schritt

Last reviewed: 2026-08-09

Text-Zusammenfasser - Privat, in Ihrem Browser funktioniert in drei Schritten: das Tool öffnen, den Text eingeben, dann das Ergebnis kopieren. Diese Seite erklärt, was jeder Schritt erwartet.


Schritt 1 - das Tool öffnen

Gehen Sie zum Text-Zusammenfasser - Privat, in Ihrem Browser. Vor dem Start muss nichts installiert oder angemeldet werden.


Schritt 2 - den Text eingeben

Ein Beispieltext und seine einfache Zusammenfassung erscheinen als Demo, sobald die Seite lädt, sodass Sie die Form der Ausgabe sehen, bevor Sie etwas einfügen.


Schritt 3 - das Ergebnis kopieren

Wenn Ihr Browser eingebaute KI mitbringt, nutzt die Seite sie ohne Download; andernfalls laden Sie ein kleines Modell direkt auf dem Gerät (Größe wird vor dem Download angezeigt, für das nächste Mal zwischengespeichert) oder bleiben im sofortigen Modus ohne Modell.

Die Statuszeile der Engine nennt immer, welcher Modus die Ausgabe erzeugt hat - eingebaute Browser-KI, ein Modell auf dem Gerät oder der einfache Durchlauf ohne Modell.
