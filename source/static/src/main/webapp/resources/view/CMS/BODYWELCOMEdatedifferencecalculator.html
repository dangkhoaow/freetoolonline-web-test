Date Difference Calculator

Last reviewed: 2026-07-12

Work out the number of days between two dates.


Key features

  • Pick a start date and an end date; the day count and week-plus-day breakdown update as you change either field.
  • The result shows a weeks-and-days breakdown, not just the raw day count.
  • Works in either direction - if the end date is before the start date, the tool still gives you the day count and says so.

When to use it

  • Count the days until a deadline.
  • Measure the duration of an event or trip.
  • Check how long ago something happened.

How it counts

Both dates are treated as midnight local time, so the count is a calendar-date difference rather than a precise elapsed-time count across time zones. Results are general estimates only and do not provide medical or financial advice.


Privacy

The calculation runs locally in the browser - no upload and no account.

Not sure this is the right way to count the days you need? See when to use the date difference calculator.

Depth: how the day count and week breakdown are worked out

When you pick a start date and an end date, the day count updates the moment you change either field - there is no submit button to press. The total is shown two ways at once, the raw day count and a weeks-plus-days breakdown, so a gap of 100 days reads as 14 weeks and 2 days with no mental arithmetic on your part. If you set the end date earlier than the start date, the tool still returns the same day count and adds a note that the end date is before the start date rather than flashing a negative number. Both dates are read as midnight local time, so a trip running from the 1st to the 8th counts as 7 calendar days, not 6.5 or 7.5 depending on the hour you happen to check. Leave either field blank or type a date the browser rejects and the tool holds off, prompting you to enter two valid dates instead of showing a broken result.
