Unix Timestamp Converter - quando usar

Last reviewed: 2026-09-02

Use o Unix Timestamp Converter sempre que um número epoch bruto precisar virar uma data humana, ou uma data precisar virar um valor epoch - sem abrir um terminal nem escrever código. Ele roda inteiramente no seu navegador, então o valor nunca sai do seu dispositivo.


Ler uma entrada de log ou uma resposta de API

Logs de servidor, respostas JSON de API e payloads de webhook costumam trazer campos como created_at: 1756800000. Colar esse número mostra a forma ISO 8601 UTC, sua hora local com o deslocamento UTC e uma frase relativa como "3 days ago" - o suficiente para saber de relance se um evento aconteceu antes ou depois de um deploy.


Conferir uma exportação de banco de dados

Exportações guardam o tempo em segundos, milissegundos, microssegundos ou nanossegundos, dependendo do motor e do tipo de coluna. O conversor detecta a unidade pela contagem de dígitos, então você pode colar qualquer um deles sem descobrir antes qual unidade a coluna usou.


Montar uma consulta ou um fixture de teste

A direção inversa serve quando uma consulta ou um teste precisa de um valor epoch: cole uma data como 2026-09-02T12:00:00Z e copie os segundos ou milissegundos Unix para o seu código ou SQL.


Quando não é a ferramenta certa

A página converte um valor por vez. Para converter uma coluna inteira de timestamps, uma fórmula de planilha ou um script funciona melhor; para agendamentos cron recorrentes, veja as ferramentas de desenvolvedor relacionadas no rodapé da página da ferramenta.
