Reading List Tracker Online

Last reviewed: 2026-07-27

Keep a running list of the books and articles you mean to read - add a title, mark it once you have finished it, and delete anything you have lost interest in.

Type a title and press Enter, or use the Add button, to append it to the list.

It stands in for a to-read versus finished checklist when you do not want to install a reading app or sign in.

Each title has a checkbox to mark it read and a button to take it off the list.

The list is saved in this browser via local storage, so it survives a page reload; clearing this site's browser data removes it. Use Export backup to save the list to a JSON file, and Import backup to restore it later or on a different device.
