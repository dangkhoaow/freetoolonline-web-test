Reading List Tracker Online

Last reviewed: 2026-07-27

Keep a running list of the books and articles you mean to read - add a title, mark it once you have finished it, and delete anything you have lost interest in.


Key features

  • Type a title and press Enter, or use the Add button, to append it to the list; an empty or whitespace-only entry is not added.
  • Each title has a checkbox to mark it read and a button to take it off the list.
  • A running count of total and remaining titles shows above the list.
  • Export backup saves every title to a JSON file, and Import backup brings a saved file back and merges those titles into your list.

When to use it

It stands in for a to-read versus finished checklist when you do not want to install a reading app or sign in.


Where your list is stored

Your to-read and finished titles are written to this browser's local storage, so the list is still there after a page reload and only a clear-out of this site's browser data erases it. To move your reading list to a different browser or device, the Export backup button saves every title to a JSON file and Import backup brings them back - the titles stay on your own machine the whole time, with no server copy and no account keeping them in step across devices.
