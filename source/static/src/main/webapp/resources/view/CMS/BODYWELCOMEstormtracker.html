Check active tornado, hurricane, flood, and other severe weather alerts straight from the National Weather Service for any US state.

How the tracker lists active alerts

Pick a state below, or press "Use my location" for a browser-location lookup, and the tool lists every active alert for that area - most severe first - with the affected area, an expiry countdown, and the official instruction text verbatim.

A warning-vs-watch-vs-advisory reference table stays on the page at all times, and when a state has no active alerts you get a clear all-clear message with a "Last checked" timestamp instead of a blank panel.

Severity rank vs. warning/watch/advisory: two different NWS scales on this page

The definitions table above answers one question - is this a Warning, a Watch, or an Advisory. The alert list answers a second, separate question - how urgent is it compared to everything else active right now. That second scale is severity rank, and it decides both the sort order and the color marker on the left edge of each card:

Severity NWS assignsCard colorList position
ExtremeDark red1st
SevereRed2nd
ModerateOrange3rd
MinorYellow4th

A Tornado Warning marked Extreme therefore sorts and displays ahead of a Flood Advisory marked Minor, even though both might be active for the same state at the same time.
