FrageAntwort
Kennen Sie das Passwort?Wenn JA, verwenden Sie /remove-zip-password.html - es baut das Archiv ohne die Passwort-Schicht neu auf und gibt Ihnen die entsperrte Kopie.
Kennen Sie das Passwort NICHT?Kein legitimes Online-Werkzeug wird es erraten. Die AES-256-Verschluesselung von ZIP ist mathematisch in keiner praktischen Zeit per Brute-Force machbar. Versuchen Sie haeufige Muster (siehe unten), fragen Sie dann den Absender oder erstellen Sie das Archiv neu.
Unterstuetzte ArchivtypenNur .zip (kein .rar, .7z, .tar, .gz, verschluesseltes .pdf, verschluesseltes .docx).
Was gleich bleibtDas urspruenglich .zip auf Ihrem Geraet bleibt unveraendert. Der Entferner produziert eine neue, entsperrte Kopie als Download.
Datenschutz-HaltungDas Archiv wird ueber HTTPS hochgeladen, der Server baut es ohne Passwort neu auf, die entsperrte Kopie wird heruntergeladen und die hochgeladene Kopie wird nach einem kurzen Aufbewahrungsfenster automatisch geloescht. Kein Konto und keine Anmeldung.

Was der Entsperrer auf dieser Seite wirklich tut

Was der Entsperrer auf dieser Seite wirklich tut: Passwort das Sie kennen eingeben, ZIP im Browser mit Remove ZIP Password oeffnen, entsperrte Kopie laden - keine Rateversuche unbekannter Passwoerter.

Wenn Sie das Passwort vergessen haben, das Archiv aber Ihres ist

Wenn Sie das Passwort vergessen haben, das Archiv aber Ihres ist: Passwort-Manager, Chat-Verlauf und Erzeuger-Tool pruefen - dann Remove ZIP Password erneut; aus Quellen neu bauen ist schneller als Brute-Force.

Wenn Sie das Passwort nicht kennen und nie kannten

Wenn Sie das Passwort nicht kennen und nie kannten, hilft der ZIP-Passwort-Entsperrer hier nicht - Absender fragen oder Archiv aus Originalen neu bauen; Raten ist ausserhalb dieser Anleitung.
