Notepad / Notes

Last reviewed: 2026-07-13

Jot down quick notes and keep them in this browser - no sign-in, no sync.

Use it for a quick scratchpad - a phone number, a draft line, or a reminder you do not want to type into a permanent app.

Each note has a Copy button to copy its text, and a Delete button to remove it; notes cannot be edited in place, so delete and re-add to change one.

Because a note here is copied or deleted rather than saved to any account, each one lives only in this browser's local storage - reopening or reloading the page brings your notes right back, while clearing this site's browser data throws them out. To keep a copy or read them on another browser, the Export backup (JSON) button writes your notes to a file and Import backup loads that file in; the notes are never sent to a server, so that saved file is the one way to carry them across.
