So Erkunden Sie den Pulsar Timing Array 3D Explorer

Zuletzt überprüft: 2026-08-04

Überprüft von FreetoolOnline-Redaktionsteam

Öffnen Sie den Pulsar Timing Array 3D Explorer, verschieben Sie den Trennwinkel-Regler und beobachten Sie, wie die live berechnete Hellings-Downs-Korrelation zwischen dem goldenen Referenzpulsar und dem magentafarbenen Testpulsar steigt, ins Negative fällt und wieder ansteigt.

  1. Öffnen Sie /space-3d/pulsar-timing-array.html und warten Sie, bis die Erde, das Pulsar-Array und das markierte Paar dargestellt werden.
  2. Ziehen Sie den Trennwinkel-Regler von 0 auf 180 Grad und beobachten Sie, wie sich der magentafarbene Testpulsar entlang des gestrichelten Bogens vom goldenen Referenzpulsar entfernt.
  3. Drücken Sie "Play sweep", um den vollen Zyklus von 0 bis 180 Grad automatisch ablaufen zu lassen.
  4. Aktivieren Sie "Show correlation-curve chart", um das eingebettete Diagramm mit der Korrelation für jeden Winkel anzuzeigen, mit einer Markierung an Ihrer aktuellen Position.
  5. Lesen Sie im Faktenbereich die live berechnete Hellings-Downs-Korrelationszahl und ob das Paar positiv korreliert, antikorreliert oder nahezu null ist.
  6. Ziehen Sie, um die Szene zu drehen, und scrollen oder zoomen Sie mit zwei Fingern, um das Array besser zu sehen.
