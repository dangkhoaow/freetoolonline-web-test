Steps

Steps are open the to-do list tool, type an item, press Enter, then check items off as you finish - on How to Make a Todo List Online the list stays in the browser until you clear it.

  1. Open the tool and type your first task in the input box.
  2. Press Enter or click Add to put it on the list.
  3. Tick the checkbox next to a task when you finish it; it shows as done.
  4. Use the Delete button to remove a task you no longer need.

Where your list is saved

The list lives in your browser's local storage, so it is still there when you reload the page or come back later on the same device and browser. Nothing is uploaded and there is no account to create. Clearing this site's browser data removes the list.

Details a quick answer leaves out

A short summary covers the basics; a few behaviors are easy to miss until you hit them. Empty entries are rejected on purpose - press Enter on a blank box and a brief inline message appears instead of a blank row, so the list never fills with stray placeholders. New tasks land at the top of the list rather than the bottom, which keeps the item you just added in view instead of pushing it beneath a long backlog. Ticking a task's checkbox does not remove it - it draws a line through the text and keeps it on the list as a visible done item, so you can see what you have already cleared; the delete button is the only thing that takes a row off for good. A running count beside the list tracks how many items are still open, so "four left" is visible at a glance without recounting the rows.
