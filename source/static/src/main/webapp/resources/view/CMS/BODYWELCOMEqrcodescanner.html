QR Code Scanner

Last reviewed: 2026-07-03

Find out what a QR code says from a screenshot or saved photo - choose the image and the decoded text appears in seconds, no app install.

When the code contains a link, the tool shows the exact URL as a clickable link BEFORE you visit it - an easy way to check a suspicious QR code for phishing.

Copy the decoded value with one click - handy for wifi passwords, serial numbers, coupon strings or long payment references.

The image is decoded locally in this browser tab and never uploaded anywhere, so it is safe to check boarding passes, wifi cards, tickets, or payment codes. A full-resolution phone photo still decodes quickly, because the scanner scales large images down automatically before reading them; if no code is found, it says so and asks for a clearer or larger image instead of failing silently. There is no camera mode - this scanner only reads a saved image or screenshot you choose, and it decodes QR codes only, not 1D barcodes like EAN-13 or Code-128.
