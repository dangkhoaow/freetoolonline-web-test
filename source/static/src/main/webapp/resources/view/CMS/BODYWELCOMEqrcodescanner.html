QR Code Scanner

Last reviewed: 2026-07-03

Find out what a QR code says from a screenshot or saved photo - choose the image and the decoded text appears in seconds, no app install.


Key features

  • Check a link before you visit it - when the code contains a link, the tool shows the exact URL as a clickable link first, an easy way to check a suspicious QR code for phishing.
  • Copy the decoded value with one click - handy for wifi passwords, serial numbers, coupon strings or long payment references.
  • Full-resolution phone photos work - large images are scaled down automatically before reading them, so even a 12MP photo decodes quickly.

Your image stays private

The image is decoded locally in this browser tab and never uploaded anywhere, so it is safe to check boarding passes, wifi cards, tickets, or payment codes.

What this scanner reads

There is no camera mode - this scanner only reads a saved image or screenshot you choose, and it decodes QR codes only, not 1D barcodes like EAN-13 or Code-128. If no code is found, it says so and asks for a clearer or larger image instead of failing silently.
