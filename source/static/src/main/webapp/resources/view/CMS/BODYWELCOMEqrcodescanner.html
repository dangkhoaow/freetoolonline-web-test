QR Code Scanner

Last reviewed: 2026-07-03

Find out what a QR code says from a screenshot or saved photo - choose the image and the decoded text appears in seconds, no app install.


Key features

  • When the code holds a link, the tool shows the exact URL as a clickable link BEFORE you visit it - an easy way to check a suspicious QR code for phishing.
  • Copy the decoded value with one click - handy for wifi passwords, serial numbers, coupon strings or long payment references.
  • A full-resolution phone photo still decodes quickly, because the scanner scales large images down automatically before reading them.
  • A short status line tracks the read as it happens - a decoding-in-progress note the moment you pick an image, so a large photo never looks like a frozen page while it is being processed.
  • If no code is found, it says so and asks for a clearer or larger image instead of failing silently; on a slow or dropped connection where the decoder cannot finish loading, the tool tells you plainly and invites a reload, instead of leaving a blank result panel with no explanation.

What this scanner reads

There is no camera mode - this scanner only reads a saved image or screenshot you choose, and it decodes QR codes only, not 1D barcodes like EAN-13 or Code-128.
