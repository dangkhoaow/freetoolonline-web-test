File Viewer

Last reviewed: 2026-10-05

Open an image, PDF, text file, JSON export, audio clip, or video and preview it right here. Nothing is uploaded.

What you can do

  • Open almost any file type and see it rendered the way it is meant to look: images as images, PDFs page by page, text and JSON as readable text, audio and video with the browser's own playback controls.
  • Get a plain hex-and-ASCII dump for the rare file the browser cannot render natively, so you still see something instead of a blank error.
  • Read a details table - name, size, type, last-modified - for every file, even ones with no visual preview.
  • Keep your file private - everything happens in the browser and nothing is uploaded.

How to use it

Choose a file with the picker above; the file's type decides how it renders, so there is no setup and nothing to configure. Pick Clear or choose a different file to start over - File Viewer releases the previous file's in-browser preview link from memory automatically.

When to use it

Reach for this when you want a quick look inside a file - checking what a download actually contains, confirming a PDF's page count, or glancing at a JSON export - without installing a desktop viewer or sending the file anywhere. For programmatic access instead, see the related developer tools.

Privacy

Inputs are not uploaded. The file is read and displayed on your own device, so nothing is sent to a server, and the in-browser preview link is released from memory as soon as you clear the tool or open a different file.
