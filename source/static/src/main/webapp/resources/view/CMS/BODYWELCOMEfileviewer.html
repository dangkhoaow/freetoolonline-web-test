File Viewer

Last reviewed: 2026-08-26

Inspect a file as an expandable tree in the browser, then search it by field name or value. Your input is never uploaded.

What you can do

  • Open a file and read it as an expandable tree, clicking any node to expand or collapse it.
  • Find a field fast with the search box, matching on field name or value.
  • Keep your file private - inputs are processed in the browser and are not uploaded.

How to use it

Paste or upload the input, then click a node to expand or collapse it. Use the search box to jump to a field by name or value. Nothing leaves your device.

When to use it

Reach for this when you want to glance inside a file structure without installing a desktop viewer or sending the file anywhere. For programmatic access instead, see the related developer tools.

Privacy

Inputs are not uploaded. The file is read and displayed on your own device, so nothing is sent to a server.
