Qual nível de compressão escolher

Ajuste o nível de compressão ao conteúdo do arquivo. A ferramenta oferece três níveis; a tabela abaixo mostra para que cada um serve melhor.

Nível de compressãoIdeal paraResultado
Store (0)Arquivos já compactados (MP4, JPG, HEIC)O mais rápido; o tamanho cai apenas 0-5%
Default (6)Uma mistura de documentos e mídiaEquilíbrio entre velocidade e tamanho
Best (9)Principalmente texto, código ou PDFsZIP menor; mais lento com entradas grandes
