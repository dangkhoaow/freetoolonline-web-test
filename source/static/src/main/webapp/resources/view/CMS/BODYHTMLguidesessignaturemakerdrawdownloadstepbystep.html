Signature Maker - Paso a Paso

Last reviewed: 2026-07-25

Signature Maker funciona en tres pasos: abrir la herramienta, dibujar tu firma y luego descargar el archivo. Esta página explica qué esperar en cada paso.


Paso 1 - abre la herramienta

Ve a Signature Maker. No necesitas instalar nada ni iniciar sesión antes de empezar.


Paso 2 - dibuja tu firma

Elige un color y un ancho de pluma, luego firma dentro del recuadro con el mouse, el dedo o un lápiz óptico. Usa Deshacer para quitar el último trazo o Borrar para empezar de nuevo si no queda bien.


Paso 3 - descarga el resultado

Haz clic en Descargar PNG. Conserva el fondo blanco para documentos, o activa antes la opción de fondo transparente para pegar la firma sobre otro contenido.

Todo se ejecuta en el navegador - sin subir archivos, sin cuenta, y el dibujo nunca se envía a ningún lugar. Recargar o salir de la página borra el lienzo, así que descarga antes de navegar a otro lado.
