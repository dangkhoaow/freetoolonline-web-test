Aspect Ratio Calculator

Last reviewed: 2026-09-04

Enter an original width and height and the tool simplifies the ratio down to its lowest terms (for example 1920x1080 reduces to 16:9), showing the decimal value too.


Key features

  • Original width and height number inputs, prefilled with 1920x1080 and editable to any dimensions.
  • A new-width and new-height pair - type into either one and the matching side scales automatically along the same ratio.
  • Seven one-tap presets - 16:9, 9:16, 4:3, 3:2, 1:1, 21:9, and 5:4 - fill the width and height for you.

When to use it

It is handy for resizing an image, video frame, or design canvas without distorting it - so a photo, export, or layout keeps its original proportions at the new size.


Privacy

The width and height you type stay in the browser - the ratio is reduced on this device, with no upload and no account.


What a zero or negative width does

Aspect Ratio Calculator does not show a validation error for an out-of-range original width or height. Type 0 or a negative number into either field and the calculator quietly treats it as 1 instead of stopping the calculation, so the ratio still renders against that floor value rather than the number you actually typed. Typing 0 for the original height, for example, computes the ratio as if you had entered 1, not as an error or a blank result.


Comparing preset ratios without retyping your target size

Aspect Ratio Calculator remembers which of the new-width or new-height fields you typed into last. Enter a target once, such as a new width of 1280, then click through the preset buttons one after another - the other field recalculates automatically to match whichever ratio you just picked, without you retyping 1280 each time. This makes it quick to compare how the same target width looks under a square crop versus a wide frame.
