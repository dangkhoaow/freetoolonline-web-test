When to Use Bennu + OSIRIS-REx TAG Sample Return 3D Explorer - Best Sessions and Limits

Last reviewed: 2026-08-09

Open Bennu + OSIRIS-REx TAG Sample Return 3D Explorer when you need a clear picture of NASA's real 2020 touch-and-go sample grab on asteroid Bennu and the surprising "ball pit" surface finding it revealed - not a live tracker and not a contact-dynamics simulation.


A sample-return lesson

A lesson starts by clicking "Simulate TAG" and watching the spacecraft's arm sink into Bennu's surface, then reading the facts panel's real sample mass, return date, and impact-risk figures.


When the Bennu explorer is the wrong tool

Skip this explorer when you need a numerically integrated descent-and-contact model: the boulder-strewn Bennu you see here is a procedural teaching shape, and the touch-and-go arm plant runs as a scripted sequence timed for clarity rather than a physics solver computing regolith mechanics. It is also not a live position feed for Bennu or for the extended-mission spacecraft now renamed OSIRIS-APEx and headed toward asteroid Apophis. The dates it teaches are fixed history - the October 2020 sample grab and the capsule's 2023-09-24 return to the Utah desert - so it will not forecast Bennu's future Earth close approaches. To compare a different agency's touch-and-go collection, one that also fired an artificial impactor to expose buried material, use the Hayabusa2-Ryugu Sample Return 3D Explorer; to see a craft that deliberately slammed into an asteroid as a planetary-defense test instead of sampling it, use the DART Asteroid Deflection 3D Explorer.
