When to Use Bennu + OSIRIS-REx TAG Sample Return 3D Explorer - Best Sessions and Limits

Last reviewed: 2026-08-09

Open Bennu + OSIRIS-REx TAG Sample Return 3D Explorer when you need a clear picture of NASA's real 2020 touch-and-go sample grab on asteroid Bennu and the surprising "ball pit" surface finding it revealed - not a live tracker and not a contact-dynamics simulation.


A sample-return lesson

A lesson starts by clicking "Simulate TAG" and watching the spacecraft's arm sink into Bennu's surface, then reading the facts panel's real sample mass, return date, and impact-risk figures.


Sessions this explorer does not fit

Sessions this page does not fit are a numerically integrated descent-and-contact simulation - Bennu's bumpy shape is a procedural teaching shape and the TAG sequence is a scripted state machine timed for clarity, not a physics solver - or a live tracker of Bennu or the renamed OSIRIS-APEx spacecraft today. For a different agency's touch-and-go sample-return mission with its own artificial-impactor crater, use the Hayabusa2-Ryugu Sample Return 3D Explorer; for a spacecraft that deliberately crashed into an asteroid to test planetary defense, use the DART Asteroid Deflection 3D Explorer.
