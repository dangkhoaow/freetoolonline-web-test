Favicon Generator

Last reviewed: 2026-07-21

Resize an image into standard favicon PNG sizes and a favicon.ico in the browser.

Choose a local image; previews for 16, 32, 48, 180, 192, and 512 appear below. Download the ICO or individual PNGs.

Background removal and text-to-icon generation are not offered here.

Which favicon size is used where

Each size this tool exports targets a different place an icon shows up, so you only need the ones your project actually uses. The downloadable favicon.ico already bundles the three classic browser sizes, and the individual PNGs cover mobile and progressive-web-app slots.

Size (px)Where it is used
16, 32Browser tab and bookmark bar
48Windows site icon and older desktop shortcuts
180Apple touch icon for the iOS home screen
192, 512Android home screen and PWA manifest icon (a plain PNG, not a platform adaptive icon)
favicon.icoLegacy /favicon.ico fallback; this file packs the 16, 32, and 48 sizes together
