Visualizador de Arquivos Passo a Passo

Last reviewed: 2026-08-26

O Visualizador de Arquivos funciona em três etapas: abra a ferramenta, forneça o seu arquivo e, em seguida, copie o resultado. Esta página explica o que cada etapa espera.


Etapa 1 - abrir a ferramenta

Acesse o Visualizador de Arquivos. Nada precisa ser instalado nem exige login antes de começar.


Etapa 2 - forneça o seu arquivo

É possível pesquisar pelo nome do campo ou pelo valor usando a caixa de pesquisa.


Etapa 3 - copie o resultado

Os arquivos não são enviados para nenhum servidor.

Para acesso programático, consulte as ferramentas de desenvolvedor relacionadas.
