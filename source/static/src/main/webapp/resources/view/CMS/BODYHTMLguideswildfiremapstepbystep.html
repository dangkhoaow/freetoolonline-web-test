How to Use the Live Wildfire Map - Step by Step

Last reviewed: 2026-08-08

The live wildfire map shows every active US fire the federal NIFC system is reporting, the moment you open it - no steps needed for the default view. The four steps below narrow it to the fires you actually care about: read the dots, filter by state and size, then sort by distance from you.


Step 1 - open the page and let it load

Go to the Live Wildfire Map. The current incident list loads straight into your browser from the federal NIFC WFIGS feed - no account, no app, no API key. Within a moment the status line reports how many incidents match, the map plots them, and the list below ranks them largest-first.


Step 2 - read the dots

Each dot is one incident. Bigger dot = more acres. The color is the containment band: red means little or no containment, orange and yellow mean a partial control line, green means 90 percent contained or better. Grey dots are prescribed burns - planned, controlled fires. Hover any dot to see the fire's name, county, acreage, and containment without leaving the map.


Step 3 - filter by state, size, and type

The state menu narrows both the map and the list to one state, with a live incident count shown next to each state. The size menu hides small fires - show only 100+, 1,000+, or 10,000+ acres. By default the view is wildfires only; tick Include prescribed burns to add the grey RX incidents. Refresh incidents re-pulls the latest data at any time.


Step 4 - sort by distance from you (optional)

Press Sort by distance from me and allow the location prompt. The list re-sorts nearest-first and gains a distance column in kilometers and miles. The permission is one-shot and optional - your location is used in this tab only, never stored, never sent anywhere - and every other feature works without it.


Reading the list

Each row shows the incident name, state, county, acres, percent contained, and how long ago it was discovered. The list caps at the 150 largest matches; if more match, a note under the table says so - narrow the state or size filter to see the rest.
