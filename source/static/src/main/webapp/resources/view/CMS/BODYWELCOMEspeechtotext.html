Speech to Text

Last reviewed: 2026-08-09

Convert a SPEECH input into a TEXT output - one step, in the browser.

Typical use: when your downstream platform accepts TEXT but not SPEECH.


Two panels, both on screen

The page stacks two panels and both stay on screen - there is no mode to switch.

PanelWhat it doesInput
Dictation (top)Types what you say as you speak, handy for a note, an email, or a quick draft.Your microphone, live.
File transcription (below)Transcribes a recording you already have - a meeting, a voice memo, a lecture, or an interview.An audio file: .mp3, .wav, .m4a, .ogg, or .webm.

Key features

  • Pick the file, click Transcribe file, and the transcript appears in the output box with Copy transcript and Download .txt buttons.
  • Files up to about 15 minutes are supported - trim longer recordings first.
  • One setting: the Language dropdown beside the Load transcription model button. Leave it on Auto-detect, or name the spoken language to keep the file transcript on that language from start to finish.

When to use each panel

Use the dictation panel when you can speak the content live, and the file panel when the audio already exists. Clear speech in a quiet room transcribes best; the small on-device model is weaker with heavy accents, overlapping voices, and background noise.


How long files are transcribed

A recording longer than 30 seconds is cut into 30-second windows that are transcribed one after another: the progress bar fills and the status line counts "window X of N" as each window finishes, and that window's words are added to the output box while the rest keep running. Consecutive windows overlap by two seconds so that no word is cut in half at a seam, which means a word or two can appear twice where one window meets the next. Give the transcript a quick read before you rely on it.


Privacy

File transcription runs on your own device with the Whisper AI model, so the recording is never uploaded to a server. The model downloads once (about 40 MB) when you click Load transcription model; after that your browser caches it and later visits skip the wait.
