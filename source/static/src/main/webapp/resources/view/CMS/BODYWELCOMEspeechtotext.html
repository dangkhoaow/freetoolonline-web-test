Speech to Text

Last reviewed: 2026-08-09

Convert a SPEECH input into a TEXT output - one step, in the browser.

Typical use: when your downstream platform accepts TEXT but not SPEECH.

Output sizing and quality are controlled by the option fields above the file picker; defaults match the most common downstream use.

To compare this tool against desktop and server-based alternatives before committing to a workflow, see the speech-to-text alternatives guide.

The page offers two modes. The mic mode types what you say as you speak - handy for dictating a note, an email, or a quick draft. The file mode transcribes a recording you already have: a meeting, a voice memo, a lecture, or an interview saved as .mp3, .wav, .m4a, .ogg, or .webm. Pick the file, click Transcribe file, and the transcript appears in the output box with copy and download buttons.

File transcription runs on your own device with the Whisper AI model, so the recording is never uploaded to a server. The model downloads once (about 40 MB) when you click Load transcription model; after that your browser caches it and later visits skip the wait. A progress bar tracks each 30-second chunk of audio, and files up to about 15 minutes are supported - trim longer recordings first.

Use the mic mode when you can speak the content live, and the file mode when the audio already exists. Clear speech in a quiet room transcribes best; the small on-device model is weaker with heavy accents, overlapping voices, and background noise, so give the transcript a quick read before you rely on it.
