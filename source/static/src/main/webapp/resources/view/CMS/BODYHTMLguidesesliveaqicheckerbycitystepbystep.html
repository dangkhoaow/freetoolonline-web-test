Live AQI Checker by City - Paso a Paso

Last reviewed: 2026-08-04

Live AQI Checker by City funciona en tres pasos: abrir la herramienta, indicar una ciudad y luego leer el resultado. Esta página explica qué espera cada paso.


Paso 1 - abrir la herramienta

Ve a Live AQI Checker by City. No necesitas instalar nada ni iniciar sesión antes de empezar.


Paso 2 - indicar tu entrada

Escribe el nombre de una ciudad y pulsa Check air quality, o pulsa Use my location para que el navegador indique tus coordenadas - de cualquier forma, no necesitas cuenta ni instalación.


Paso 3 - leer el resultado

El resultado muestra el número actual de US AQI, su categoría, y los niveles de PM2.5 / PM10 / ozono, además de una tabla de pronóstico del AQI máximo a 3 días que responde si la calidad del aire mejorará mañana, útil durante episodios de humo de incendios forestales o picos de contaminación.

Los datos llegan en vivo desde la API gratuita de calidad del aire de Open-Meteo - no se sube nada y no se requiere cuenta; la búsqueda de ciudad usa la API de geocodificación de Open-Meteo.

Muestra solo la calidad del aire ambiental exterior - no es una lectura de un sensor de aire interior ni sustituye los avisos de salud locales durante un episodio de humo.
