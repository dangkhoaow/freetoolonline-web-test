User Agent Parser - Schritt für Schritt

Last reviewed: 2026-07-24

Der User Agent Parser laeuft in drei Schritten: Tool oeffnen, Eingabe machen, dann Ergebnis kopieren. Diese Seite geht durch, was jeder Schritt erwartet.


Schritt 1 - Tool oeffnen

Oeffne den User Agent Parser. Vor dem Start muss nichts installiert oder eingeloggt werden.


Schritt 2 - Eingabe machen

Fuege eine beliebige User-Agent-Zeichenfolge in das linke Feld ein, oder lasse es leer, damit das Tool automatisch den User-Agent deines eigenen Browsers liest. Klicke auf die Schaltflaeche, um sie zu entschluesseln.


Schritt 3 - Ergebnis kopieren

Das rechte Feld fuellt sich mit Browsername und -version, Render-Engine, Betriebssystem und Geraeteklasse, gefolgt von der urspruenglichen Rohzeichenfolge. Nutze die Schaltflaeche Copy Output, um sie in die Zwischenablage zu kopieren. Das alles passiert lokal in deinem Browser - nichts, was du einfuegst, wird an einen Server gesendet.

Alles laeuft lokal im Browser - kein Upload und kein Konto.
