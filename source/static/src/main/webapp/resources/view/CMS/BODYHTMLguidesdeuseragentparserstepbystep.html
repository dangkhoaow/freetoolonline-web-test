User Agent Parser - Schritt für Schritt

Last reviewed: 2026-07-24

Der User Agent Parser läuft in drei Schritten: Tool öffnen, Eingabe machen, dann Ergebnis kopieren. Diese Seite geht durch, was jeder Schritt erwartet.


Schritt 1 - Tool öffnen

Öffne den User Agent Parser. Vor dem Start muss nichts installiert oder eingeloggt werden.


Schritt 2 - Eingabe machen

Füge eine beliebige User-Agent-Zeichenfolge in das linke Feld ein, oder lasse es leer, damit das Tool automatisch den User-Agent deines eigenen Browsers liest. Klicke auf die Schaltfläche, um sie zu entschlüsseln.


Schritt 3 - Ergebnis kopieren

Das rechte Feld füllt sich mit Browsername und -version, Render-Engine, Betriebssystem und Geräteklasse, gefolgt von der ursprünglichen Rohzeichenfolge. Nutze die Schaltfläche Copy Output, um sie in die Zwischenablage zu kopieren. Das alles passiert lokal in deinem Browser - nichts, was du einfügst, wird an einen Server gesendet.

Alles läuft lokal im Browser - kein Upload und kein Konto.
