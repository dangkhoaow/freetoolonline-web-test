Cara Menggunakan Pemeriksa JSON Online - Langkah demi Langkah

Last reviewed: 2026-07-30

Pemeriksa JSON Online membandingkan dua teks JSON dan menyorot penambahan, penghapusan, dan nilai yang berubah - semua di browser, tanpa instalasi.

Langkah 1 - Buka alat

Buka developer-tools/json-diff-checker.html. Alat ini dimuat langsung di browser - tidak perlu menginstal program apa pun.

Langkah 2 - Tempel dua JSON

Tempel JSON asli di panel kiri (Original JSON) dan JSON yang dimodifikasi di panel kanan (Modified JSON). Objek bertingkat dan array dibandingkan secara rekursif.

Langkah 3 - Klik Compare dan tinjau

Klik tombol Compare. Setiap baris hasil menampilkan jalur kunci lengkap (misalnya user.address.city), nilai lama, dan nilai baru. Kunci yang ditambahkan berwarna hijau, yang dihapus merah, dan yang berubah kuning.

Langkah 4 - Salin hasilnya

Klik Copy Diff untuk menyalin ringkasan diff ke clipboard. Tidak ada data yang keluar dari browser Anda.
