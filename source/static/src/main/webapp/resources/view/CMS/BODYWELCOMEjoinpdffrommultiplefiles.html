A merged PDF can grow large fast - twenty scanned receipts or a stack of contracts adds up to many megabytes. Once the join is done, route the combined file through our file compressor to shrink it before emailing or uploading.

What the combined PDF keeps from each source file

When you combine multiple PDFs into one, each source file keeps its pages exactly as they were - the merge concatenates them page by page rather than re-rendering, so text stays selectable and there is no quality loss. Because nothing is recompressed, the combined output weighs roughly the sum of its inputs: three 2 MB reports become one file near 6 MB, not smaller. Bookmarks, embedded fonts, and form fields carry through when the source files present them as valid, landing at their original page numbers. Drag the files into the sequence you want before merging; if the order still looks wrong in the download, reorder the source files and merge again rather than rearranging pages inside the finished PDF.
