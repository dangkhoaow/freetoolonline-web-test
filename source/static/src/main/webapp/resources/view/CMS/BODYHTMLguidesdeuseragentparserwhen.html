User Agent Parser - Wann Nutzen

Last reviewed: 2026-07-24

Es lohnt sich, den User Agent Parser zu oeffnen, wenn du eine schnelle, einmalige Pruefung brauchst, ohne etwas zu installieren. Diese Seite erklaert, wann das passt und wann nicht.


Wann es passt

Nutze ihn, wenn ein Support-Ticket, ein Server-Zugriffsprotokoll oder ein Analytics-Export eine rohe User-Agent-Zeichenfolge enthaelt und du wissen musst, welcher Browser, welches System oder welches Geraet dahintersteckt, ohne eine UA-String-Referenztabelle von Hand zu durchsuchen. Er ist auch nuetzlich, um zu pruefen, ob sich der User-Agent-String eines Bots oder Crawlers so identifiziert, wie es seine Dokumentation behauptet.


Was zu erwarten ist

Fuege die Zeichenfolge ein (oder lasse das Feld leer, um die deines eigenen Browsers zu lesen), und das Tool liefert Browsername und -version, Render-Engine, Betriebssystem und Geraeteklasse - alles lokal in deinem Browser entschluesselt, ohne dass etwas an einen Server gesendet wird. Es erkennt die aktuellen wichtigsten Desktop- und Mobil-Browser und -Betriebssysteme; eine unbekannte Zeichenfolge liefert trotzdem den Rohtext plus alle Felder, die es sicher erkennen kann.
