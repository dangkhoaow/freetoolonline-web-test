Cómo Usar el Explorador 3D del Horizonte del Universo Observable - Paso a Paso

Última revisión: 2026-08-27

Abre el Explorador 3D del Horizonte del Universo Observable, arrastra el control deslizante "Cosmic time" desde el Big Bang hacia hoy, y observa cómo las dos esferas crecientes se separan.


Recorre el tiempo cósmico

Arrastra el control deslizante "Cosmic time" para saltar a cualquier momento entre el Big Bang y hoy (13,787 mil millones de años), o pulsa "Play cosmic time" para moverte automáticamente. Observa cómo la esfera naranja de distancia comóvil supera a la esfera verde de distancia recorrida por la luz a medida que avanza el tiempo.


Alterna entre las lecturas comóvil y de tiempo de luz

Pulsa "Showing: comoving distance" para cambiar el titular del panel de datos a "Showing: light-travel distance" en el mismo momento cósmico - los dos números describen el mismo instante de forma diferente, no dos momentos distintos.


Elige una capa de referencia

Pulsa "Milky Way", "Local Group", "Virgo galaxy cluster", "Laniakea Supercluster", "Hubble radius" o "Particle horizon" para cargar la distancia característica real y el texto de datos de esa capa en el panel y resaltarla en la escena.


Lee el panel de datos

La tabla siempre visible enumera la edad del universo, el radio comóvil del horizonte de 46,5 mil millones de años luz, la distancia ingenua de tiempo de luz de 13,8 mil millones de años luz, el radio de Hubble de 14,4 mil millones de años luz, y dos estimaciones publicadas y competidoras del número de galaxias.


Arrastra para orbitar y usa pantalla completa

Arrastra para orbitar la cámara, usa la rueda del mouse o el gesto de pinza para hacer zoom, y usa el botón de Pantalla Completa para expandir todo el marco y obtener una vista más clara.
