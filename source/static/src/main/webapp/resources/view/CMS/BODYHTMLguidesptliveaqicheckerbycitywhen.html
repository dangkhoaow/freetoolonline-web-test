Live AQI Checker by City - Quando Usar

Last reviewed: 2026-08-04

Live AQI Checker by City vale a pena abrir quando você precisa de uma consulta rápida e única, sem instalar nada. Esta página explica quando isso se aplica e quando não se aplica.


Quando se aplica

Uma tabela de previsão do pico do AQI para 3 dias abaixo do resultado responde se a qualidade do ar vai melhorar amanhã, útil em episódios de fumaça de incêndios florestais ou picos de poluição.


O que esperar

Os dados vêm em tempo real da API gratuita de qualidade do ar da Open-Meteo - nada é enviado para upload e nenhuma conta é necessária; a busca de cidade usa a API de geocodificação da Open-Meteo.

Mostra apenas a qualidade do ar ambiente externo - não é uma leitura de sensor de ar interno e não substitui os alertas de saúde locais durante um episódio de fumaça.
