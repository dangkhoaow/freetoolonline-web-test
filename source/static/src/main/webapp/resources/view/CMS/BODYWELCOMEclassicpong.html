Classic Pong

Last reviewed: 2026-08-04
FreetoolOnline editorial team

Classic Pong is a free browser canvas table-tennis game you play without an account or install: press Play to load the ~60 KB game in a same-origin iframe, then choose 1 for vs AI, 2 for local two-player, or 0 for a computer demo.

It runs on desktop and mobile, and a keyboard makes the two-player match easier - Player 1 uses Q and A, Player 2 uses P and L, and Esc abandons the current match. Privacy note: nothing leaves this device except the initial page and game files from this site. For more free browser games, open the games hub.
