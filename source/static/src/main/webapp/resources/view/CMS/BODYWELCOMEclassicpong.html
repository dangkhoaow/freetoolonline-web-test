Classic Pong

Last reviewed: 2026-08-04
FreetoolOnline editorial team

Classic Pong is a free browser canvas table-tennis game you play without an account or install. Press Play to load it, then rally the ball past the other paddle to score.


Key features

  • Three modes - press 1 for vs AI, 2 for local two-player, or 0 for a computer demo.
  • Keyboard paddles - Player 1 uses Q and A, Player 2 uses P and L, and Esc abandons the current match.
  • Optional sound effects for the ping, pong, wall bounces, and goals.
  • Runs on desktop and mobile, and a keyboard makes the two-player match easier.

How it loads

Press Play to load the ~60 KB game in a same-origin iframe. The build is session-only, so there is nothing to install and no progress is saved.


Privacy

Nothing leaves this device except the initial page and game files from this site.
