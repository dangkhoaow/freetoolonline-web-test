If the AI watermark detector comes back clean, treat that as inconclusive rather than proof the image is human-made - a screenshot or a simple re-save already strips every metadata mark the scan can see, and Google's SynthID sits inside the pixels where no browser tool can reach it. Checking text works differently: there is no reliable AI-text detector at all, so the AI text detector instead lists concrete tells like invisible Unicode characters and repetition statistics rather than guessing a percentage.
