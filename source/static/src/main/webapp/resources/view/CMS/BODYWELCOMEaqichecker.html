Live AQI Checker by City

Last reviewed: 2026-08-04

Check the current air quality (US AQI) for any city, right in the browser.

A 3-day peak-AQI forecast table below the result answers "will it improve tomorrow" for wildfire-smoke or pollution spikes.

Data comes live from Open-Meteo's free air-quality API - nothing is uploaded and no account is required; the city search uses Open-Meteo's geocoding API.

Location access is optional and only requested after you press Use my location; the browser asks for permission each time you use it, and typing a city name instead needs no permissions at all.
