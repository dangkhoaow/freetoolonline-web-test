How to explain a code snippet in your browser

  1. Paste your code into the box. A sample snippet is preloaded so you can see the output shape first.
  2. Read the instant structure outline - the language guess, function and class names, imports, and loop and conditional counts appear with no download at all.
  3. Choose the explanation style: developer overview, step-by-step walkthrough, or plain English.
  4. For a full explanation, load a code-tuned on-device model (the download size is shown before it starts, and the model is cached for later visits) - or, in browsers that ship built-in AI, the page uses that with zero download.
  5. Press Explain code and copy the result. The code stays on your device the whole time.
