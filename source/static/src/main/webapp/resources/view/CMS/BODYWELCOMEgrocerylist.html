Grocery List

Last reviewed: 2026-08-09

Build your shopping list before a store run - add each item as you notice you are running low, tick things off as they land in the cart, and remove what you no longer need.

It is handy as a quick grocery checklist for the household when you would rather not install an app or create a sign in.

Each grocery item shows a checkbox for marking it bought and a delete button. The list is held in local storage on this one browser, so it stays put across a reload; wiping this site's browser data empties it.

Because local storage is tied to one browser, use the Export backup button to save the list as a JSON file, then use Import backup to load that same file back in - on a new browser, a new device, or after clearing browser data. Nothing is uploaded to a server either way; the file is built and read directly in the browser.

To see how this browser tool compares to a desktop app or an upload-based service, see Grocery List vs desktop apps and online services.
