Grocery List

Last reviewed: 2026-08-09

Build your shopping list before a store run - add each item as you notice you are running low, tick things off as they land in the cart, and remove what you no longer need.

It is handy as a quick grocery checklist for the household when you would rather not install an app or create a sign in.

Each grocery item shows a checkbox for marking it bought and a delete button. Your list is kept on this single browser, tucked into its local storage, which means a mid-shop reload will not lose your ticked-off items - only clearing this site's browser data empties the cart.

Since that storage never travels to another browser on its own, the Export backup button writes the whole list to a JSON file and Import backup reads it back - handy for moving the list to the family tablet or a fresh browser. The file is created and opened right on your device, so no shopping list is ever sent to a server and nothing syncs in the background.

Not sure whether to stick with this in-browser list or switch to a dedicated shopping app? The trade-offs are weighed up in Grocery List vs desktop apps and online services.
