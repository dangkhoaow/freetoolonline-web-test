Grocery List

Last reviewed: 2026-08-09

Build your shopping list before a store run - add each item as you notice you are running low, tick things off as they land in the cart, and remove what you no longer need.

The Grocery List tool is handy as a quick grocery checklist for the household when you would rather not install an app or create a sign in.


Key features

  • Add each item as you run low, then check it off once it is in the cart.
  • Every grocery item shows a checkbox for marking it bought and a delete button.
  • Export backup writes the whole list to a JSON file, and Import backup reads it back.
  • No app to install and no account or sign in to create.

When to use it

Reach for it for the weekly shop or a quick top-up run, when a shared household list beats scattered notes. Because storage never travels to another browser on its own, use Export backup and Import backup to move the list to the family tablet or a fresh browser.


How your list is stored

Your list is kept on this single browser, tucked into its local storage, which means a mid-shop reload will not lose your ticked-off items - only clearing this site's browser data empties the cart.

The backup file is created and opened right on your device, so no shopping list is ever sent to a server and nothing syncs in the background.
