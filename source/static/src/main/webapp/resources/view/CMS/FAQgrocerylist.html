Frequently Asked Questions

Does my list survive closing the tab or restarting the browser?

Yes. Items are held in this browser's local storage, so the list is still there after a reload or restart. It clears only when you delete items yourself or wipe this site's browser data, and it does not sync to other devices.

Do I need an account, and does anything upload?

No account and no upload. The list is built and stored on this device only, so it works offline once the page has loaded.

What complementary tools work well alongside grocery list?

The habit tracker works the same browser-local way for routines you tick off, and both keep their data on this device with no sign-in.
