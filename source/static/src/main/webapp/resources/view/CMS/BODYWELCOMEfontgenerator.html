Where font generator starts, and how the image is sized

If you have not touched a control yet, font generator opens with the sample line "Your Custom Text" set in Arial at 48px, weight 400, centered, black text on a white background, 20px of padding on every side, and no drop shadow. Click Reset at any point to jump straight back to that combination instead of undoing each control by hand.

The exported PNG is never a fixed square or a fixed banner size. Font generator measures your exact text - including every line if you press Enter for a new line - and builds a canvas just wide enough for the longest line and just tall enough for every line, then adds your padding value on all four sides. Type one short word and you download a small, tightly cropped image; type a full multi-line message and the image grows to match, with the same padding all the way around either way.

Turning on the drop shadow adds a shadow set to a 4px blur offset 2px right and 2px down by default, and you can change the shadow color, blur, and offset from there. Copying to the clipboard needs a browser with clipboard-image support (recent Chrome, Edge, and Firefox); if your browser does not support it, the Copy button does nothing but Download still saves the PNG normally.
