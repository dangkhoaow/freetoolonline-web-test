Windows desktop EXIF/XMP/IPTC photo metadata editor powered by ExifTool

Last reviewed: 2026-07-22

See what camera, date, and GPS tags your photos still carry before you share them.


What the editor shows you

  • The camera tags recorded when the shot was taken.
  • The date the photo was captured.
  • GPS location, if the photo still carries it.

Removing location before you share

If GPS is present, a privacy warning and an OpenStreetMap link appear so you can see exactly where the photo places you. From there you can optionally download a JPEG with the metadata stripped, so the copy you pass on no longer carries the original tags.


Runs in your browser

Everything runs in the browser - the photo is never uploaded and no account is required.
