Windows desktop EXIF/XMP/IPTC photo metadata editor powered by ExifTool

Last reviewed: 2026-07-22

See what camera, date, and GPS tags your photos still carry before you share them.


Key features

  • Reads the Camera, Date / Time, GPS, and Other metadata groups from a photo.
  • Opens a local file in the browser without uploading it to a server.
  • Accepts HEIC, HEIF, TIF, and TIFF input alongside common image formats.
  • If GPS is present, a privacy warning and OpenStreetMap link appear.
  • Optionally download a JPEG with metadata stripped.

When to use it

Check a photo before you post it publicly, so you know what travels with the file. If a location tag would reveal where the picture was taken, download the stripped copy instead of the original.


Privacy

Everything runs in the browser - the photo is never uploaded and no account is required.
