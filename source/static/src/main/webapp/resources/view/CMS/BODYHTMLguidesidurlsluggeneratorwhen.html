URL Slug Generator - Kapan Digunakan

Last reviewed: 2026-07-26

URL Slug Generator layak dibuka saat Anda butuh permalink bersih dari judul manusia tanpa menginstal apa pun. Halaman ini menjelaskan kapan cocok dan kapan tidak.


Kapan cocok

Gunakan untuk menyiapkan permalink blog, jalur CMS, atau nama file situs statis dari sebuah judul. Tempel satu frasa per baris untuk batch, pilih "-" atau "_" sebagai pemisah, dan opsional batasi panjangnya.


Yang perlu diharapkan

Slugify menghapus diakritik Latin dan Vietnam lewat Unicode normalize (NFD) dan berjalan lokal - tanpa unggah dan tanpa akun. Copy menaruh slug saat ini ke clipboard; tidak ada yang disimpan antar kunjungan.

Tidak mentransliterasi skrip Cina, Arab, atau Sirilik. Jika Anda butuh skrip itu di jalur, gunakan langkah transliterasi khusus lebih dulu.
